# 浏览器筛选、模型评估与远端归档

本模式由浏览器完成规则计算、排序和模型请求，平台只读取本人选定资料、冻结输入、校验引用并保存结果。需要更新后的服务端与页面一起使用；直接打开 `server/static/index.html` 的 `file://` 页面不能替代平台登录和 API。

## 使用流程

1. 从实际平台 HTTPS 地址打开投资工作台（本机开发可用 localhost），选择本人投资账户，先准备股票/ETF标的和盘后行情缓存。
2. 打开“浏览器筛选与评估”。默认读取已有个人模型配置，也可填写本入口自己的地址、模型名和密钥；“仅保存到本浏览器”按登录账号保存，不改变其他 AI 入口。
3. 明确选择1至20个缓存标的、行情截至日期、规则和排序，最多评估前5个候选。点击“浏览器筛选并查看发送预览”；这一步保存冻结输入和筛选摘要，不调用模型。
4. 展开核对每个候选的实际发送消息。确认后点击“确认上述范围并在浏览器评估”；每个候选进行主分析与同模型反证两次请求，本人 API 可能计费。
5. 在本页、原“AI报告”或任务中心查看报告与分析依据。报告仍使用原引用检查和本人采用流程，建议只生成草稿，不产生实际成交。

## 模型连接条件

- 支持标准非流式 `/chat/completions` JSON 返回；Base URL可填到 `/v1`，本入口自动补接口路径。
- 普通 API 使用 HTTPS；本机服务可使用 `http://localhost:11434/v1`、`http://127.0.0.1:11434/v1` 等严格回环地址。API Key仅在模型服务允许无认证时留空。此例外不放宽其他业务入口。
- 模型 API需要允许实际平台页面来源的跨域请求。访问回环模型服务还可能需要浏览器本地网络权限；不能通过关掉浏览器安全策略、`no-cors`或平台代理解决。[CORS说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS)、[Chrome本地网络访问说明](https://developer.chrome.com/docs/modern-web-guidance/guides/security/local-network-access)。
- 本模式拒绝把平台本身作为模型地址，不携带平台 Cookie或账号头给模型，也不把模型密钥交给平台。若本人配置的是云模型 API，推理仍发生在该服务商，浏览器只是直接发出请求；不等于完全离线。

## 数据和计算范围

首批使用本人选定的已有缓存，每个标的最多200条日线，非全市场。读取新的数据商行情和CSV导入继续使用原入口；从浏览器直接取得新行情、基本面资料与全市场候选池另批推进。

阈值和排序采用带版本的 BigInt 分数比较，不使用二进制浮点近似判断。摘要数值最多展示28位小数，不能用显示截断值替代实际条件比较。当前本地指标包括相邻有效记录收盘变化、前5条成交量比值、收盘与MA20关系，不新增ATR、波动率或收益概率。缺少数据保持未知，不按0处理。

实际模型输入仅包含候选标的身份、筛选摘要及截至所选日期的最近20条日线，并记录摘要省略条数。规则计算的完整原始输入保存在批次快照，主分析和反证分别保留各自的实际消息。不会自动读取私人笔记、持仓金额或其他投资账户原文。

远端保存批次、来源版本/哈希、计算版本、本地上报结果、实际模型输入、原始模型响应、规范化报告与接收回执。来源以后修改/删除不会改写旧快照；查看依据时显示来源状态。模型密钥、平台密码和会话不进入这些记录或检查点。

“远端校验通过”表示结构、引用和阶段匹配，不证明本地真的使用某个模型，不证明行情真实性，也不证明选股或收益有效。所有本地计算均明确标为浏览器自报，远端不重算指标。

## 中断和恢复

- 本页关闭、刷新或电脑休眠后不承诺继续运行。重新登录后打开本入口，使用原批次的本机检查点；恢复会先查看实际发送预览，不自动发起模型调用。
- 收到输出后先保存在当前浏览器账号的 IndexedDB，再上传。网络响应丢失时“查看发送预览 / 重试上传”只重传原输出，不重新请求模型。
- 若只留下“模型调用已开始”但没有收到并保存输出，显示“结果未确认”，不自动重发。核对后取消该批次，明确新建一次尝试；新批次会重新捕获本人选择的来源。
- 多标签页使用浏览器锁，并在拿到锁后重读最新检查点；其他浏览器不能抢占原执行归属。登录/退出会通知同源旧页面停止请求，每次模型调用前也重新核对登录身份；旧账号结果不会上传到新账号。
- 未成功显示发送预览的候选不能随整批确认开始模型调用；先重新查看该候选的预览。浏览器批次与原服务端分析可以分别进行，浏览器专用输入不会改由原服务端分析接口执行。
- 本机检查点丢失后仍可查询远端已保存结果，但未上传的输出无法从远端找回。已确认保存或已取消的批次可清理本机检查点，远端记录保留。
- “暂停并关闭”停止本页后续执行；“取消此批次”同时取消远端未完成候选，迟到结果不能使其恢复完成。
