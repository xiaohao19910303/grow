## 5. T04验收清单

- [x] 决策、预测、旧四问及洞察更新保留既有整数ID；新增ID由数据库分配，删除后不复用。
- [x] 自定义记录以`_record_id`携带数据库ID；表单编辑保留身份元数据。既有数据若与保留字段冲突则停止，不静默覆盖。
- [x] GET在同一读事务获取一致快照并返回`_revision`；PUT在`BEGIN IMMEDIATE`事务内校验后保存。

- [x] 后台导入修改旧状态表后，即使不主动更新修订表，也会使旧内容哈希失效。
- [x] 前端串行提交；保存期间继续编辑不会被响应覆盖，新增记录ID能合并回当前草稿。
- [x] 409后暂停自动保存，保留本地修改，可下载副本并重新读取；读取期间新增编辑也不被替换。
- [x] Python隔离测试、Node异步前端检查和实际Chromium两页面竞争保存验证通过。
