## 🚀 部署到 Render.com

### 步骤 1：注册 Render 账号

1. 访问 https://render.com
2. 点击 "Get Started" 或 "Sign Up"
3. 使用 GitHub 账号登录（推荐）

### 步骤 2：创建 Web Service

1. 登录后，点击 "New +" → "Web Service"
2. 选择 "Connect a repository"
3. 授权 Render 访问你的 GitHub 仓库
4. 选择 "知行成长" 仓库
5. 点击 "Connect"

### 步骤 3：配置服务

Render 会自动检测到 `render.yaml` 配置文件，但你需要确认以下设置：

**基本设置：**
- **Name**: `zhixingchengzhang`（或你喜欢的名字）
- **Region**: Singapore（选择离你最近的区域）
- **Branch**: `main`
- **Runtime**: `Python 3`
- **Build Command**: `pip install -r server/requirements.txt`
- **Start Command**: `uvicorn server.app:app --host 0.0.0.0 --port $PORT`

**环境变量：**
点击 "Environment Variables" 添加：

| Key | Value |
|-----|-------|
| `DATABASE_URL` | `postgresql://postgres:SHUAIge.zhixingchengzhang@db.cafdvxlzmqavmvospgvd.supabase.co:5432/postgres` |
| `PYTHON_VERSION` | `3.11.0` |
| `LEARN_ROOT` | `/opt/render/project/src/学习资料`（可选，如果有学习资料） |

**实例类型：**
- 选择 **Free**（免费套餐）

### 步骤 4：部署

1. 点击 "Create Web Service"
2. 等待部署完成（大约 3-5 分钟）
3. 部署成功后，你会看到一个网址：
   ```
   https://zhixingchengzhang.onrender.com
   ```

### 步骤 5：验证部署

1. 打开浏览器，访问你的网址
2. 检查是否能正常加载页面
3. 测试基本功能：
   - 查看学习模块
   - 创建待办事项
   - 查看学习记录

## 🔐 安全配置

### 数据库安全

数据库连接字符串已经硬编码在代码中，建议：

1. **在 Supabase 设置白名单**（可选）
   - 进入 Supabase 控制台
   - Project Settings → Database
   - 配置网络限制

2. **使用环境变量**（推荐）
   - 从代码中移除数据库连接字符串
   - 只在 Render 环境变量中配置
   - 修改 `db.py` 从环境变量读取

### 访问控制

目前是单用户应用，没有登录功能。如果需要保护：

1. **使用 Render 的私有网络**（付费功能）
2. **添加简单的密码保护**（需要修改代码）
3. **使用 Cloudflare Access**（免费方案）
