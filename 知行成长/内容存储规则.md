生效日期：2026-10-14；数据边界与备份规则更新：2026-10-16。平台定位：个人学习与成长平台。

## 1. 根目录与职责

工作区根目录由应用位置推导，当前为 `/Users/hao/Documents/grow/`，应用目录为 `知行成长/`。原 `/Volumes/Xiaohao/学习/` 为历史路径，不作为固定配置。学习资料按模块与应用目录并列保存，避免把课程、个人笔记与程序运行数据混在一起。

## 2. 正式内容路径

以下路径均相对于工作区根目录；沿用已接入平台的目录和命名方式，暂不增加年份或月份层级，因为当前课程扫描读取直属文件。

| 内容 | 保存路径与命名 | 索引位置 |
|---|---|---|
| 认知通识课程 | `每日认知与通识学习/每日课程/YYYY-MM-DD-第NNN课-主题.md` | 模块下 `学习记录.md` |

| 英文阅读文章 | `英文阅读/每日文章/YYYY-MM-DD-DayNNN-主题.md` | 模块下 `学习记录.md` |
| 表达练习 | `结构化表达/每日练习/Day NNN - 主题.md` | 模块下 `学习记录.md`；正文写日期 |
| 思维工具阶段教程 | `现代思维工具教程/NN-第N阶段-主题.md` | 沿用现有教程目录及总规划 |

写作、综合练习等目录在首次实际生成时创建，不生成空内容占位。英文与表达的既有资料可以保留在正文中；需要单独资料时放在模块的 `参考资料/DayNNN-参考资料.md`，并从正文明确链接。文件存入模块不代表已经接入网页列表；网页仍按现有模块能力展示。

## 3. 日期、序号与防重复

- 日期使用北京时间真实生成日期 `YYYY-MM-DD`；课程编号在所属模块内独立递增，至少补齐三位，从已有最后完整课次继续。已有历史名称不批量重命名。
- 主题用简短中文，不能包含路径分隔符 `/`、`\`、换行或 `..` 路径片段；不把网址当文件名。
- 同日已有完整课程时不重复生成；只有资料或索引缺失时补齐对应课次。不得用新的编号掩盖缺失或冲突。
- 按需文章或独立写作同日同主题有多个内容时，可用 `-02`、`-03` 区分；固定课次课程不得这样复制成多份。
- 本阶段认知课程为第一轮001–168。现有网页只支持第一轮；到达168课时先规划下一轮的独立目录及系统接入，不直接在旧目录混写169课或重新编号001。

## 4. 每次生成的交付流程

1. 读取模块规划、记录索引和最近正文，确认已有课次与当天内容。
2. 核实资料，保存完整课程和可离线阅读的原创资料摘要。摘要包含标题、作者或机构、发布日期（未知则注明）、来源链接、查阅日期、支持的观点与边界。
3. 同课正文和资料使用相对链接互引。新增图片等附件放在模块下 `附件/第NNN课/`（英文和表达使用 `附件/DayNNN/`），避免跨模块重名；不得自动下载受限全文。
4. 正文与资料保存成功后，才向现有索引追加一行；不重写个人记录区。新课程状态为“待本人记录”，文章状态为“待阅读”。
5. 检查文件存在、正文非空、课次唯一、同日无重复、相对链接可达和索引仅追加一次，再通知用户绝对路径。

卷不可用、写入冲突或文件保存失败时，应明确报告，不能把未完成落盘的内容记为已交付。正式课程、资料和笔记不能被新生成内容静默覆盖。

## 5. 程序数据与人工记录

课程 Markdown 是可直接阅读的资料；`server/data.db` 保存平台的结构化记录、草稿等。不要手动改写数据库来标记学习完成，也不要把数据放进前端 `static/`。

网页生成继续走已有草稿、确认保存和冲突恢复流程。外部自动任务与网页写入目前尚未统一锁协议，仍须遵守应用 README 中的安全写入时段要求；本次目录命名调整不改变该并发限制。

原认知模块备份保存在 `知行成长/server/.copilot/backups/`；平台资料与整库备份保存在 `知行成长/server/.plans/backups/`，两者恢复命令不同。浏览器导出文件落在浏览器选择的下载位置，不宣称已自动进入本地课程目录；JSON导出也不等于整个平台的完整备份。

**日常记录（自由记录）与旧复盘的边界**：首页「今日」与「记录」页的「记几句」写入 `执行复盘/日常记录/YYYY-MM/ref-<uuid>.md`，镜像保存在独立的 `reflection_entries` 表；它不进入旧的 `checkins`/`reviews` 全量同步（DELETE+INSERT 覆盖）链路，因此旧 `/api/data` 导出与外部同步脚本不会触碰该目录，反向亦然。AI 追问/整理只发送用户最终选定发送的正文与回答，不扫描其他模块、不把私人内容写进日志。自由记录支持版本历史、归档/恢复与独立导出；完整备份与恢复覆盖新表、版本和 Markdown。外部直接编辑该 Markdown 会触发哈希冲突，需在页面内人工对照，不能删恢复日志假装成功。旧的「复盘四问」文件保持原路径与只读历史形式，不自动迁移、不为旧记录开启 AI。


## 6. 新学习计划（AI规划与手动规划通用）

新增方向采用 `学习计划/plan-YYYYMMDD-NNN/`，与应用目录并列。编号由服务端分配；名称变更不移动目录。已有模块继续原路径，不迁移。

- `计划信息.json`：稳定编号、名称、学习条件、活动版本和状态。
- `学习规划.md`：当前采用的规划；`规划历史/vNNN.md` 保留每次版本。
- `课程目录.md`：正式发布的课程及资料链接。
- `每日课程/YYYY-MM-DD-第NNN课-主题.md` 与 `参考资料/第NNN课-参考资料.md`：正文和原创资料摘要互链。
- `备课资料/第NNN课.json` 与 `第NNN课-摘要.md`：明确选定、可以发给模型的备课内容，不混入个人笔记。
- `学习记录.md`：个人笔记与本人反馈，生成不会自动标为完成。

新计划由平台统一发布，不能继续让外部自动任务绕过平台写入该目录。当前10:00任务仍只写原认知模块。新计划每计划每天至多发布一课；课号独立连续，不因漏学跳号。规划变化不覆盖已发布课次，旧草稿需重新核对版本。数据库保存权威状态，外部改动通过哈希核对后显式导入，不静默覆盖。

新计划与全平台学习备份见 `知行成长/server/.plans/backups/`，恢复命令见平台README。浏览器下载与已有JSON导出仍不代表课程完整备份。
