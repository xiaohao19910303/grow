# 知行成长 - 第二台电脑快速配置指南

## 快速开始（3 步完成配置）

### 步骤 1：拉取最新代码
```bash
cd /Users/hao/Documents/grow/知行成长
git pull
```

### 步骤 2：安装 Python 依赖
```bash
cd server
pip install -r requirements.txt
```

### 步骤 3：启动服务器
```bash
python3 app.py
```

然后打开浏览器访问：http://localhost:8000

## 就这么简单！

因为数据库已经在云端（Supabase），所以：
- ✅ 不需要迁移数据
- ✅ 不需要配置数据库
- ✅ 打开就能看到所有数据
- ✅ 和家里电脑的数据完全一致

## 验证配置

启动服务器后，检查以下几点：

1. **首页加载正常**
   - 应该能看到学习模块
   - 应该能看到之前的学习记录

2. **数据同步正常**
   - 在家电脑添加的数据，这里应该能看到
   - 在这里添加的数据，回家打开电脑也能看到

3. **功能正常**
   - 测试创建一个待办事项
   - 测试记录一次学习
   - 测试查看阅读记录

## 常见问题

### Q: 需要配置数据库连接吗？
A: 不需要！数据库连接已经硬编码在 `db.py` 中，可以直接使用。

### Q: 需要创建本地数据库吗？
A: 不需要！系统使用云端数据库，本地不需要 SQLite 文件。

### Q: 数据会同步吗？
A: 会自动同步！两台电脑访问同一个云端数据库，数据实时同步。

### Q: 需要 git push 数据吗？
A: 不需要！数据保存在云端，不需要通过 git 同步数据（只需要同步代码）。

### Q: 如果忘记带电脑怎么办？
A: 可以在任何电脑上拉取代码并运行，只要安装了 Python 就能使用。

## 日常使用流程

### 在家电脑
1. 启动服务器：`python3 app.py`
2. 打开浏览器：http://localhost:8000
3. 学习和记录
4. 数据自动保存到云端

### 到公司电脑
1. 拉取最新代码：`git pull`（如果有代码更新）
2. 启动服务器：`python3 app.py`
3. 打开浏览器：http://localhost:8000
4. 看到的就是家里的最新数据

### 回家
1. 重复上面的流程
2. 数据自动同步，无缝切换

## 注意事项

1. **网络连接**
   - 需要联网才能访问云端数据库
   - 离线时无法使用系统

2. **代码同步**
   - 如果修改了代码，记得 `git push`
   - 另一台电脑使用前先 `git pull`

3. **数据安全**
   - 数据在云端有备份
   - Supabase 提供免费的数据恢复功能
