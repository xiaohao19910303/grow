4. 第二轮人工语义核对：近5日≥3%、当日换手[2,8]%、5日平均成交额≥1亿元→100000000元、量比降序均保留；量比>1被明确标为AI建议，未宣称有效。将此草稿应用到真实股票数据后，000001因涨幅及换手率条件不满足而排除；不得为制造入选而调整用户阈值。此句核对通过不能证明全部自然语言正确。
5. **真实浏览器模型全流程未通过**：[Chrome跨域证据](browser-model-cors.json)显示实际模型响应含多个 `Access-Control-Allow-Origin` 值 `*,*`，浏览器拒绝；预检允许头也未列Authorization。本机请求能成功不代表浏览器能直连。需模型服务响应支持正确的单一允许来源及Authorization/Content-Type预检，或本人换成支持浏览器直连的兼容地址后再验收。未改为服务端代理、未自动切换地址、未关闭浏览器安全。
6. 受此CORS阻塞，真实浏览器自然语言生成及候选主分析/反证尚未放行；候选流程只有模拟模型UI和HTTP证据。ETF原流程通过回归，本次真实行情样例为股票，不将历史ETF真实验收算作本次重新验证。
