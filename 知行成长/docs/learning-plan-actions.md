# 课程规划关联行动与阶段进度

采用课程规划时，可保留默认选中的「同时关联到行动（不指定学习日期）」。已有规划可进入「学习 → 课程规划 → 查看计划」，点击「关联到行动」。这一步不调用模型，也不生成未发布的课程。

只为已正式发布且尚未确认学完的课程补入内容行动。未发布课程先显示在进度中，等正式发布后再自动补入。已有同课行动会被复用，其标题、日期和状态保留。反复同步不会重复创建，已被本人编辑、取消或归档的关联行动不会被自动覆盖或重新创建。

「行动 → 目标与计划」可查看整体和阶段进度。分母是当前正式规划的全部课次，包含尚未发布课程；分子是已发布且由本人确认学完的课次。草稿、生成成功、笔记或累计分钟都不算学完。阶段按正式规划中的阶段划分，整体按课次计算，不平均各阶段百分比。

关联的行动默认位于「未安排」，没有提醒、学习日期或虚构的学习时长。点击「查看第 N 课行动」，再选择「安排今日并开始」；学完后，在课程中点击「本人确认学完」。系统复用已有来源回执更新对应内容行动，重复确认不重复记录同一完成。学习状态和行动状态会分别显示。

如果直接在课程中确认学完，课程进度照常更新。仍未安排日期的行动不会因此被补成过去的执行；可查看行动并由本人整理。计时行动、内容行动和勾选待办继续使用各自的完成规则。

规划详情和行动页都提供「同步已发布课程到行动」「停止自动补入」「恢复自动补入」。停止补入保留已有行动；暂停或归档课程规划时不新增行动，已有行动的日期和状态仍由本人管理。恢复规划后可显式同步。

正式内容保存成功、但关联失败时，页面会提示「正式内容已保存，关联行动尚未同步」。在规划详情重试关联或同步即可，无需重新生成、再次发布或重复录入。读取失败可直接重试读取；旧版本页面须刷新后才能写入行动。

关联数据、学习反馈和执行记录均属于当前账号。若行动已进入跨端接管阶段，Grow 仅展示课程进度，拒绝在本地补项。当前实现面向 GitHub 正式内容与 PostgreSQL 存储，不改变原生端或 Zook 的接口与发布开关。
