# 网页设计变量与验收约定

主页面的共享变量集中在 `server/static/design-tokens.css`，由 `index.html` 在组件样式前加载。沿用现有品牌蓝、渐变、字号与布局，提供颜色、间距、圆角、阴影、字体及动态效果变量。

原有 `--primary-soft`、`--green`、`--red`、`--amber`、`--radius` 等名称通过别名保留，避免已有业务模块失去颜色或圆角。主页面不再内联重复定义这些变量。更改文件后同步更新页面的资源版本参数，防止浏览器使用旧样式。

状态底色与文字色分别定义。徽标正常、提醒和错误文字使用对应前景色，验收要求正常字号的文字／底色对比度至少 4.5:1；图表和进度仍可沿用原语义颜色。键盘聚焦的输入和按钮保留清晰轮廓，鼠标使用仍沿用原交互状态。

系统开启“减少动态效果”时，网页缩短过渡和动画、禁用按钮按压缩放，并停止平滑滚动。正常模式保留既有轻量反馈，不改变业务状态或执行时间。

浏览器最小夹具如果只抽取 `index.html` 的内联样式，需要同时载入 Token 文件；生产页面则请求原始 CSS 资源。样式验收覆盖 320、768、1440px、键盘、减少动态效果、状态对比度与既有设置、阅读、规划和行动流程。

本次范围是 Grow 网页的待提交样式收尾。原生端的设计一致性需要独立核验，Token 文件不表示与原生端自动同步。运行环境与样式专项证据见[验收报告](../../docs/verification/runtime-design-closeout-2026-10-25/README.md)。
