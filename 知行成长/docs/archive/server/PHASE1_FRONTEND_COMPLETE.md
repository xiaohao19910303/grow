## 技术实现要点

### 1. 模块封装模式
所有新模块采用 IIFE（立即调用函数表达式）封装：
```javascript
(function () {
  'use strict';
  // 私有状态和函数
  
  // 暴露公开接口
  window.ModuleName = {
    publicMethod1,
    publicMethod2,
  };
})();
```

### 2. API 调用模式
统一使用 fetch + async/await，自动处理认证：
```javascript
try {
  const response = await fetch(url);
  if (!response.ok) throw new Error('请求失败');
  const data = await response.json();
  // 处理数据
} catch (error) {
  toast('操作失败: ' + error.message);
}
```

### 3. XSS 防护
所有用户输入渲染到 HTML 前都经过 `esc()` 转义：
```javascript
function esc(s) {
  return String(s == null ? '' : s).replace(/[&<>"']/g, c => ESC[c]);
}
```

### 4. 响应式设计
复用现有断点：760px / 680px / 480px，确保移动端体验。

### 5. 可访问性
- ✅ 搜索框添加 `aria-label`
- ✅ 键盘导航支持（⌘K 快捷键）
- ✅ 焦点管理
