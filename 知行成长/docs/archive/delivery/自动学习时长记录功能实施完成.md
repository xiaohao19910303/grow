#### 技术细节

```javascript
// 时间追踪核心逻辑
let learningStartTime = null;
let elapsedTime = 0;
let timerInterval = null;

// 开始追踪
function startLearningTimer(lessonNo) {
  currentLessonNo = lessonNo;
  learningStartTime = Date.now();
  elapsedTime = 0;
  
  // 每秒更新一次
  timerInterval = setInterval(() => {
    elapsedTime = Math.floor((Date.now() - learningStartTime) / 1000);
    updateTimerDisplay();
  }, 1000);
}

// 获取学习时长
function getElapsedTime() {
  if (learningStartTime) {
    return Math.floor((Date.now() - learningStartTime) / 1000);
  }
  return elapsedTime;
}
```

### 2. 命名优化：认知阅读 → 今日阅读

#### 修改内容

- ✅ `index.html` - 导航标签：`认知阅读` → `今日阅读`
- ✅ `reading.js` - 所有界面文本：

用户反馈："认知阅读改成今日阅读吧，不一定局限于认知领域，可以是科技、医疗、航天、物理等前沿科技类、管理类等，不要局限"

新的命名更加通用，不局限于特定领域，涵盖：
- 前沿科技
- 医疗健康
- 航空航天
- 物理化学
- 管理商业
- 其他任何感兴趣的领域

## 📊 数据流程

### 学习时长记录流程

```
用户开始学习
    ↓
启动计时器 (startLearningTimer)
    ↓
每秒更新显示 (updateTimerDisplay)
    ↓
用户完成学习
    ↓
获取学习时长 (getElapsedTime)
    ↓
提交到后端 (time_spent_seconds)
    ↓
保存到数据库 (copilot_learning_records.time_spent_seconds)
    ↓
在学习记录中显示
```

### API 端点

所有完成方式都接受 `time_spent_seconds` 参数：

1. **复盘完成** - `POST /api/copilot/lessons/{number}/review`
2. **总结完成** - `POST /api/copilot/lessons/{number}/summary`
3. **快速完成** - `POST /api/copilot/lessons/{number}/complete`
