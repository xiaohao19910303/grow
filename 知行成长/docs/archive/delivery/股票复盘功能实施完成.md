## 📊 功能概览

### 股票复盘功能

**核心功能**：
1. ✅ 创建股票记录（买入/卖出/持有）
2. ✅ 记录操作价格、数量、目标价、止损价、信心度
3. ✅ 添加操作理由和标签
4. ✅ 追踪结果（成功/失败）
5. ✅ 自动计算盈亏
6. ✅ 复盘思考（做对了什么、做错了什么、学到的教训、投资模式）
7. ✅ 统计视图（总记录数、成功率、总盈亏等）
8. ✅ 筛选功能（全部/进行中/成功/失败）
9. ✅ 编辑和删除记录

**数据模型**：
```javascript
{
  id: "stock-xxx",
  stock_code: "600519",
  stock_name: "贵州茅台",
  action: "buy",           // buy/sell/hold
  date: "2026-10-15",
  price: 1800.50,
  quantity: 100,
  rationale: "理由...",
  target_price: 2000,      // 可选
  stop_loss: 1600,         // 可选
  confidence: 0.7,         // 可选 0-1
  outcome: "success",      // pending/success/failure
  actual_price: 1950,
  result_date: "2026-11-15",
  profit_loss: 14950,      // 自动计算
  retrospective: {
    what_went_right: "...",
    what_went_wrong: "...",
    lessons_learned: "...",
    pattern: "value_investing"
  },
  tags: ["白酒", "消费升级"],
  created_at: "2026-10-15T23:33:24+08:00",
  updated_at: "2026-10-15T23:35:00+08:00"
}
```

**API 端点**：
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/stocks` | 列出所有记录（可选 status 过滤） |
| GET | `/api/stocks/statistics` | 获取统计数据 |
| POST | `/api/stocks` | 创建股票记录 |
| GET | `/api/stocks/{id}` | 获取单条记录 |
| PUT | `/api/stocks/{id}` | 更新股票记录 |
| POST | `/api/stocks/{id}/outcome` | 更新结果和复盘 |
| DELETE | `/api/stocks/{id}` | 删除记录 |

## 🚀 如何使用

### 访问股票复盘模块
1. 打开浏览器访问 `http://localhost:8756`
2. 点击顶部导航栏的"记录"标签
3. 在子导航栏中点击"投资复盘"

### 创建第一条股票记录
1. 点击"+ 新建股票记录"按钮
2. 填写表单：
   - 股票代码：如 600519
   - 股票名称：如 贵州茅台
   - 操作类型：选择买入/卖出/持有
   - 操作日期：选择日期
   - 价格：输入买入价格
   - 数量：输入购买数量
   - 操作理由：记录你的投资逻辑
   - 标签：如 白酒, 消费升级
3. 点击"创建记录"

### 更新结果和复盘
1. 在股票记录卡片上点击"更新结果"按钮
2. 填写：
   - 结果：选择成功/失败
   - 实际价格：输入卖出价格
   - 结果日期：选择日期
   - 做对了什么：记录你的正确判断
   - 做错了什么：记录你的错误判断
   - 学到的教训：总结你学到的经验
   - 投资模式：如 value_investing, momentum 等
3. 点击"保存结果"

### 查看统计
统计卡片会自动显示：
- 总记录数
- 进行中的记录数
- 成功的记录数
- 失败的记录数
- 成功率（百分比）
- 总盈亏（自动计算）

### 筛选记录
点击筛选器按钮可以快速查看：
- 全部记录
- 进行中的记录
- 成功的记录
- 失败的记录

## 🔧 技术要点

### 标签系统设计
- 标签存储为 JSON 数组（`tags: list[str]`）
- 不建独立表，纯文本标签
- 前端支持逗号分隔输入，自动解析

### 股票复盘设计
- 独立模块，不与其他记录混合
- 支持三种操作：买入/卖出/持有
- 结果追踪：成功/失败/进行中
- 自动计算盈亏：
  - 买入：(actual_price - price) * quantity
  - 卖出：(price - actual_price) * quantity
- 复盘包含四个维度：
  - 做对了什么（what_went_right）
  - 做错了什么（what_went_wrong）
  - 学到的教训（lessons_learned）
  - 投资模式（pattern）

### 前端架构
- 使用原生 JavaScript，无框架依赖
-  StocksModule 类封装所有逻辑
- 响应式设计，支持移动端
- 使用 CSS 变量适配主题
