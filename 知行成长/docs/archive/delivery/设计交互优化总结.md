## 🎯 设计原则

所有优化遵循以下设计原则：

1. **一致性**：使用统一的系统设计令牌，确保视觉一致性
2. **可访问性**：支持 `prefers-reduced-motion`，尊重用户偏好
3. **响应式**：优化移动端体验，确保在小屏幕上也能良好显示
4. **反馈**：提供清晰的用户反馈（toast 通知、悬停效果、焦点状态）
5. **可用性**：添加键盘快捷键，提升效率；添加确认对话框，防止误操作

## ⏳ 待实施功能

### 自动学习时长记录

**用户需求**：学习时长应该根据学习阅读过程自动记录，不需要手动输入。

**实施方案**（待开发）：
1. **前端追踪**：在用户阅读学习内容时，使用 JavaScript 记录开始时间和结束时间
2. **后端存储**：将学习时长自动保存到学习记录数据库
3. **集成方式**：
   - 在 `daily-learning.js` 或 `reading.js` 中添加时间追踪逻辑
   - 用户开始阅读时记录 `start_time`
   - 用户完成阅读或离开页面时记录 `end_time`
   - 计算差值并自动保存到 `/api/copilot/learning-history/` 接口
4. **UI 调整**：移除手动输入学习时长的表单字段，改为自动显示

**技术要点**：
- 使用 `performance.now()` 或 `Date.now()` 记录时间
- 使用 `visibilitychange` 事件检测页面可见性
- 使用 `beforeunload` 事件在用户离开时保存记录
- 考虑网络延迟和失败重试机制
