# 今日、行动与学习

主导航为今日、行动、学习、记录、成长。阅读与课程归学习，课程规划统一称课程计划。

## 数据与交互合同

- 内容保存在原阅读库／课程库；某日安排复用 action_plans 的 day 行动，通过 target 引用原内容。
- 日行动增加 completion_mode：time（原有计时目标，默认）、content（本人确认读完／学完）、check（普通待办勾选）。既有数据默认 time，无破坏性迁移。
- POST /api/action-plans/schedules：title、target、date、timezone（默认 Asia/Shanghai）、target_minutes（预计时长）、key。同一内容同一天只有一条未取消安排，不同请求编号也不会重复创建。已完成安排再次加入同一天返回原安排。
- 日期安排通过 reschedule 操作原地修改，保留执行记录；目的日期已有相同内容时返回冲突，原安排不变。cancel 只取消安排，不删除内容。执行中的安排需先保存执行。
- 今日仅显示所选日期的安排、旧待办与当天记录。明日预览显示次日安排。过去未完成的事项进入行动的待调整视角，不自动滚入下一天。
- content 安排在来源实际保存本人完成确认后完成；未来安排不随当前确认完成。计时目标的达成不修改内容状态。普通待办支持勾选与撤销完成。
- 完成事实写 action_executions，content/check 不推算投入分钟；仅有实际计时确认时才计入时长。记录和成长读取相同执行事实。
- 新安排、改期、取消使用现有同源保护、账号隔离、版本检查与幂等请求合同。
- 阅读位置作为私有 PostgreSQL 记录保存，不写 GitHub。正文渲染与视图切换不改变读完状态。

## 实施与验收

- [ ] 五个主导航，今日无重复子导航，阅读归学习。
- [ ] 保存文章／课程后可以加入今日、明日或选择日期，展示当前安排并支持取消、改期。
- [ ] 今日安排统一展示行动、内容与普通待办，保留旧待办；明日预览与日期切换同步。
- [ ] 行动提供目标计划、日程安排和待调整视角；不要求小事绑定目标。
- [ ] 确认完成、投入时长、阅读位置各自按真实保存结果更新。
- [ ] 记录展示执行事实，成长分别统计完成行动与实际投入。
- [ ] 隔离数据库验证去重、并发、改期冲突、跨天、完成规则、取消保留原文、账号隔离。
- [ ] 浏览器走通文章加入明日、明日预览、改期今日、开始阅读、确认读完及刷新恢复。
