# 配置个人 AI

已有课程、文章和自己的记录无需 AI 配置即可使用。生成课程、阅读导读或 AI 辅助时，才需要自己的服务地址、API Key 和模型名称。

进入「设置 → 课程生成配置 → 开始配置引导」。课程规划、认知课程及自动导读的缺配置提示也可通过「配置个人模型」进入引导。离开原页面前，仍会执行原有未保存输入保护。

1. **服务地址**：从服务商复制兼容 Chat Completions 的 HTTPS API 地址。填写 API 地址而非聊天网页地址；保留服务商要求的路径，末尾带或不带 `/chat/completions` 均可。地址不能带账号密码、查询参数或片段，密钥填写在下一步。
2. **密钥与模型**：填写自己的 API Key，并复制该密钥有权限使用的模型 ID。模型名称不是自定义昵称。密钥以密码框显示；核对摘要不显示密钥。
3. **核对并保存**：核对地址、模型和保存范围，点击「保存配置」。保存只写入当前账号在当前浏览器的站点存储，不调用模型、不自动测试、不自动生成课程。也可以先点击「测试连接」。

熟悉配置后，可使用「直接编辑全部字段」。在引导中前进、后退或切换直接编辑会保留当前填写；只有点击保存才写入本地配置。「读取本地配置」会用已保存值替换当前输入，「清除本地配置」只移除当前账号在当前浏览器的 AI 配置，学习内容与记录保留。

## 测试连接与失败恢复

「测试连接」使用当前填写的三个字段，经后端临时发送一次简短模型请求，可能产生服务商费用。测试不自动保存配置；连接成功只说明本次收到完整响应，不保证后续额度、速度或所有模型能力。

- 填写缺失、地址不合法、字段过长或包含控制字符时，先在本地提示，不发测试请求。
- 连接失败时，核对服务地址、密钥权限、模型 ID、额度和服务商状态，再手动重试。未保存的测试不会改写旧配置；界面不回显提供商原始错误或密钥。
- 可取消等待；超时后可重试。修改字段、读取、清除、离开设置或切换账号后，旧测试结果不再用于说明当前配置。
- 浏览器拒绝站点存储时，保存会明确报错，不显示成功，原有保存值保留。允许该站点存储后重试；不要把密钥写进学习笔记或课程正文来代替配置。

配置按账号保存在当前浏览器与站点地址下。换浏览器、换设备、换站点地址或清除站点数据后，需要重新填写。其他账号读取不到本账号的配置；服务端不保存这组 AI 配置，也不使用环境变量或平台共享密钥兜底。后台生成需要时仅从当次请求临时取得配置。

保存后回到原功能，由本人重新选择生成；引导不会重放刚才的请求。课程学完、行动完成和投入时间的区别见[完成与进度说明](completion-semantics.md)。
