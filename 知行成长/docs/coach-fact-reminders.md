# 教练今日提醒：记录事实与规则

打开「今日」或「成长 → 成长总览」会自动显示一条基于当前账号已保存数据的事实，不需要填写 AI 配置或点击生成。两处展示同一条事实，包含日期范围、北京时间口径、来源及判断边界。尚无相关记录时会明确显示空态，不生成示例成绩。

## 显示规则

按以下顺序选择第一条符合条件的提示：

| 提示 | 条件与依据 | 判断边界 |
|---|---|---|
| 分类记录变化 | 前三个完整北京时间日期都有正样本，且分类记录数逐日严格递减，例如3、2、1 | 同一分类每日只计一次，包含进展与学完记录；不是课程数、时长或实际能力下滑；今天不参与比较 |
| 课程回看 | 英文／表达、认知或当前有效学习计划课程的最近学完确认距今至少14天 | 只说明最近确认记录的间隔，不能证明此后没有在线或线下复习；暂停／归档的学习计划及归档认知课程不参与 |
| 预测事实 | 本周录入、结果为正确／错误且概率在0–100内的已核对预测至少5条 | 展示样本数、正确数和四舍五入到整数的准确率；待核对和未知结果不计入，不推断概率校准或长期能力 |
| 连续活动记录 | 学习分类或习惯补记连续有记录至少2天 | 与成长统计一致，今天尚无记录时可延续到昨天；不是必须维持的打卡要求 |
| 近7天活动／空态 | 当前没有满足上述阈值的事实 | 同一天多来源只计一天；未记录不代表没有学习，不合计可能重叠的时长 |

课程内容尚未生成或没有明确学完记录时，不会据此提醒“久未复习”。查看依据后，可以通过「查看记录」回到学习回顾或预测记录，也可以自行选择下一步。

## 提醒与收起

- 复用现有行动提醒的前台刷新循环；同一页面最多每5分钟常规读取一次，初次打开、跨日或明确确认课程学完后可提前刷新。普通表单自动保存只使快照失效，下一次前台循环或进入卡片页时读取，避免每次输入都查询。数据读取失败显示重试，不把故障当作零记录。
- 有到时行动提醒时，教练卡片先收起，行动处理或不再到时后恢复；日常节奏提醒仍沿用原设置。教练卡片不需要开启日常节奏，也不改变其开关。
- 「今天先不显示」只保存当前账号的一条日期。同账号其他标签页与刷新后也沿用；次日可再次显示。浏览器禁止站点存储时，本页仍能收起，但重开页面可能恢复。
- 不新增桌面／系统推送，不申请通知权限，不承诺关网页送达，不自动运行 AI 行为报告。
- 课程完成、行动同步等原有反馈不等待事实读取。事实请求即使变慢或失败，也不会撤销已保存的完成记录。

## 数据与隐私

`GET /api/coach-facts` 沿用现有登录与账号身份检查，只读当前账号 PostgreSQL schema。读取使用一致性只读事务，无新增表、提醒日志或定时任务，不向外部模型或 GitHub 发送数据；响应不包含私人笔记、习惯正文或 API Key。

日期沿用现有成长统计的 `Asia/Shanghai`，与某项行动单独设置的时区分别说明。未来日期、无效日期与不支持的预测结果不会被算成已发生的事实。

本轮实现与隔离测试证据见[D1/D2 专项验收](../../docs/verification/coach-facts-2026-10-25/README.md)。它说明受测版本的行为，不代表线上已发布或真实账号已经使用验证。
