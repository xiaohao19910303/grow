## 使用指南

### 1. 启动服务

```bash
# 最简单的方式
./run.sh

# 或者
./manage.sh start

# 或者
make start
```

### 2. 查看服务状态

```bash
./manage.sh status
```

### 3. 使用认知阅读

#### 查看来源
```
学习 → 认知阅读 → 阅读偏好与来源 → 内容来源管理
```

#### 添加自定义来源
```
点击"添加自定义来源"
填写：名称、URL、语言、主题
点击"添加来源"
```

#### 搜集文章
```
认知阅读 → 帮我找文章
选择主题和语言
开始搜集
```

#### 阅读文章
```
点击文章卡片 → 阅读导读与笔记
查看完整文章
生成总结/导读/英语学习材料
记录个人笔记
```

### 4. 管理命令

```bash
# 启动
./run.sh

# 停止
./run.sh stop

# 重启
./run.sh restart

# 查看状态
./run.sh status

# 查看日志
./run.sh logs
```

## 注意事项

### 服务管理
1. ✅ 服务在后台运行，关闭终端不影响
2. ✅ 自动PID管理，防止重复启动
3. ✅ 日志自动轮转
4. ⚠️ 定期清理 `.server.log` 避免过大

### 认知阅读
1. ✅ 所有文章保存在本地，不依赖网络
2. ✅ 文件哈希保护，防止冲突
3. ⚠️ AI功能会调用模型，可能产生费用
4. ⚠️ 自定义来源需要有效的RSS/Atom订阅
5. ⚠️ 某些网站可能无法获取完整内容（反爬虫）

### 数据备份
建议定期备份：
```bash
# 备份整个认知阅读目录
cp -r 认知阅读/ 认知阅读备份-$(date +%Y%m%d)/

# 备份数据库
cp server/data.db server/data.db.backup
```
