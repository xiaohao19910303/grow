### Phase 2: 股票复盘功能（后端）✅

**新建文件**：

- `server/stocks/store.py` - 数据存储和查询逻辑

**修改文件**：
- `server/app.py` - 导入和注册 stocks 模块

**数据库表**：
```sql
CREATE TABLE IF NOT EXISTS stock_records (
    id TEXT PRIMARY KEY, data TEXT NOT NULL);
```

**API 端点**：
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/stocks` | 列出所有记录（可选 status 过滤） |
| GET | `/api/stocks/statistics` | 获取统计数据 |
| POST | `/api/stocks` | 创建股票记录 |
| GET | `/api/stocks/{id}` | 获取单条记录 |
| PUT | `/api/stocks/{id}` | 更新股票记录 |
| POST | `/api/stocks/{id}/outcome` | 更新结果和复盘 |
| DELETE | `/api/stocks/{id}` | 删除记录 |

**API 测试**：
```bash
# 创建股票记录 ✅
curl -X POST "http://localhost:8756/api/stocks" \
  -H "Content-Type: application/json" \
  -H "X-Copilot-Request: 1" \
  -d '{
    "stock_code": "600519",
    "stock_name": "贵州茅台",
    "action": "buy",
    "date": "2026-10-15",
    "price": 1800.50,
    "quantity": 100,
    "rationale": "看好消费升级趋势",
    "target_price": 2000,
    "stop_loss": 1600,
    "confidence": 0.7,
    "tags": ["白酒", "消费升级"]
  }'

# 更新结果和复盘 ✅
curl -X POST "http://localhost:8756/api/stocks/stock-b808baa284f248ec/outcome" \
  -H "Content-Type: application/json" \
  -H "X-Copilot-Request: 1" \
  -d '{
    "outcome": "success",
    "actual_price": 1950,
    "result_date": "2026-11-15",
    "retrospective": {
      "what_went_right": "判断对了消费复苏的趋势",
      "what_went_wrong": "买入时机可以更好",
      "lessons_learned": "不要追高",
      "pattern": "value_investing"
    }
  }'

# 获取统计 ✅
curl -s "http://localhost:8756/api/stocks/statistics" | jq '.'
```

## 📋 技术要点

### 标签系统设计
- 标签存储为 JSON 数组（`tags: list[str]`）
- 不建独立表，纯文本标签
- 支持逗号分隔输入，前端解析

### 股票复盘设计
- 独立模块，不与其他记录混合
- 支持三种操作：买入/卖出/持有
- 结果追踪：成功/失败/进行中
- 自动计算盈亏（price * quantity）
- 复盘包含四个维度：做对了什么、做错了什么、学到的教训、投资模式
