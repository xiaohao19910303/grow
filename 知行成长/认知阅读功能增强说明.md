# 认知阅读功能增强 - 更新说明

## 新增功能概览

### 1. 自定义来源管理 ✅

**功能说明**：
- 可以添加自己喜欢的RSS/Atom订阅源
- 支持删除已添加的自定义来源
- 系统默认提供10个优质来源推荐

**默认来源列表**：
1. **Aeon** (英文) - 认知、社会学、心理
2. **Behavioral Scientist** (英文) - 认知、心理、社会学
3. **FT中文网** (中文) - 经济学、社会学
4. **阮一峰的网络日志** (中文) - 成长、社会学
5. **Our World in Data** (英文) - 经济学、社会学、认知
6. **36氪** (中文) - 成长、经济学
7. **少数派** (中文) - 成长、认知
8. **Harvard Business Review** (英文) - 成长、认知、心理
9. **Psychology Today** (英文) - 心理、认知
10. **Wait But Why** (英文) - 认知、成长、心理

**使用方法**：
1. 进入"认知阅读" → 点击"阅读偏好与来源"
2. 滚动到"内容来源管理"部分
3. 查看默认推荐来源和已添加的自定义来源
4. 点击"添加自定义来源"展开表单
5. 填写来源名称、订阅地址、选择语言和主题
6. 点击"添加来源"按钮

### 2. 本地文章完整展示 ✅

**功能说明**：
- 搜集文章时自动获取完整内容
- 在应用内完整展示文章，无需跳转到原文网站
- 支持Markdown格式渲染，阅读体验更佳
- 文章保存到本地，可随时查看，不依赖网络

**使用流程**：
1. 搜集文章后，系统会自动获取完整内容
2. 打开文章阅读时，直接显示完整文章
3. 如果文章尚未获取，会显示"获取并保存完整文章"按钮
4. 点击按钮即可获取并保存到本地

### 3. 详细总结功能 ✅

**功能说明**：
- 基于文章全文生成详细的中文总结
- 包含以下部分：
  - 核心观点（3-5个要点）
  - 关键论据和例子
  - 作者的主要论证逻辑
  - 文章的局限或待讨论之处
  - 对读者的启发（2-3点）
- 总结保存到本地文件，可随时查看

**使用方法**：
1. 打开文章阅读界面
2. 滚动到"内容总结"部分
3. 点击"生成/更新中文总结"按钮
4. 等待AI生成完成
5. 总结会自动保存到本地

### 4. 英语学习材料（仅英文文章）✅

**功能说明**：
- 专为英文文章设计的英语学习辅助功能
- 包含以下内容：
  - 重点词汇（8-12个高级词汇，含音标、中文释义、原文例句）
  - 重要短语和搭配（5-8个）
  - 关键语法点（2-3个复杂句式解析，含中文翻译）
  - 长难句分析（挑选2-3个典型句子，逐层解析结构）

**使用方法**：
1. 打开英文文章阅读界面
2. 滚动到"英语学习"部分
3. 点击"生成/更新英语学习材料"按钮
4. 等待AI生成完成
5. 学习材料会自动保存到本地

### 5. AI导读与解读升级 ✅

**功能说明**：
- 基于完整文章内容生成详细导读（不再是简短摘要）
- 包含以下部分：
  - 文章概览（100字简介）
  - 核心观点（3-5个要点，每个要点展开说明）
  - 关键论据和例子
  - 论证逻辑分析
  - 批判性思考（文章的局限、可能的反驳）
  - 实用启发（如何应用到生活中）
  - 延伸阅读建议

**使用方法**：
1. 打开文章阅读界面
2. 滚动到"AI导读与解读"部分
3. 点击"生成/更新AI导读"按钮
4. 等待AI生成完成
5. 导读会自动保存到本地

## 界面改进

### 文章阅读界面重构

新的文章阅读界面分为以下几个清晰的区域：

1. **操作按钮区** - 收藏、稍后阅读、完成状态
2. **完整文章内容** - 显示完整文章，无需跳转
3. **内容总结** - 详细总结（中文文章）
4. **英语学习** - 英语学习材料（英文文章）
5. **AI导读与解读** - 深入分析和理解
6. **个人笔记** - 记录自己的思考和想法

每个区域都是独立的卡片式设计，清晰易读。

### 来源管理界面

在"阅读偏好与来源"页面新增：

- **默认推荐来源** - 系统预设的10个优质来源
- **自定义来源** - 用户添加的来源列表，支持删除
- **添加自定义来源** - 可折叠的表单，方便添加新来源

## 技术细节

### 数据存储位置

所有文章和生成的内容都保存在本地：

```
认知阅读/
├── 文章资料/
│   └── article-{id}/
│       ├── 文章信息.json      # 文章元信息
│       ├── 原文.md            # 完整文章内容
│       ├── 详细总结.md        # AI生成的详细总结
│       ├── 英语学习.md        # 英语学习材料
│       ├── 中文导读.md        # AI导读与解读
│       └── 个人笔记.md        # 用户的个人笔记
```

### API端点新增

- `GET /api/reading` - 现在返回 `default_sources` 和 `custom_sources`
- `POST /api/reading/sources` - 添加自定义来源
- `DELETE /api/reading/sources/{id}` - 删除自定义来源
- `POST /api/reading/articles/{id}/fetch_full` - 获取完整文章

### 任务类型新增

- `fetch_full` - 获取并保存完整文章内容
- `summary` - 生成详细总结（基于完整文章）
- `english` - 生成英语学习材料
- `guide` - 生成详细导读（基于完整文章）

## 使用建议

### 推荐的阅读流程

1. **搜集文章** - 按主题和语言搜集感兴趣的文章
2. **浏览完整内容** - 在应用内阅读完整文章
3. **生成总结** - 获取文章的核心观点和论据
4. **阅读导读** - 了解深入分析和批判性思考
5. **记录笔记** - 写下自己的思考和想法
6. **英语学习**（英文文章）- 学习重点词汇和语法

### 自定义来源建议

添加自定义来源时，建议：

1. 选择你经常阅读的高质量博客或网站
2. 确保网站提供RSS或Atom订阅（通常以 `/feed`、`/rss`、`/atom.xml` 结尾）
3. 为每个来源选择合适的主题，便于筛选
4. 定期检查来源是否有效，删除失效的来源

### AI功能使用提示

- **总结、导读、英语学习都会调用AI模型**，可能产生费用
- 建议先阅读完整文章，再使用AI功能辅助理解
- 生成的内容仅供参考，建议结合原文理解
- 可以在个人笔记中记录AI分析不准确的地方

## 注意事项

1. **自定义来源需要有效的RSS/Atom订阅地址**
   - 不是所有网站都提供订阅
   - 可以使用RSS订阅发现工具查找

2. **完整文章获取可能失败**
   - 某些网站有反爬虫机制
   - 某些文章需要登录才能访问
   - 获取失败时可以手动复制文章内容

3. **AI生成内容需要调用模型**
   - 会产生费用，请注意控制使用量
   - 生成过程需要几秒钟，请耐心等待
   - 如果生成失败，可以重试

4. **所有数据都保存在本地**
   - 不会自动同步到云端
   - 建议定期备份"认知阅读"目录
   - 删除文章会同时删除所有相关文件
