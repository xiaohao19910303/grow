# 知行成长 - 快速启动参考卡

## 🚀 一键启动

```bash
./run.sh
```

就这么简单！服务会自动启动并打开浏览器。

## 📋 常用命令速查

| 操作 | 命令 | 说明 |
|------|------|------|
| **启动** | `./run.sh` | 一键启动（推荐） |
| **停止** | `./run.sh stop` | 停止服务 |
| **重启** | `./run.sh restart` | 重启服务 |
| **状态** | `./run.sh status` | 查看运行状态 |
| **日志** | `./run.sh logs` | 查看实时日志 |

## 🔧 高级命令

### 使用管理脚本

```bash
./manage.sh start     # 启动
./manage.sh stop      # 停止
./manage.sh restart   # 重启
./manage.sh status    # 状态
./manage.sh logs      # 日志
./manage.sh help      # 帮助
```

### 使用 Make 命令

```bash
make start      # 启动 (或 make up)
make stop       # 停止 (或 make down)
make restart    # 重启 (或 make reload)
make status     # 状态 (或 make ps)
make logs       # 日志 (或 make log)
```

## ⚙️ 自定义配置

### 修改端口
```bash
PORT=9000 ./run.sh
```

### 局域网模式
```bash
export COPILOT_LAN=1
export COPILOT_ACCESS_TOKEN="your-token-at-least-24-chars"
export COPILOT_ALLOWED_HOSTS="192.168.1.100"
./run.sh
```

## 📊 服务信息

- **地址**: http://localhost:8756
- **PID文件**: `.server.pid`
- **日志文件**: `.server.log`

## 🐛 故障排查

### 服务无法启动？
```bash
# 1. 检查虚拟环境
ls -la .venv/bin/python

# 2. 安装依赖
source .venv/bin/activate
pip install fastapi uvicorn

# 3. 查看错误日志
cat .server.log

# 4. 检查端口占用
lsof -i :8756
```

### 服务无法停止？
```bash
# 手动终止
ps aux | grep uvicorn
kill -9 <PID>
rm -f .server.pid
```

## 🎯 典型工作流

### 日常使用
```bash
# 早上开始工作
./run.sh

# 查看状态
./run.sh status

# 需要重启时
./run.sh restart

# 查看日志
./run.sh logs

# 晚上结束工作
./run.sh stop
```

### 开发调试
```bash
# 启动服务
./run.sh

# 修改代码后重启
./run.sh restart

# 查看日志
./run.sh logs

# 测试完成后停止
./run.sh stop
```
