# 知行成长 · 个人学习与成长平台

平台名称统一为“知行成长”，副标题为“个人学习与成长平台”。应用位于 `知行成长/`；原 `学习仪表盘/` 仅作兼容链接。课程继续按工作区内各学习模块保存，具体路径与命名见 [内容生成与存储规则](内容存储规则.md)。

学习副驾驶复用原有服务、数据库和页面，进入“学习 → 课程管理”即可使用。当前仅接入“每日认知与通识学习”。已有打卡、复盘同步、知识扫描和周报保持原入口。

## 创建新的学习计划

进入 **学习 → 学习计划 → 创建学习计划**，填写方向、目标、基础、周期、每周次数和每次时间。

1. 可选择“让AI生成规划草稿”，也可“手动编写规划”。AI不可用时手动规划和本地阅读仍可用。
2. 编辑阶段、逐课目标、练习、自查与先修，保存草稿并预览，核对后采用。复盘占用规划内课时；多个计划共用每周总预算，旧模块时间可手动登记。
3. 在计划详情“准备本课资料”中录入实际核验过的来源和原创摘要，再“生成下一课草稿”。本阶段不会自动上网找资料。
4. 课程预览确认保存后，进入“今日”和“我的课程”。读完后由本人确认完成，阅读时间不自动转换成掌握程度。
5. “调整后续规划”支持选择反馈后AI起草，或手动修改。已发布课次冻结，新版本只调整未发布部分。检测到外部规划修改时，先核对并手动导入，原文保留在规划历史中。

新计划存入工作区 `学习计划/plan-YYYYMMDD-NNN/`。显示名称可修改，编号和目录不变；旧模块保持原目录。创建计划不自动创建定时任务，每天10:00的原认知任务保持原安排。

本次用户已授权在项目虚拟环境安装 `httpx 0.28.1`，版本记录在 `requirements-ai.txt`；启动脚本不会自动安装依赖。AI配置复用现有设置页面和服务端环境变量，页面配置优先。请在自己的设置页面输入密钥，不将密钥写入课程、规划或提交到仓库。

AI流式接口使用OpenAI兼容协议，要求HTTPS完整 `chat/completions` 地址，不自动跳转或重试。适配器按照[提供方流式输出说明](https://www.alibabacloud.com/help/en/model-studio/stream)处理内容、结束信号与用量。模型必须支持该协议；其他提供方兼容性需实测。取消会关闭本地连接，但不承诺提供方尚未完成的处理立即停止或不计费。用量或价格缺失时显示未知。

请由本人重启已有本地服务加载新增入口；本次没有自动重启服务或修改真实数据库。首次启动会增量建表并保存迁移前快照，现有页面改动、课程和反馈保留。

### 新计划备份与恢复

“学习计划 → 完整学习备份”前，先停止旧自动任务和其他编辑器写入，再明确确认。备份包含支持的学习模块资料、版本、反馈、草稿、发布日志及整份平台数据库，保存于 `server/.plans/backups/`；备份副本会移除现有设置表中的API密钥，恢复后可能需要重新配置。原课程管理的单模块备份和旧JSON导出不等同于此完整备份。

正式恢复只在停止服务和所有外部写入后进行。在 `知行成长/server` 目录先预览：

```sh
../.venv/bin/python -m plans.backup /完整备份目录
```

核对整库影响后再确认：

```sh
../.venv/bin/python -m plans.backup /完整备份目录 --confirm-token 预览返回的标识 --writers-stopped
```

恢复前会保留当前完整快照。出现 `.plans/restore-pending.json` 时服务会阻止启动/继续请求，应先核对日志中的恢复前备份和目标，不直接删除日志继续写入。课程发布中断可使用“检查未完成保存”；遇到未知人工改动会停止恢复，不自动覆盖。

### 验证与回退

新增计划使用临时目录、临时SQLite和模拟模型做隔离验收；实际网络模型效果、真实费用和浏览器交互需单独验收。测试不写用户课程，不调用真实模型。

回退优先撤下新增计划入口，保留 `learning_` 表和 `学习计划/`，继续使用旧模块；不要自动删表或删文件。若恢复整库，先保存同期旧模块学习记录、待办及复盘，避免退回早期快照导致新增记录丢失。

## 今日与明日安排

首页「今日待学习」优先展示所选日期已生成且待反馈的课程，接入认知通识、英文阅读、结构化表达；可直接打开正文，之前待反馈课程单独列出。未生成新课会明确提示，不用历史课程冒充当天新课。完成状态读取现有学习记录，待办打卡不会替代学习反馈。

网页默认进入「今日」。今日和明日均可添加待办、勾选完成、编辑内容或计划日期、删除待办，并显示完成数量。日期选择器支持查看历史记录或安排未来日期。

今日复盘和明日复盘复用「复盘四问」，可新增、编辑、删除；两个入口看到的是同一份记录。明日可提前记录预期，实际结果留到当天补充。日期按浏览器本地时间计算；记录绑定具体日期，不会每天清空或自动顺延未完成事项。

待办和复盘沿用本地数据库自动保存，保存成功以页面顶部「已保存」为准，JSON 导出包含待办。待办勾选不改变课程学习完成状态。本次升级后需重启旧服务；若页面提示重启，先重启再使用。

## 主导航与阅读

- **今日**：桌面端并列展示当天学习与待办；窄屏显示当天摘要、学习内容及「新增待办」快捷入口。历史课程默认折叠，明日待办与复盘在「明日安排」中展开。
- **学习**：我的课程、学习打卡、课程管理。课程先展示正文，认知课程的生成、备份和写入帮助保留在课程管理中；「返回学习列表」保留原日期与滚动位置。
- **记录**：每日复盘、学习时长、决策日志、预测校准、个人洞察和自定义记录。
- **成长**：成长总览、知识图谱、周报。
- **设置**：手动保存、JSON 导出和重置。

主导航使用可键盘操作的按钮。复盘等弹窗自动聚焦输入、限制 Tab 焦点范围，Esc 可关闭并返回触发位置。本轮仅调整前端交互，未更改已有数据库结构与记录接口；英文和表达的网页完成反馈仍按原能力边界处理。

## 启动与依赖

使用项目现有 `.venv`，执行 `./start.sh`。启动不再安装或升级依赖；默认只监听本机 `127.0.0.1:8756`。当前实现要求 Python 3.10+，原虚拟环境为 Python 3.13。

已有环境包含 FastAPI 和 uvicorn。本次按明确授权安装了可选AI依赖httpx并接入传输适配器；真实生成仍需有效模型配置，其他本地能力不依赖该包。不得因阅读文档而自动执行付费调用。

生成配置由后端环境变量读取，启动前在本机设置，不写入前端或Git：

- `QWEN_API_KEY`：与所选地域匹配的密钥。
- `QWEN_BASE_URL`：官方OpenAI兼容的完整chat/completions接口地址，按账号地域配置。
- `QWEN_MODEL`：默认qwen-plus。
- 可选费用估算：`QWEN_PRICE_VERSION`、`QWEN_INPUT_PRICE_PER_MILLION`、`QWEN_OUTPUT_PRICE_PER_MILLION`。价格单位为元/百万token；需自行核验有效报价。未配置时费用显示未知。

不会自动加载或执行 `.env` 文件；如使用本地shell管理环境变量，请勿把密钥写入可提交文件。

## 既有课程与学习状态

首次启动会先创建增量迁移前备份，再新增 `copilot_` 表并扫描课程。第001和002课沿用现有文件名、内容和资料，不重新生成。内容缺失、重复、日期冲突会显示待修复原因，不跳过。

“已生成”仅表示有完整课程、资料和索引，“本人确认完成”只来自学习记录或本人在页面明确点击。保存课程不会增加学习完成数。原模块打卡不推断具体课次。

每次打开页面重新扫描外部生成的课程；以北京时间检查同日限制。第一轮168课结束后不生成169课或自动开启第二轮。无网络或无Key时仍可阅读已保存的正文及资料摘要、查看记录。

## 安全写入时段

现有自动课程任务尚未改为共同锁协议。正式保存、学习反馈与完整备份前，请先暂停自动课程任务和其他编辑器的写入，再点击“确认安全写入时段”。确认有效10分钟，按钮不会替你暂停任务。

代码使用 `server/.copilot/renzhi.lock` 跨进程锁。外部程序若不遵守该锁，不能保证并发安全；仅检查文件哈希不能消除竞态。未来统一写入入口需另行协调自动任务。阅读和草稿查看不需要此确认。

## 后续主题规划

首周主题直接读取已有 `每日认知与通识学习/学习规划.md`。第008课以后须补具体主题。

需要扩展时，在模块下创建 `课程主题规划.md`，保留001–007原主题并增加后续行，例如：

```markdown
# 课程主题规划

| 课次 | 主题 | 学习目标 |
|---|---|---|
| 008 | 在这里填写已确定的下一课主题 | 本课应能解释或做到什么 |
```

每行课次唯一且在1–168内；主题文件存在时作为完整主题来源，应包含所有需要生成的课次。页面“查看与确认主题”展示后再确认。文件发生变化时旧确认失效。第7课自动按周复盘要求，第28课按整合复盘要求构建上下文。

## 准备已核验资料

一期不自动检索来源。按课次在模块下准备 `备课资料/第003课.json` 等清单和专用教学摘要。这里不要放个人笔记；仅这份明确选定的摘要会发给模型。

```json
[
  {
    "title": "实际来源标题",
    "url": "https://example.org/verified-source",
    "verified_at": "2026-10-13",
    "verification": "填写实际核验方式；示例不是核验凭证",
    "claim": "该来源支持的具体观点及边界",
    "note_path": "备课资料/第003课-摘要.md"
  }
]
```

示例链接不可直接当成真实资料。必须实际核验来源，并将摘要保存至相应本地文件。程序检查字段、日期和内容完整性，不能替人证明来源真实可信。已有课程参考资料不会自动冒充下一课的核验材料。

## 草稿与正式保存

草稿生成成功后可多行编辑、预览、保存修改，再确认保存为正式课程。未完成流或已取消的片段不可直接发布。重新生成是一次新的调用，可能新增费用；已发布课程不会被新草稿覆盖。

重复保存使用同一请求标识，服务端返回原结果；文件外部修改会报告冲突。课程、资料、学习记录多文件落盘不是一个文件系统事务，因此发生错误时保留操作日志；在安全写入时段内点击“检查并恢复”。未知文件哈希会停止恢复，避免覆盖个人内容。冲突需人工对照内容解决，不能删除日志假装成功。

## 备份与恢复

“完整备份”保存模块下Markdown/JSON资料、SQLite一致性快照及校验清单，位置为 `server/.copilot/backups/`，不含密钥。备份期间检测到文件变化会失败。原有“导出JSON”仍只导出原平台数据，不是完整课程备份。

恢复必须停止平台及所有外部写入。先在 `知行成长/server` 目录预览：

```sh
../.venv/bin/python -m copilot.backup /完整备份目录
```

检查差异及数据库恢复范围后，再以返回的预览标识确认：

```sh
../.venv/bin/python -m copilot.backup /完整备份目录 --confirm-token 返回的标识 --writers-stopped
```

恢复前会备份当前状态。恢复整份数据库会同时恢复原平台记录，因此必须检查差异。若出现 `restore-pending.json`，服务API会阻止继续使用；按其中记录找到恢复前备份，核对后人工处理，不应直接删文件继续写入。只扫描Markdown无法恢复未备份的草稿和生成日志。

## 局域网模式

默认本机使用。需要手机访问时，显式设置 `COPILOT_LAN=1`、至少24字符的 `COPILOT_ACCESS_TOKEN` 以及逗号分隔的 `COPILOT_ALLOWED_HOSTS`（如本机局域网IP），再启动。页面首次API请求会要求凭证，凭证仅保留在当前页面内存中。不要将服务直接暴露到公网。

## 验证边界

本次开发默认不启动真实服务、不调用真实Qwen、不修改自动任务。隔离样本中的检查不能证明真实API质量、耗时、费用或手机浏览效果。实施进度与待验证项见 `openspec/changes/learning-copilot/tasks.md`。

## 认知阅读（2026-10-14）

进入「学习 → 认知阅读」。默认每天北京时间10:00搜集3篇，优先2篇近期精选＋1篇经典重读，中英文均可。必须保持本地服务运行；停机后只补当天，不补历史日期。「阅读偏好与来源」可更改主题、语言、数量、时间或暂停。每日搜集不调用付费模型。

「帮我找文章」在已公开列明的来源标题、摘要及经典目录内筛选，并非全网搜索；中文主题会扩展为英文关键词。近期以发表日期30天内为准，未知日期不冒充近期。热度没有证据时明确标记未核实。部分来源失败或数量不足会显示，已保存文章不重复推荐。经典种子库目前4篇，用尽后会提示不足，需要后续维护目录。

手动结果先预览，勾选保存；每日任务自动保存。资料路径为学习根目录下的 `认知阅读/每日精选/YYYY/MM/`、`认知阅读/文章资料/article-ID/`、`认知阅读/阅读笔记/` 与 `认知阅读/搜集记录/`。保存的是来源元信息、短摘要和阅读提示，默认不复制全文。英文摘要保持来源语言；点击文章里的「确认发送摘要并生成导读」才生成文章专属中文导读，可能产生费用。仅发送本篇元信息和已有摘要，不发送笔记，不声称读取过全文。

收藏、稍后阅读、本人确认读完独立记录；打开页面、保存文章和生成导读都不会标记已学习。笔记保存有文件哈希校验；外部修改冲突时先核对，不要删除恢复记录。学习计划入口的「完整学习备份」已包含认知阅读目录和数据库，恢复使用 `python -m plans.backup`，需先停止服务与外部写入。

## 生成预览与按范围调整（2026-10-14）

学习计划与课程生成使用模型流式返回、页面约1.5秒读取进度。页面显示中文状态、实际用时和已收到的完整条目；不展示猜测百分比。完整返回并校验后，仍在原生成页且页面可见时自动进入阅读预览；离开后只提示，任务不会重复调用。

预览中可直接编辑，或指定课次/字段、课程章节让AI调整。手改与AI调整建立关联子稿，原版保留；真实差异与版本历史可查看。同组草稿只能正式采用其中一份；修改正式规划请从计划详情开始新的修订。发布仍校验预算、来源、日期、文件冲突和已发布课次。跨日课程需明确确认建立新日期子稿。

默认单次规划任务总时限300秒，可通过共享配置键 `generation_total_timeout_seconds` 设置；原传输的读取超时未变。未完整结束、取消、失败的片段不能发布。新数据表和草稿关系有增量迁移前备份。回退时先暂停认知阅读日任务、停止服务、备份全量数据；只回退页面入口时保留服务端家族与哈希保护。不要用旧数据库覆盖新草稿或个人笔记。

实际验证与限制见 `openspec/changes/cognitive-reading/verification.md` 和 `openspec/changes/generation-preview-refinement/verification.md`；上方旧版本的“默认不联调”说明不代表此次交付状态。
