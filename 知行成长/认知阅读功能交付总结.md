## 使用流程

### 1. 添加自定义来源

```
认知阅读 → 阅读偏好与来源 → 内容来源管理 → 添加自定义来源
```

填写：
- 来源名称
- 订阅地址（RSS/Atom）
- 选择语言（中文/英文）
- 选择主题（可多选）

### 2. 搜集文章

```
认知阅读 → 帮我找文章 → 选择主题和语言 → 开始搜集
```

系统会：
1. 从所有来源（默认+自定义）中筛选文章
2. 自动获取完整文章内容
3. 保存到本地

### 3. 阅读文章

```
点击文章卡片 → 阅读导读与笔记
```

界面分区：
1. **完整文章内容** - 在应用内阅读完整文章
2. **内容总结** - 查看详细总结
3. **英语学习**（英文文章）- 查看词汇、语法、长难句
4. **AI导读与解读** - 查看深入分析
5. **个人笔记** - 记录自己的想法

### 4. 生成内容

- **获取完整文章** - 如果文章尚未获取，点击按钮获取
- **生成中文总结** - 点击"生成/更新中文总结"
- **生成英语学习材料** - 点击"生成/更新英语学习材料"
- **生成AI导读** - 点击"生成/更新AI导读"

所有内容都会保存到本地，可随时查看。

## 技术亮点

1. **完整的本地化** - 所有文章和内容都保存在本地，不依赖网络
2. **智能内容获取** - 自动获取完整文章，支持反爬虫机制
3. **深入的内容分析** - 基于完整文章生成详细总结、导读和学习材料
4. **灵活的来源管理** - 支持自定义添加和删除来源
5. **优雅的界面设计** - 卡片式布局，清晰的分区
6. **持久化存储** - 所有内容都有文件哈希保护，防止冲突
