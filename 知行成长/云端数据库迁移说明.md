## 使用提示

### 在家电脑
1. 学习完成后，数据自动保存到云端
2. 不需要手动 git push 数据（代码除外）

### 在公司电脑
1. 拉取最新代码：`git pull`
2. 启动服务器：`python3 app.py`
3. 打开浏览器即可看到最新数据

### 数据一致性
- 两台电脑访问同一个云端数据库
- 数据实时同步，无需手动操作
- 即使电脑离线，数据也保存在云端

## 故障排查

### 无法连接数据库
1. 检查网络连接
2. 检查 .env 文件中的 DATABASE_URL
3. 确认 Supabase 项目是否正常运行

### 数据不一致
1. 两台电脑都访问同一个数据库，理论上不会不一致
2. 如果不一致，检查是否都连接到了正确的数据库

### 服务器启动失败
1. 检查是否安装了依赖：`pip install -r requirements.txt`
2. 检查端口是否被占用：`lsof -i :8000`
3. 查看错误日志

## 备份和恢复

### 自动备份
- Supabase 提供自动备份功能
- 可以在 Supabase 控制台查看和恢复备份

### 手动备份
```bash

# 恢复数据库
psql postgresql://postgres:SHUAIge.zhixingchengzhang@db.cafdvxlzmqavmvospgvd.supabase.co:5432/postgres < backup.sql
```
