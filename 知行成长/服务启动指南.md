# 知行成长 - 服务启动指南

## 快速开始

### 一键启动（推荐）

```bash
./run.sh
```

这会启动服务并自动打开浏览器。

### 使用管理脚本

```bash
# 启动服务
./manage.sh start

# 停止服务
./manage.sh stop

# 重启服务
./manage.sh restart

# 查看状态
./manage.sh status

# 查看实时日志
./manage.sh logs
```

### 使用 Make 命令（可选）

```bash
# 启动服务
make start  # 或 make up

# 停止服务
make stop  # 或 make down

# 重启服务
make restart  # 或 make reload

# 查看状态
make status  # 或 make ps

# 查看日志
make logs  # 或 make log
```

## 启动方式对比

| 方式 | 命令 | 说明 |
|------|------|------|
| 一键启动 | `./run.sh` | 最简单，直接启动服务 |
| 管理脚本 | `./manage.sh <命令>` | 完整功能，支持所有操作 |
| Make 命令 | `make <命令>` | 快捷方式，适合习惯 make 的用户 |
| 传统方式 | `./start.sh` | 向后兼容，实际调用 manage.sh |

## 服务信息

- **默认地址**: http://localhost:8756
- **默认端口**: 8756
- **PID 文件**: `.server.pid`
- **日志文件**: `.server.log`

## 自定义配置

### 修改端口

```bash
PORT=9000 ./manage.sh start
# 或
PORT=9000 ./run.sh start
```

### 局域网模式

允许其他设备访问服务：

```bash
export COPILOT_LAN=1
export COPILOT_ACCESS_TOKEN="your-secure-token-at-least-24-chars"
export COPILOT_ALLOWED_HOSTS="192.168.1.100,192.168.1.101"

./manage.sh start
```

## 故障排查

### 服务无法启动

1. **检查虚拟环境**
   ```bash
   ls -la .venv/bin/python
   ```

2. **检查依赖**
   ```bash
   source .venv/bin/activate
   pip install fastapi uvicorn
   pip install -r requirements-ai.txt
   ```

3. **查看错误日志**
   ```bash
   cat .server.log
   ```

4. **检查端口占用**
   ```bash
   lsof -i :8756
   ```

### 服务无法停止

如果服务无法正常停止，可以手动终止：

```bash
# 查找进程
ps aux | grep uvicorn

# 强制终止
kill -9 <PID>

# 清理 PID 文件
rm -f .server.pid
```

### 端口被占用

修改启动端口：

```bash
PORT=9000 ./manage.sh start
```

## 后台运行

服务默认在后台运行，关闭终端不会影响服务。

如果需要在前台运行（调试用）：

```bash
cd server
../.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8756 --reload
```

## 自动启动（可选）

### macOS - 使用 launchd

创建 plist 文件：

```bash
cat > ~/Library/LaunchAgents/com.zhixingchengzhang.server.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.zhixingchengzhang.server</string>
    <key>ProgramArguments</key>
    <array>
        <string>/bin/bash</string>
        <string>/Users/hao/Documents/grow/知行成长/manage.sh</string>
        <string>start</string>
    </array>
    <key>WorkingDirectory</key>
    <string>/Users/hao/Documents/grow/知行成长</string>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
    <key>StandardOutPath</key>
    <string>/Users/hao/Documents/grow/知行成长/.server.log</string>
    <key>StandardErrorPath</key>
    <string>/Users/hao/Documents/grow/知行成长/.server.log</string>
</dict>
</plist>
EOF

# 加载服务
launchctl load ~/Library/LaunchAgents/com.zhixingchengzhang.server.plist

# 卸载服务
launchctl unload ~/Library/LaunchAgents/com.zhixingchengzhang.server.plist
```

## 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `PORT` | 服务端口 | 8756 |
| `COPILOT_LAN` | 启用局域网模式 (0/1) | 0 |
| `COPILOT_ACCESS_TOKEN` | 访问令牌 (≥24字符) | - |
| `COPILOT_ALLOWED_HOSTS` | 允许的主机 (逗号分隔) | - |
| `QWEN_API_KEY` | Qwen API 密钥 | - |
| `QWEN_BASE_URL` | Qwen API 地址 | - |
| `QWEN_MODEL` | Qwen 模型名称 | qwen-plus |
