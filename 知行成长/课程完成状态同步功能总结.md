### 1. 后端 API 改进（server/copilot/core.py）

**修改 `_scan` 方法**：
- 在读取 "学习记录.md" 文件后，同时查询 `copilot_learning_records` 数据库表
- 如果数据库中有该课程的学习记录，则标记为 "completed"
- 这样即使 Markdown 文件没有更新，数据库中的记录也会被识别

**代码逻辑**：
```python
# 先从 Markdown 文件读取状态
completed = status.startswith('已完成') or status.startswith('已学习')
lesson['learning_state'] = 'completed' if completed else 'unknown'

# 再从数据库检查（新增）
with self.conn() as c:
    db_record = c.execute('''
        SELECT completed_at, time_spent_seconds FROM copilot_learning_records
        WHERE module_id = 'renzhi' AND round_id = 1 AND lesson_no = ?
    ''', (n,)).fetchone()
    if db_record:
        lesson['learning_state'] = 'completed'
        lesson['completed_at'] = db_record['completed_at']
        lesson['time_spent_seconds'] = db_record['time_spent_seconds']
```

## 系统工作原理

### 学习状态来源

系统现在从**两个来源**读取学习完成状态：

1. **Markdown 文件**（学习记录.md）
   - 认知与通识：从表格的"学习状态"列读取
   - 英文阅读：从表格的"完成"列读取
   - 结构化表达：暂不支持课程级别的完成状态

2. **数据库**（copilot_learning_records 表）
   - 通过 UI 的"标记完成"按钮写入
   - 通过提交复盘/总结写入
   - 优先级高于 Markdown 文件

### 状态判断逻辑

```
如果 数据库中该课程有记录 → 已完成
否则如果 Markdown 文件中状态为"已完成"/"已学习" → 已完成
否则 → 未完成（unknown）
```

### 前端显示逻辑

**今日页面**（daily-learning.js）：
- 只显示 `learning_state !== 'completed'` 的课程在"待学习"区域
- 已完成的课程显示在"今日已完成"区域
- 用户可以点击"查看记录"查看学习详情

### 如何标记课程完成

#### 方法1：通过 UI 按钮（推荐）
1. 在"今日"页面找到课程
2. 点击"标记完成"按钮
3. 系统自动写入数据库并更新 Markdown 文件
