# 第四阶段：创新与发散工具

> 学习周期：2-3 周 | 目标：突破思维定式，产生有创意的解决方案
>
> 前置要求：已完成前三个阶段

---

## 阶段目标

完成本阶段后，你将能够：
1. 用设计思维 5 步法以人为本解决创新问题
2. 用 SCAMPER 7 个角度改造现有产品或方案
3. 用水平思维打破固有模式
4. 用头脑风暴规则高效产生大量创意

## 第十三课：设计思维（4天）

### 13.1 什么是设计思维

设计思维（Design Thinking）是以人为本的创新方法论，由斯坦福大学 d.school（Hasso Plattner Institute of Design）推广，IDEO 公司实践。

它不是设计师的专属——任何人都可以用设计思维解决任何领域的创新问题。

### 13.2 设计思维 5 步

```
  ┌─────────────────────────────────────────┐
  │  共情 → 定义 → 构思 → 原型 → 测试    │
  │ (Empathize)(Define)(Ideate)(Prototype)(Test)│
  └─────────────────────────────────────────┘
```

### Step 1：共情（Empathize）

**目标**：深入理解用户的需求、痛点和行为。

**核心原则**：
- 不要假设你了解用户——去真正观察和倾听
- 区分"用户说的"和"用户真正需要的"
- 关注行为和情感，不只是语言

**方法**：
- **用户访谈**：开放式问题，倾听故事
- **现场观察**：看用户实际怎么做（而非怎么说）
- **沉浸体验**：自己当一回用户
- **共情地图**：记录用户的所见、所说、所做、所感

**共情地图模板**：
```
         用户的想法和感受
              ↑
用户看到的    ← 用户 →    用户说的和做的
              ↓
         用户的痛点和收获
```

### Step 2：定义（Define）

**目标**：把共情阶段的洞察转化为明确的问题陈述。

**问题陈述模板**：
> "[用户角色] 需要 [需求]，因为 [洞察/原因]。"

**案例**：
- ❌ "我们需要改进 ATM 机"
- ✅ "忙碌的职场妈妈需要在 3 分钟内取到现金，因为她下班后还要接孩子、做饭，时间非常紧张"

**好的问题陈述**：
- 以人为本（聚焦用户需求，不是技术方案）
- 足够宽（有创新空间）
- 足够窄（可操作）

### Step 3：构思（Ideate）

**目标**：大量产生创意，不急于评判。

**核心原则**：
- 追求数量（越多越好）
- 延迟评判（不批评任何想法）
- 欢迎疯狂想法（越疯狂越好）
- 在别人想法上叠加（搭便车）

**方法**：
- **头脑风暴**（详见第 16 课）
- **最疯狂的想法**："如果不考虑限制，你会怎么做？"
- **类比思考**："其他行业是怎么解决类似问题的？"
- **逆向思考**："如何让问题更糟？"然后反转

### Step 4：原型（Prototype）

**目标**：快速、低成本地做出可体验的方案。

**核心原则**：
- **快速粗糙**——不是做成品，是为了学习和验证
- **低保真优先**——纸模型 > 精美设计
- **每个原型测试一个假设**

**原型类型**：
| 低保真 | 中保真 | 高保真 |
|--------|--------|--------|
| 纸模型 | 数字线框图 | 可交互原型 |
| 故事板 | 角色扮演 | 功能 demo |
| 乐高模型 | 简易 app | 接近成品的原型 |
| 海报/传单 | | |

**关键**：不要在一个原型上花太多时间。如果一个原型花了超过 1 小时，你可能做得太精细了。

### Step 5：测试（Test）

**目标**：让用户使用原型，收集反馈并迭代。

**测试原则**：
- 不要"推销"你的方案——观察用户的真实反应
- 让用户出声思考（"请边用边说出你的想法"）
- 关注用户做了什么，不只是说了什么
- 每次测试后立刻迭代

**测试问题模板**：
- "你觉得这个怎么样？"
- "你能完成 XX 任务吗？"
- "什么让你困惑？"
- "如果改进一个地方，你最想改什么？"

### 13.3 设计思维案例

**案例：重新设计机场等候体验**

```
Step 1 共情：
- 观察：乘客抱怨等候行李的时间太长（平均 8 分钟）
- 访谈：乘客说"等行李的时候很焦虑，不知道什么时候轮到自己"
- 洞察：问题不是等待时间长，而是"无事可做的焦虑感"

Step 2 定义：
- "焦虑的旅客需要在等行李时有事可做，因为无聊放大了等待的痛苦感"

Step 3 构思：
- 安装屏幕播放目的地旅游视频
- 设置行李实时追踪显示屏
- 提供免费的咖啡试饮
- 增加行李转盘附近的商店
- ...

Step 4 原型：
- 用纸模型模拟行李追踪屏的界面
- 用海报测试旅游视频的概念

Step 5 测试：
- 结果：行李追踪屏的反馈最好
- 迭代：在屏幕上增加"预计等待时间"
- 最终方案：安装行李追踪实时显示屏
- 效果：投诉下降 50%（等待时间没变，但焦虑感降低了）
```

### 13.4 实战练习

**练习 1：重新设计一个日常体验**
- 选一个你有切身体验的场景（如：排队、开会、做饭…）
- 完成设计思维 5 步
- 做出纸模型原型

**练习 2：帮助一个朋友解决问题**
- 找一个朋友的困扰
- 用共情方法深入理解
- 走完 5 步流程

**练习 3：改进一个产品/服务**
- 选一个你觉得不好用的产品
- 做用户观察和访谈
- 走完 5 步流程

## 第十四课：SCAMPER 法（3天）

### 14.1 什么是 SCAMPER

SCAMPER 是 7 个创意激发角度的首字母缩写，由 Alex Osborn 提出、Bob Eberle 整理。

它帮助你从 7 个固定角度审视现有产品/方案/想法，产生改进或创新方案。

### 14.2 SCAMPER 七角度详解

#### S - Substitute（替代）

**问题**：能用什么替代？换掉某一部分会怎样？

可以替代的：
- 人（换谁来做？）
- 材料（换什么材料？）
- 流程（换什么步骤？）
- 规则（换什么规则？）
- 地点（换个地方？）

**案例**：
- 麦当劳用自助点餐机替代收银员
- 素肉替代真肉
- 线上课程替代线下课堂

#### C - Combine（合并）

**问题**：能和什么合并？组合哪些元素？

可以合并的：
- 功能（多功能合一）
- 目的（一个产品满足多个目的）
- 场景（在不同场景都能用）

**案例**：
- 手机 = 电话 + 相机 + 电脑 + ...
- 沙发床 = 沙发 + 床
- 带充电宝的手机壳

#### A - Adapt（调整）

**问题**：能调整什么来适应新需求？能借鉴什么？

思路：
- 这个想法能用在别的地方吗？
- 别的领域的做法能借鉴过来吗？
- 改变一下条件会怎样？

**案例**：
- 仿生学：借鉴自然界的结构（如：魔术贴借鉴苍耳）
- 快餐模式借鉴到医疗（QuickCare 诊所）
- 游戏化（把游戏元素用到教育中）

#### M - Modify/Magnify（修改/放大）

**问题**：能改变什么属性？放大/缩小/改变形状/颜色/意义？

可以修改的：
- 大小（放大/缩小）
- 形状（改变形态）
- 颜色（改变配色）
- 声音（改变音效）
- 意义（改变定位）
- 频率（增加/减少）

**案例**：
- 放大：巨型巧克力棒（GoodToGo 大份量）
- 缩小：迷你口红、旅行装
- 改形：方形西瓜（方便运输）
- 改义：钻石从"稀有宝石"重新定位为"爱情象征"

#### P - Put to other uses（另作他用）

**问题**：还能在哪里用？谁能用？换个场景呢？

思路：
- 这个产品还能做什么？
- 能卖给不同的用户群吗？
- 能用在不同场景吗？

**案例**：
- 小苏打：从烘焙用品 → 除味剂、清洁剂
- 轮胎：废旧轮胎做成游乐场设施
- 集装箱：从运输工具 → 集装箱房屋

#### E - Eliminate（消除）

**问题**：能去掉什么？简化什么？缩减什么？

可以消除的：
- 多余的步骤
- 不必要的功能
- 冗余的材料
- 复杂的操作

**案例**：
- 无印良品：去掉品牌和包装
- 谷歌首页：去掉所有多余元素
- 廉价航空：去掉免费餐食、选座、行李

#### R - Reverse/Rearrange（反转/重排）

**问题**：能颠倒顺序吗？能重新排列吗？能倒过来做吗？

可以反转的：
- 流程顺序（先做后面的步骤？）
- 因果关系（结果变成原因？）
- 角色（用户变成提供者？）
- 布局（重新排列组件）

**案例**：
- 反转流程：先吃甜点再吃主菜（Omakase 的另一种形式）
- 反转角色：乘客自己开车（Uber 的早期版本 Lyft）
- 重排布局：超市把必需品放在最里面（让你经过更多货架）

### 14.3 SCAMPER 使用流程

**Step 1**：确定对象
- 选择一个现有的产品/方案/流程

**Step 2**：逐一应用 7 个角度
- 每个角度花 5-10 分钟
- 每个角度至少想出 3 个想法
- 不评判，先追求数量

**Step 3**：筛选和评估
- 从所有想法中选出最有潜力的 3-5 个
- 用决策矩阵或其他工具评估

**Step 4**：发展和细化
- 选出的想法进一步发展
- 考虑可行性和实施路径

### 14.4 SCAMPER 完整案例

**对象：重新设计水杯**

| 角度 | 想法 |
|------|------|
| S 替代 | 用竹纤维替代塑料；用胶囊替代杯盖 |
| C 合并 | 水杯 + 搅拌器；水杯 + 温度计；水杯 + 药盒 |
| A 调整 | 借鉴保温瓶的真空层；借鉴运动水壶的吸管 |
| M 修改 | 可折叠水杯（缩小）；方形水杯（改形，方便收纳） |
| P 另作他用 | 当花盆；当笔筒；当应急灯 |
| E 消除 | 去掉杯盖（用密封设计）；去掉颜色（透明极简） |
| R 反转 | 从底部注水；杯盖朝下放（防漏设计） |

### 14.5 实战练习

**练习 1**：用 SCAMPER 改进一个日常用品
- 选一个你每天用的东西（如：手机壳、背包、笔记本）
- 7 个角度各想至少 3 个改进方案

**练习 2**：用 SCAMPER 改进一个服务/流程
- 选一个你熟悉的服务（如：点外卖、开会、学习…）
- 7 个角度各想至少 2 个方案

**练习 3**：团队 SCAMPER
- 找 3-5 人，对一个产品做 SCAMPER
- 每人负责 1-2 个角度，然后分享汇总

## 第十五课：水平思维（3天）

### 15.1 什么是水平思维

水平思维（Lateral Thinking）由爱德华·德博诺在 1967 年提出。

与垂直思维（逻辑推理，一步步推导）不同，水平思维是通过跳跃、重组、引入随机性来打破固有思维模式。

| 垂直思维 | 水平思维 |
|---------|---------|
| 逻辑推导 | 跳跃联想 |
| 一步步来 | 可以跳步 |
| 每步必须正确 | 欢迎"错误"的尝试 |
| 分析性 | 创造性 |
| 收敛 | 发散 |
| "是什么" | "可能是什么" |

### 15.2 水平思维的核心方法

#### 方法 1：挑战假设

**步骤**：
1. 列出关于这个问题的"理所当然"的假设
2. 逐一反转每个假设
3. 思考：如果假设不成立，会怎样？

**案例**：

问题：如何改进餐厅体验？

| 假设 | 反转 | 创意 |
|------|------|------|
| 餐厅必须有菜单 | 没有菜单呢？ | Omakase（厨师决定菜单） |
| 顾客自己点餐 | 服务员帮点 | 根据你的口味推荐 |
| 餐厅只卖食物 | 餐厅卖体验 | 主题餐厅、沉浸式餐厅 |
| 顾客是来吃饭的 | 顾客是来社交的 | 增加互动环节 |

#### 方法 2：随机输入

**步骤**：
1. 明确问题
2. 随机选一个词/图/物体
3. 强制把随机物和你的问题关联
4. 从关联中产生新想法

**案例**：

问题：如何提升会议效率？

随机词：**动物园**

联想过程：
- 动物园 → 分区（食草区、猛兽区…）→ 会议也分不同"区"
  - 创意：把会议分成"信息同步区"（快速汇报）和"深度讨论区"（专项讨论）
- 动物园 → 动物有各自的活动空间 → 开会的人也需要不同空间
  - 创意：设置"安静工作区"和"讨论区"，需要讨论时去讨论区
- 动物园 → 门票、导览 → 会议也需要"入场规则"
  - 创意：会议必须有明确的"入园须知"（议程和目标）

#### 方法 3：概念扇（Concept Fan）

从大概念逐步细化到具体方案：

```
大方向（Direction）
  └── 概念（Concept）
        └── 具体想法（Idea）
              └── 实施方案
```

**案例**：

问题：如何减少交通拥堵？

```
方向：减少路上的车辆数
  概念 1：让人们少开车
    想法：弹性工作制
    想法：远程办公
    想法：拼车激励
  概念 2：让每次出行更高效
    想法：智能信号灯
    想法：实时路况导航
  概念 3：提供替代方案
    想法：更多地铁线路
    想法：共享单车

方向：提高道路容量
  概念 1：扩建道路
    想法：增加车道
  概念 2：更高效利用现有道路
    想法：可变车道
    想法：错峰出行
```

#### 方法 4：随机挑战

给自己设定限制，迫使思维跳出常规：

- "如果只能用一半的预算？"
- "如果时间只有 1/3？"
- "如果没有互联网？"
- "如果是 5 岁小孩来解决这个问题？"
- "如果完全反过来做？"

### 15.3 水平思维 vs 垂直思维

两种思维不是对立的，而是互补的：

- **水平思维**产生新方向和可能性
- **垂直思维**把可能性变成可行方案

最佳实践：
1. 先用水平思维打开思路
2. 再用垂直思维深入执行

### 15.4 实战练习

**练习 1：挑战假设**
- 选一个问题
- 列出 5 个关于这个问题的"理所当然"的假设
- 逐一反转，每个反转产生至少 1 个创意

**练习 2：随机输入**
- 选一个问题
- 随机翻开字典/书，选一个词
- 强制关联，产生 5 个创意

**练习 3：概念扇**
- 选一个大问题
- 画出概念扇（至少 2 个大方向、每个方向 3 个概念、每个概念 2 个想法）

## 第十六课：头脑风暴（2天）

### 16.1 什么是头脑风暴

头脑风暴（Brainstorming）由 Alex Osborn 在 1953 年提出，是一种通过群体讨论产生大量创意的方法。

### 16.2 经典规则（OSBORN 规则）

1. **延迟评判**（Deferred Judgment）
   - 想的时候不评判，评判的时候不想
   - "没有坏主意"

2. **追求数量**（Quantity over Quality）
   - 越多越好
   - 量变引起质变

3. **欢迎疯狂想法**（Wild Ideas Welcome）
   - 越疯狂越好
   - 疯狂的想法更容易拉回现实，但现实的想法很难变得疯狂

4. **搭便车**（Build on Others' Ideas）
   - 在别人想法基础上叠加
   - "是的，而且..."

### 16.3 头脑风暴流程

**准备阶段**：
- 明确问题（提前通知参与者）
- 5-12 人为宜
- 准备白板/便签
- 选一位主持人

**执行阶段**（30-60 分钟）：
1. 主持人说明规则和主题（5 分钟）
2. 热身：一个简单的创意练习（5 分钟）
3. 自由发想（20-40 分钟）
   - 每人说出想法，主持人写在白板上
   - 追求数量，不评判
4. 整理和分类（5-10 分钟）
5. 投票选出最有潜力的想法

**后续阶段**：
- 评估选出的想法
- 发展成可行方案
- 制定行动计划

### 16.4 头脑风暴变体

| 变体 | 特点 | 适用场景 |
|------|------|---------|
| 经典头脑风暴 | 口头说出想法 | 小团队、开放话题 |
| Brainwriting | 各自写下想法，再分享 | 内向团队、避免从众 |
| Round Robin | 轮流发言 | 确保每人参与 |
| 逆向头脑风暴 | 先想"如何让问题更糟"，再反转 | 发现隐含假设 |
| 6-3-5 | 6 人、3 个想法、5 分钟 | 结构化高效 |
| SCAMPER 头脑风暴 | 用 SCAMPER 7 角度引导 | 产品改进 |

#### 6-3-5 方法详解

1. 6 个人围坐
2. 每人一张纸，写下 3 个想法（5 分钟）
3. 把纸传给右边的人
4. 在别人的想法基础上再加 3 个想法（5 分钟）
5. 重复，直到纸回到原主人
6. 总共 6 轮 × 6 人 × 3 个想法 = 108 个想法

### 16.5 常见问题

**Q：想法太少怎么办？**
A：换一种变体（如 Brainwriting），或用 SCAMPER 引导。

**Q：想法太保守/太常规？**
A：加入"最疯狂想法"环节，强制至少 5 个疯狂想法。

**Q：被少数人主导？**
A：用 Brainwriting 或 Round Robin，确保每人都有发言机会。

**Q：讨论跑偏？**
A：主持人的职责——温和地把讨论拉回主题。

### 16.6 实战练习

**练习 1：个人头脑风暴**
- 选一个主题
- 设定 5 分钟计时
- 目标：写出 20 个想法
- 不评判，追求数量

**练习 2：逆向头脑风暴**
- 问题："如何让客户更满意？"
- 先想："如何让客户更不满意？"（至少 10 个）
- 逐一反转，变成解决方案

**练习 3：团队头脑风暴**
- 组织 3-5 人
- 选一个主题
- 用经典规则或 6-3-5 方法
- 目标：30 分钟 30+ 个想法
