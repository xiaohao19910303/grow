## 开始使用

### 访问应用

浏览器应该已经自动打开 http://localhost:8756

如果没有，请手动打开浏览器访问该地址。

### 测试新功能

#### 1. 查看默认来源

进入 **学习 → 认知阅读 → 阅读偏好与来源**

滚动到"内容来源管理"部分，你会看到：
- 10个默认推荐来源
- 自定义来源管理界面

#### 2. 添加自定义来源

点击"添加自定义来源"，填写：
- 来源名称：例如"我的博客"
- 订阅地址：例如 `https://example.com/feed`
- 选择语言：中文或英文
- 选择主题：可多选

#### 3. 搜集文章

返回认知阅读主页，点击"帮我找文章"：
- 可以输入关键词或留空
- 选择感兴趣的主题
- 点击"开始搜集并预览"

系统会：
1. 从所有来源中筛选文章
2. 自动获取完整文章内容
3. 保存到本地

#### 4. 阅读文章

点击文章卡片上的"阅读导读与笔记"：

界面分为几个区域：
- **完整文章内容** - 在应用内阅读完整文章
- **内容总结** - 点击"生成/更新中文总结"
- **英语学习**（英文文章）- 点击"生成/更新英语学习材料"
- **AI导读与解读** - 点击"生成/更新AI导读"
- **个人笔记** - 记录自己的想法

#### 5. 生成内容

点击相应的按钮生成：
- 详细总结（基于完整文章）
- 英语学习材料（词汇、语法、长难句）
- AI导读与解读（深入分析）

所有内容都会保存到本地文件。

## 配置AI模型（可选）

如果你想使用AI功能（生成总结、导读、英语学习材料），需要配置AI模型：

1. 进入 **设置** 页面
2. 找到AI配置部分
3. 填写：
   - `QWEN_API_KEY`：你的API密钥
   - `QWEN_BASE_URL`：API地址
   - `QWEN_MODEL`：模型名称（默认qwen-plus）

或者在启动服务前设置环境变量：
```bash
export QWEN_API_KEY="your-api-key"
export QWEN_BASE_URL="https://your-api-endpoint"
export QWEN_MODEL="qwen-plus"
./manage.sh start
```

## 故障排查

### 服务无法启动

1. 检查虚拟环境：
```bash
ls -la .venv/bin/python
```

2. 检查依赖：
```bash
source .venv/bin/activate
pip list | grep -E "fastapi|uvicorn|httpx"
```

3. 查看错误日志：
```bash
cat .server.log
```

4. 检查端口占用：
```bash
lsof -i :8756
```

### 端口被占用

修改端口：
```bash
PORT=9000 ./manage.sh start
```
