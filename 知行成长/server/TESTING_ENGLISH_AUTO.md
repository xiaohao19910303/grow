# 英语文章自动处理功能测试指南

## 测试目标
验证保存英语文章时，系统自动生成：
1. 中文详细总结
2. 英语学习材料

---

## 测试步骤

### 1. 访问系统
- 打开浏览器访问：http://localhost:8756
- 登录你的账户

### 2. 进入阅读模块
- 点击顶部导航的"阅读"标签
- 进入"今日阅读"页面

### 3. 添加英语文章
有两种方式：

**方式 A：通过"帮我找文章"搜集**
1. 点击"帮我找文章"
2. 设置语言偏好为"英文"
3. 选择感兴趣的主题（如：科技、认知、经济学）
4. 点击"开始查找"
5. 等待搜集完成
6. 选择文章并保存

**方式 B：手动添加英语文章**
1. 点击"添加文章"
2. 选择"URL 导入"
3. 输入一篇英语文章的链接（如：https://www.economist.com/ 或 https://www.nytimes.com/）
4. 语言选择"英文"
5. 点击"抓取并预览"
6. 确认后保存

### 4. 观察自动处理
保存英语文章后，系统应该**自动**：
- 创建"详细总结"任务
- 创建"英语学习"任务

### 5. 查看结果
1. 在"今日阅读"页面，找到刚保存的英语文章
2. 点击"本站阅读"
3. 查看以下标签页：
   - **总结**：应该显示 AI 生成的详细中文总结
   - **英语解析**：应该显示词汇、语法、长难句分析

### 6. 检查任务状态
- 返回"今日阅读"页面
- 展开"最近搜集与导读记录"
- 应该能看到两个新任务：
  - `summary` - 详细总结生成中/已完成
  - `english` - 英语学习材料生成中/已完成

---

## 预期结果

### ✅ 成功
- 保存英语文章后，自动创建两个后台任务
- 任务完成后，文章详情页的"总结"和"英语解析"标签有内容
- 无需手动点击"生成/更新中文总结"或"生成/更新英语学习材料"

### ❌ 失败
- 保存后没有自动创建任务
- 任务创建但失败（显示错误信息）
- 任务完成但内容为空

---

## 常见问题

### Q1: 保存后没有看到自动任务
**可能原因**：
- 文章语言不是 `en`（英文）
- 系统已经有其他任务在运行（并发限制）

**解决**：
- 检查文章的语言字段
- 等待现有任务完成后再试

### Q2: 任务失败
**可能原因**：
- AI 模型配置问题
- 网络问题
- 文章内容太短

**解决**：
- 检查 AI 配置（阅读偏好页面）
- 重试任务

### Q3: 中文文章也触发了自动处理
**不应该发生**，如果发生了请报告 bug。

## 技术细节

### 修改的文件
- `server/reading/api.py` - `save()` 函数添加了自动处理逻辑

### 代码逻辑
```python
# 保存文章时检查语言
if a.get('language') == 'en':
    # 自动创建总结任务
    reader.begin({'kind': 'summary', 'article_id': aid})
    # 自动创建英语学习任务
    reader.begin({'kind': 'english', 'article_id': aid})
```

### 文件存储
```
认知阅读/文章资料/{文章ID}/
├── 文章信息.json
├── 中文导读.md          # 基础导读（立即生成）
├── 原文.md              # 文章正文
├── 详细总结.md          # AI 详细总结（自动生成）✨
└── 英语学习.md          # 英语学习材料（自动生成）✨
```
