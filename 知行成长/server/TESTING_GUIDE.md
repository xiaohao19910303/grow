## 常见问题排查

### 问题 1：搜索框不显示
**解决**：清除浏览器缓存（Cmd+Shift+R），刷新页面

### 问题 2：搜索结果不显示
**可能原因**：
- 数据库中没有相关数据
- API 返回错误

**排查**：
1. 打开浏览器控制台，查看是否有错误
2. 切换到 Network 标签，检查 `/api/search` 请求的响应

### 问题 3：时间线视图空白
**可能原因**：
- 日期范围内没有数据
- API 调用失败

**排查**：
1. 调整日期范围（选择更大的范围）
2. 检查浏览器控制台的错误信息

### 问题 4：状态按钮不显示
**可能原因**：
- 计划数据中没有 status 字段
- plans.js 未正确加载

**排查**：
1. 检查浏览器控制台的错误
2. 确认 plans.js 已正确加载（Network 标签）
