## 🚀 快速使用

### 方式一：一键启动（推荐）

```bash
./run.sh
```

就这么简单！服务会自动启动并打开浏览器。

### 方式二：使用管理脚本

```bash
# 启动服务
./manage.sh start

# 停止服务
./manage.sh stop

# 重启服务
./manage.sh restart

# 查看状态
./manage.sh status

# 查看日志
./manage.sh logs
```

### 方式三：使用 Make 命令

```bash
make start      # 启动
make stop       # 停止
make restart    # 重启
make status     # 状态
make logs       # 日志
```

## 🎁 使用示例

### 场景1：日常开发

```bash

./run.sh status

# 修改代码后重启
./run.sh restart

```

### 场景2：自定义端口


## 🔍 故障排查

### 服务无法启动？

```bash
# 1. 检查虚拟环境
ls -la .venv/bin/python

# 2. 安装依赖
source .venv/bin/activate
pip install fastapi uvicorn

# 3. 查看错误日志
cat .server.log

# 4. 检查端口占用
lsof -i :8756
```

### 服务无法停止？

```bash
# 手动终止
ps aux | grep uvicorn
kill -9 <PID>
rm -f .server.pid
```
