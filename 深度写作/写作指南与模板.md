# 深度写作指南与模板

## 写作框架（三选一）

### 框架1：观点型（PREP 升级版）

适合：你有一个明确的观点，想论证它

```
【结论】我认为 ______。

【理由1】第一，______。
  - 依据：______
  - 例子：______

【理由2】第二，______。
  - 依据：______
  - 例子：______

【反面思考】当然，也有人会反对，他们认为 ______。
  - 但我觉得这个观点的问题在于 ______。

【重申结论】所以，我的看法是 ______。
```

---

### 框架2：分析型（问题拆解）

适合：分析一个复杂问题，不急于下结论

```
【问题】我想搞清楚：______？

【这个问题为什么重要】
因为 ______。

【我现在的理解】
我目前觉得是这样的：______。

【拆解】
这个问题可以分成几个方面来看：
1. ______
2. ______
3. ______

【我的判断】
综合来看，我倾向于认为 ______。
但这个判断还不够确定，因为 ______。

【下一步】
我还需要搞清楚 ______，才能更有把握。
```

---

### 框架3：复盘型（STAR 写作版）

适合：复盘一件你做过的事，提炼经验

```
【背景】当时的情况是 ______。
【我的任务/目标】我需要 ______。
【我做了什么】我采取了这些行动：______。
【结果】最后结果是 ______。
【反思】
  - 做得好的地方：______
  - 做得不好的地方：______
  - 下次我会怎么改进：______
【提炼出来的原则】
通过这件事，我学到了一个道理：______。
```

## 写作自检清单

写完之后，问自己这几个问题：

- [ ] 我的第一句话，读者能看懂我要说什么吗？
- [ ] 我的结论，有至少两个理由支撑吗？
- [ ] 每个理由，都有具体的依据或例子吗？
- [ ] 我有没有考虑过反面观点？
- [ ] 如果一个聪明人看了这篇文章，他会提出什么质疑？
- [ ] 写完之后，我自己有没有更清楚这个问题？
