# 深度写作：从"说清楚"到"有观点"

## 为什么要有这个模块

结构化表达训练的是"把事情有条理地说出来"——PREP、金字塔、SCQA，这些是**沟通工具**。
但"有思考的人"还需要一种更深的能力：**形成自己的观点，并写成有深度的东西。**

这两者的区别：
- **结构化表达** = 把已有的想法，有条理地说给别人听
- **深度写作** = 把模糊的思考，通过写作打磨成清晰的观点

**写作是最好的思考方式。** 很多时候你以为自己想清楚了，一写就发现逻辑漏洞——这就是"写作倒逼思考"。

## 写作不是为了发表，是为了自己

你不需要成为作家，也不需要给别人看。
写的目的只有一个：**通过写作，把你脑子里模糊的、混乱的想法，变成清晰的、有逻辑的观点。**

## 写什么？

选你最近在想的问题，任何方向都可以：
- 工作上的：这个技术选型对不对？为什么？
- 生活上的：我为什么总是拖延？怎么破？
- 投资上的：我对这个公司的判断对不对？依据是什么？
- 认知上的：最近学的一个概念，我是怎么理解的？
- 反思类的：我最近犯的一个错，根因是什么？

## 怎么写？

**频率：** 每两周 1 次，每次 30 分钟
**篇幅：** 300 - 500 字，不需要长
**框架：** 可以用结构化表达学的框架（PREP、SCQA、金字塔）

写作流程：
1. 选一个你在想的问题（1分钟）
2. 先不看任何资料，把你脑子里的想法写下来（10分钟）——不要管逻辑，先倒出来
3. 整理结构：你的结论是什么？有几个支撑论点？（10分钟）
4. 问自己：我的依据充分吗？有没有反例？（5分钟）
5. 修改润色，定稿（5分钟）

## 关键提醒

- **不要追求文采，追求想清楚。**
- 写得烂也比不写强——写得烂说明你在思考
- 写完不用给别人看，自己留着就好
- 三个月后回看你写的东西，你会发现自己的思考在进步
