# 第三阶段：决策与评估工具

> 学习周期：2-3 周 | 目标：面对多选项、多维度时，做出更理性的决策
>
> 前置要求：已完成第一、二阶段

---

## 阶段目标

完成本阶段后，你将能够：
1. 用 SWOT 全面评估一个决策对象的内外因素
2. 用决策矩阵在多个选项中做量化比较
3. 用六顶思考帽从多个角度全面审视问题
4. 用成本收益分析判断一个决定"值不值得"

## 第九课：SWOT 分析（3天）

### 9.1 什么是 SWOT

SWOT 分析是一种战略评估工具，从四个维度系统分析一个决策对象：

```
         有利因素              不利因素
       ┌──────────────┬──────────────┐
内部   │  S - Strengths │  W - Weaknesses│
       │   （优势）     │   （劣势）     │
       ├──────────────┼──────────────┤
外部   │ O - Opportunities│ T - Threats    │
       │   （机会）     │   （威胁）     │
       └──────────────┴──────────────┘
```

- **内部因素**（你可以控制的）：优势、劣势
- **外部因素**（你无法控制的）：机会、威胁

### 9.2 SWOT 各维度分析要点

#### S - Strengths（优势）

问自己：
- 我/我们擅长什么？
- 有什么独特的资源或能力？
- 别人认为我们的优势是什么？
- 我们做了什么做得比竞品好？

#### W - Weaknesses（劣势）

问自己：
- 我/我们不擅长什么？
- 缺少什么资源？
- 别人认为我们的劣势是什么？
- 什么在阻碍我们？

#### O - Opportunities（机会）

问自己：
- 有什么好的趋势或变化？
- 有什么新的需求或市场？
- 政策/技术有什么利好？
- 有什么可以利用的外部资源？

#### T - Threats（威胁）

问自己：
- 竞争对手在做什么？
- 有什么不利趋势？
- 技术变革是否对我们不利？
- 政策/法规有什么风险？

### 9.3 SWOT 进阶：策略矩阵

SWOT 不只是列出四个象限的内容，更重要的是交叉组合形成策略：

| 组合 | 策略 | 说明 |
|------|------|------|
| **SO 策略** | 增长型 | 利用优势抓住机会——全力进攻 |
| **WO 策略** | 扭转型 | 克服劣势利用机会——补齐短板 |
| **ST 策略** | 多元化 | 利用优势化解威胁——发挥优势应对 |
| **WT 策略** | 防御型 | 减少劣势规避威胁——防守或退出 |

### 9.4 SWOT 分析案例

**案例：个人职业选择——是否跳槽**

```
S（优势）                      W（劣势）
• 5 年行业经验                 • 管理经验不足
• 技术能力强                   • 英语口语较弱
• 有行业人脉                   • 对目标行业了解不深
                               
O（机会）                      T（威胁）
• 目标公司快速扩张              • 行业竞争激烈
• 行业薪资涨幅明显              • 新环境不确定性高
• 有朋友可以内推                • 现有公司可能加薪挽留
```

**策略矩阵**：
- SO：用技术能力 + 行业经验抓住目标公司的扩张机会
- WO：在入职前补齐管理知识，利用入职后的学习资源
- ST：用技术优势和人脉关系应对行业竞争
- WT：先在内部争取加薪，同时深入了解目标行业

### 9.5 SWOT 分析的常见错误

| 错误 | 改进 |
|------|------|
| 只列清单不做交叉分析 | 一定要做策略矩阵，形成行动方案 |
| 内外因素混淆 | S/W 是内部的（你能改变的），O/T 是外部的 |
| 太过笼统 | 要具体、可操作。不是"沟通能力强"，而是"有 3 次跨部门项目协调经验" |
| 只分析不决策 | SWOT 是决策辅助工具，分析完要得出结论 |

### 9.6 实战练习

**练习 1**：对自己做一次 SWOT 分析（职业规划）
**练习 2**：对一个正在考虑的项目做 SWOT 分析
**练习 3**：对一个你熟悉的公司的竞品做 SWOT 对比分析

## 第十课：决策矩阵（3天）

### 10.1 什么是决策矩阵

决策矩阵（Decision Matrix）是一种量化决策工具，帮助你在多个选项中按多个维度做系统比较。

当你面临：
- 多个选项
- 多个评估维度
- 需要综合考虑

决策矩阵就是你的最佳选择。

### 10.2 决策矩阵构建步骤

**Step 1**：列出选项和维度

| | 维度1 | 维度2 | 维度3 |
|---|---|---|---|
| 选项A | | | |
| 选项B | | | |
| 选项C | | | |

**Step 2**：给维度设定权重

权重反映每个维度对你的重要程度。所有权重之和 = 100%。

**Step 3**：对每个选项的每个维度打分（1-5 分）

**Step 4**：计算加权分数 = 分数 × 权重

**Step 5**：汇总各选项的总加权分

**Step 6**：选总分最高的选项

### 10.3 完整案例

**场景：选择工作 Offer**

你收到了 3 个 Offer，需要从 5 个维度评估：

**Step 1 & 2**：维度和权重

| 维度 | 权重 |
|------|------|
| 薪资待遇 | 30% |
| 职业发展 | 25% |
| 工作内容 | 20% |
| 公司文化 | 15% |
| 通勤距离 | 10% |

**Step 3**：打分（1-5 分）

| 维度（权重） | Offer A | Offer B | Offer C |
|-------------|---------|---------|---------|
| 薪资待遇（30%） | 5 | 3 | 4 |
| 职业发展（25%） | 3 | 5 | 4 |
| 工作内容（20%） | 4 | 4 | 3 |
| 公司文化（15%） | 3 | 4 | 5 |
| 通勤距离（10%） | 4 | 2 | 3 |

**Step 4-5**：加权计算

| 维度（权重） | Offer A | Offer B | Offer C |
|-------------|---------|---------|---------|
| 薪资待遇（30%） | 5×0.3=1.50 | 3×0.3=0.90 | 4×0.3=1.20 |
| 职业发展（25%） | 3×0.25=0.75 | 5×0.25=1.25 | 4×0.25=1.00 |
| 工作内容（20%） | 4×0.2=0.80 | 4×0.2=0.80 | 3×0.2=0.60 |
| 公司文化（15%） | 3×0.15=0.45 | 4×0.15=0.60 | 5×0.15=0.75 |
| 通勤距离（10%） | 4×0.1=0.40 | 2×0.1=0.20 | 3×0.1=0.30 |
| **总分** | **3.90** | **3.75** | **3.85** |

**结论**：Offer A 总分最高（3.90）。

### 10.4 决策矩阵的注意事项

**1. 权重的设定至关重要**
- 权重反映你的价值观和优先级
- 如果权重不同，结果可能完全不同
- 可以用 100 分分配法：把 100 分分配给各维度

**2. 打分的客观性**
- 尽量基于事实和数据打分
- 如果主观性强，可以多人分别打分再平均

**3. 敏感性分析**
- 调整权重，看结果是否变化
- 如果结果对权重变化很敏感，说明需要更慎重

**4. 定量 vs 定性**
- 决策矩阵是辅助工具，不是替代判断
- 最终决策还需要考虑直觉和情感因素

### 10.5 决策矩阵的变体

| 变体 | 特点 | 适用场景 |
|------|------|---------|
| 加权决策矩阵 | 如上所述 | 通用 |
| Pugh 矩阵 | 以某个选项为基准，其他选项与之比较 | 工程设计 |
| 网格分析 | 用 +++ / ++ / + / - 代替分数 | 快速筛选 |

### 10.6 实战练习

**练习 1**：用决策矩阵选择下一个要学习的技能
**练习 2**：用决策矩阵评估一个正在考虑的购买决策
**练习 3**：用决策矩阵评估团队项目的方案选择

## 第十一课：六顶思考帽（3天）

### 11.1 什么是六顶思考帽

六顶思考帽（Six Thinking Hats）由爱德华·德博诺在 1985 年提出，是一种"平行思维"工具。

核心理念：**与其同时考虑所有因素（导致混乱），不如在同一时间只从一个角度思考——像换帽子一样。**

### 11.2 六顶帽子的含义

| 帽子 | 颜色 | 思维模式 | 核心问题 | 关键词 |
|------|------|---------|---------|--------|
| 白帽 | ⬜ 白色 | 事实与数据 | 我们知道什么？还需要知道什么？ | 客观、中立 |
| 红帽 | 🟥 红色 | 情感与直觉 | 我的感觉是什么？别人会怎么感觉？ | 感性、直觉 |
| 黑帽 | 🟨 黑色 | 风险与批判 | 可能出什么问题？有什么风险？ | 谨慎、批判 |
| 黄帽 | 🟨 黄色 | 乐观与价值 | 好处是什么？谁受益？ | 积极、建设 |
| 绿帽 | 🟩 绿色 | 创意与可能 | 有没有其他方案？能怎么做？ | 创造、探索 |
| 蓝帽 | 🟦 蓝色 | 过程与组织 | 现在该戴哪顶帽子？下一步做什么？ | 元思维、控制 |

### 11.3 使用方式

#### 个人使用

独自决策时，依次"戴"六顶帽子：

1. 🔵 蓝帽：定义问题，确定思考顺序
2. ⬜ 白帽：列出所有已知事实和数据
3. 🟨 黄帽：思考所有好处和价值
4. ⬛ 黑帽：思考所有风险和缺点
5. 🟥 红帽：记录此刻的直觉和感受
6. 🟩 绿帽：想出其他可能的方案
7. 🔵 蓝帽：总结，做出决策

#### 团队使用

在会议中，主持人引导所有人同时戴同一顶帽子：

```
1. 🔵 蓝帽开场（2分钟）
   "今天我们要讨论是否推出新产品。"
   "思考顺序：白→黄→黑→绿→红→蓝"

2. ⬜ 白帽（5分钟）
   所有人只说事实和数据
   "目前市场规模 XX 亿""竞品有 3 个"

3. 🟨 黄帽（5分钟）
   所有人只说好处
   "可以进入新市场""利用现有技术优势"

4. ⬛ 黑帽（5分钟）
   所有人只说风险
   "资金投入大""竞品可能反击"

5. 🟩 绿帽（10分钟）
   所有人只提新方案/改进主意
   "可以先做 MVP""可以合作而非竞争"

6. 🟥 红帽（2分钟）
   每人说出此刻的直觉感受
   "我觉得可行""我还有点担心"

7. 🔵 蓝帽总结（5分钟）
   总结讨论，确定下一步行动
```

### 11.4 六顶思考帽的优势

| 传统讨论 | 六顶思考帽 |
|---------|-----------|
| 混乱——同时争论事实和感受 | 有序——同一时间只关注一个维度 |
| 对抗——每个人坚持自己立场 | 平行——所有人朝同一方向思考 |
| 低效——重复讨论 | 高效——每个维度只讨论一次 |
| 从众——少数人主导 | 平等——每个人都有发言空间 |
| 消极——习惯挑毛病 | 平衡——强制思考正面和创意 |

### 11.5 实战案例

**问题：是否要开始远程办公？**

```
🔵 蓝帽：今天讨论是否实行远程办公，顺序：白→黄→黑→绿→红→蓝

⬜ 白帽：
- 行业调研：60% 的科技公司提供远程选项
- 现有工具：已有 Slack、Zoom 等远程协作工具
- 成本：办公室月租 10 万

🟨 黄帽：
- 员工满意度会提升
- 可以招聘到异地人才
- 节省办公成本

⬛ 黑帽：
- 团队协作效率可能下降
- 新员工融入困难
- 信息安全隐患

🟩 绿帽：
- 可以混合模式（每周 2 天远程）
- 设定远程办公考核标准
- 建立虚拟茶水间增进交流

🟥 红帽：
- "我觉得可以尝试，但需要循序渐进"

🔵 蓝帽：
- 总结：好处和风险都比较明确
- 决定：先试点 3 个月，每周 2 天远程
- 下一步：制定试点方案
```

### 11.6 实战练习

**练习 1**：用六顶思考帽独自分析一个问题
- 问题："是否要换工作？"
- 按顺序戴每顶帽子，每顶帽子下写 3-5 条

**练习 2**：团队练习
- 找 3-5 个人，模拟一次六顶思考帽讨论
- 讨论一个真实问题

## 第十二课：成本收益分析（2天）

### 12.1 什么是成本收益分析

成本收益分析（Cost-Benefit Analysis, CBA）是一种评估决策"值不值得做"的方法。

核心公式：**净收益 = 总收益 - 总成本**

如果净收益 > 0，值得做。
净收益越大越好。

### 12.2 分析步骤

**Step 1**：明确决策
- 要做什么决定？

**Step 2**：列出所有成本
- 直接成本（金钱）
- 时间成本
- 精力成本
- 机会成本（做了 A 就不能做 B）
- 隐性成本（风险、压力等）

**Step 3**：列出所有收益
- 直接收益（金钱）
- 间接收益（技能提升、人脉等）
- 无形收益（满意度、幸福感等）
- 长期收益

**Step 4**：量化
- 尽量将成本和收益转化为金钱
- 难以量化的标注权重或等级

**Step 5**：计算净收益
- 简单版：净收益 = 总收益 - 总成本
- 进阶版：考虑时间价值（折现）

**Step 6**：决策
- 净收益 > 0 且最大化的选项胜出

### 12.3 实战案例

**场景：是否要读 MBA？**

**成本分析**：

| 成本项 | 金额（万元） |
|--------|------------|
| 学费 | 30 |
| 教材和学习材料 | 1 |
| 放弃工作收入（2 年） | 40 |
| 生活费增量 | 5 |
| 精力和时间投入（折算） | 5 |
| **总成本** | **81** |

**收益分析**：

| 收益项 | 金额（万元） |
|--------|------------|
| 毕业后薪资增长（5 年累计） | 60 |
| 人脉资源（折算） | 20 |
| 知识技能提升（折算） | 15 |
| 职业转型机会（折算） | 10 |
| **总收益** | **105** |

**净收益** = 105 - 81 = 24 万元

**结论**：净收益为正，从经济角度值得读。

### 12.4 进阶概念

#### 机会成本

做一件事的真正成本 = 你因此放弃的最佳替代选择

例：
- 读 MBA 的机会成本 = 不读 MBA 能赚的钱 + 能获得的经验
- 花时间 A 项目的机会成本 = 不能做 B 项目

#### 时间价值（折现）

今天的 1 万元 ≠ 3 年后的 1 万元

折现公式：未来价值 / (1 + 折现率)^年数

#### 敏感性分析

如果关键假设变化，结论是否改变？

例：如果毕业后薪资只增长 20%（而非预期的 30%），还值得吗？

### 12.5 实战练习

**练习 1**：是否要买 XX 产品？（如：洗碗机、扫地机器人）
- 列出成本（购买价、维护费、时间…）
- 列出收益（节省的时间、提升的幸福感…）
- 计算净收益

**练习 2**：是否要花 XX 时间学习某项技能？
- 列出成本（时间、金钱、精力…）
- 列出收益（薪资增长、新机会…）
- 计算净收益
