## 🎯 四大核心框架

| 框架 | 适用场景 | 口诀 |
|------|---------|------|
| **PREP** | 日常沟通、会议发言 | 结论-原因-例子-结论 |
| **金字塔原理** | 周报、方案、复杂汇报 | 一个中心，三个基本点 |
| **SCQA** | 立项、申请资源、说服 | 背景-冲突-问题-答案 |
| **STAR** | 面试、述职、复盘 | 情境-任务-行动-结果 |

## 💡 每日 15 分钟极简练习法

时间紧张时的最小练习单元：

- **5 分钟**：看一个场景（邮件/会议/汇报），分析结构
- **5 分钟**：用合适框架重新表达
- **5 分钟**：对比原版，记录改进点

## 📝 表达自检清单

### 表达前
- [ ] 我的结论是什么？

### 表达后
- [ ] 第一句话是结论吗？
- [ ] 对方追问细节了吗？
- [ ] 对方行动了吗？
