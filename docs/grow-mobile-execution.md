# Grow H5 与手机执行职责（2026-10-25 候选）

H5 制订和完善正式计划、发布课程，手机查看计划/阶段进度、执行行动、平时记录与通知。手机“接着学”当前进入 H5 来源；原生阅读、离线正文和跨端私人笔记仍是后续迭代。课程学完由来源本人明确确认，计时、勾选、笔记分别记事实。

## 连接范围

Zook canonical 候选固定 `ccb50c4ef40da87750f469a0c0e2c2a4ec3ef9a3`。保留默认关闭，只有同时启用 `LIGHTTICK_ACTIONS_ENABLED=1`、`LIGHTTICK_ACTIONS_V2_ENABLED=1` 且消费者发送 schema 2 时才可写入。Grow 沿用原有可信桥接配置及 HMAC，不把来源凭据或 App token 放入浏览器 URL。

网页登录→手机登录并生成短期连接码→H5 预览目标账户及范围→本人确认→冻结、完整 v2 预检/导入/回执核对→切换唯一行动写入方。预览后源内容变化会要求重新预览。默认旧端保持拒绝；来源有日常节奏数据时 R20 仍关闭，不能只导入部分对象后放开双写。

接管 v2 的本人确认文案包含正式计划/阶段进度只读同步。既有 v1 连接不自动扩权为 v2。记录范围的旧数据接续使用独立流程，不能以行动授权代替记录或私人学习数据授权。

## 只读计划进度

配置可公开访问且属于本 Grow 服务的 `GROW_PUBLIC_URL=https://你的域名/`。仅允许无用户名/密码、query、fragment 的 HTTPS 来源；HTTP 仅供 localhost 隔离测试。不配置就不发布手机进度，独立 H5 可继续使用。此变量也被定时阅读唤醒使用，须保持同一服务地址。

使用既有 `action_source_worker` 的 30 秒轮询，不新增另一套定时器。服务端从可信账户枚举中恢复 tenant 和 GitHub 仓库配置；只投递正式计划的 ID、名称、版本、状态、总/已发布/已学完课次、百分比及阶段汇总，不投递课程正文、笔记、反馈、凭据或 AI 建议。

payload、revision 和待确认回执持久化；丢响应重试原 payload。Zook 校验当前绑定、账户、来源版本及内容摘要；回执一致才标记 delivered。手机显示来源更新时间，来源错误不会伪造新进度。阶段分母保留未发布课次，百分比与 Grow 使用一致的舍入。

## H5 手机来源入口

- `/#plans/detail/plan-…`：正式计划详情，刷新仍恢复。
- `/#mobile/action/action-…`：在当前 Grow 账户查找已有行动，再打开其有效来源，保留行动上下文。

浏览器无 Grow 会话时按既有私有页面登录规则处理，仅保留白名单 hash 路由；不会自动兑换 App 登录态，也不会因为打开链接就完成课程。手机本机空间不需要账户，同步/连接私人数据时再引导登录。
