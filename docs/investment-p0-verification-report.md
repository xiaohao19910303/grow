### 2.2 测试 2：成本核算手算例验证

**测试内容：** 按设计文档中的手算例验证成本核算准确性

**测试数据：**
- 期初现金: 10000.00
- 第一次买入: 100 股 @ 10.00, 费用 1.00 → 支出 1001.00
- 第二次买入: 100 股 @ 12.00, 费用 1.00 → 支出 1201.00
- 卖出: 50 股 @ 13.00, 费用 1.00 → 净收入 649.00

**验证结果：**

| 指标 | 预期值 | 实际值 | 状态 |
|-----|-------|-------|------|
| 均价 | 11.01 | 11.01 | ✅ |
| 已实现净盈亏 | 98.50 | 98.50 | ✅ |
| 浮动盈亏 | 148.50 | 148.50 | ✅ |
| 期末现金 | 8447.00 | 8447.00 | ✅ |
| 净变化 | 247.00 | 247.00 | ✅ |

**计算过程：**
```
第一次买入:
  支出 = 100 × 10 + 1 = 1001.00
  成本 = 1001.00
  持仓 = 100

第二次买入:
  支出 = 100 × 12 + 1 = 1201.00
  总成本 = 1001.00 + 1201.00 = 2202.00
  总数量 = 100 + 100 = 200
  均价 = 2202.00 / 200 = 11.01

卖出:
  净收入 = 50 × 13 - 1 = 649.00
  分配成本 = 11.01 × 50 = 550.50
  已实现净盈亏 = 649.00 - 550.50 = 98.50

剩余持仓:
  数量 = 200 - 50 = 150
  成本 = 11.01 × 150 = 1651.50
  市值 = 12 × 150 = 1800.00
  浮动盈亏 = 1800.00 - 1651.50 = 148.50

现金核对:
  期末现金 = 10000.00 - 1001.00 - 1201.00 + 649.00 = 8447.00

总资产:
  总资产 = 8447.00 + 1800.00 = 10247.00
  净变化 = 10247.00 - 10000.00 = 247.00
  验证: 98.50 + 148.50 = 247.00 ✅
```

**结论：** 成本核算完全准确，移动加权平均成本计算正确，费用分摊正确，已实现与浮动盈亏分开计算正确。
