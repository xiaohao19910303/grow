# 投资研究工具使用与接入

入口：投资工作台 →「市场研究工具」。先选择投资账户；资料、方案、提醒、结果及历史版本保存在当前登录账号的私人数据库中。研究结果不修改交易账本。

## 市场筛选

填写来源并确认本人使用范围，导入 CSV、读取本人接口，或显式读取 AKShare 盘后全市场快照。CSV 表头可在页面下载；示例：

```csv
code,name,close,turnover_rate_pct,pe,pb,roe_pct,known_at
000001,合成示例,10,3,8,1,12,2026-10-28T15:00:00+08:00
600000,合成示例二,20,,12,2,,
```

最多8000只。成交量用股／份、成交额及市值用元，百分数直接填3表示3%。财务指标必须提供带时区的可知时间，不能填未来时间。字段目录见页面条件选择及 `/api/investments/research/catalog`。指标由来源提供；这里不把未知指标补零，也不把当前全市场快照当作过去的证券池。

添加最多10个条件，选择全部／任一满足、排序，执行后查看入选、排除和未知及逐条件解释。每页50条，可导出全结果。方案支持保存、载入、修改、启停、删除；历史版本保留。「加入研究并预览AI资料」先保存选定证券和来源证据，再打开已有AI预览，不自动调用模型。

AKShare 快照没有可验证的逐笔报价时间，页面标注的数据日只是最近完成交易日的参考，不能用于实时提醒。供应商完整性与许可须另行核对。

## 价格提醒

支持价格高于／低于、当日涨跌幅高于／低于，阈值、冷却、修改、停用及删除。本人接口报价示例：

```json
{"quotes":[{"code":"000001","price":"11","previous_close":"10","quoted_at":"2026-10-29T10:00:00+08:00"}]}
```

点击「从本人接口核对一次」或显式「开始网页内监控」，可选1／5／10分钟。只有新鲜、同一交易日且处于公开日历覆盖的交易时段的报价可以触发。默认时效300秒、冷却86400秒；旧报价、午休、假日或日历未知不触发。冷却及事件持久化，重复请求／多页面检查不重复产生同一冷却期事件，修改阈值不清除冷却。

「开启浏览器通知」由本人点击申请。拒绝或不支持时仍有站内触发历史。关闭页面、切换账号或修改接口配置会停止监控；这不是网页关闭后持续运行的服务。接口断流不以旧价触发，保留旧资料和历史。

## 历史与回放

CSV／本人接口支持最多10000根日线或一分钟OHLCV。AKShare 手动查询限制为日线90个自然日、分钟7个自然日；实际返回范围由供应商决定。相同查询可用已有缓存；主动刷新创建新记录。普通OHLC可以回放，不足以直接证明可成交。

回放支持播放、暂停、前后步进、速度、滑块、MA5／10／20、MACD、成交量、滚轮缩放、拖动及悬停。手机图表可横向滑动，保留可读刻度。

回测所需CSV列：

```csv
time,open_at,available_at,open,high,low,close,volume_shares,suspended,limit_up,limit_down,corporate_actions_known,adj_factor,split_ratio,cash_dividend
2026-10-19T15:00:00+08:00,2026-10-19T09:30:00+08:00,2026-10-19T15:01:00+08:00,10,11,9,10,10000,false,11,9,true,1,1,0
```

`time`为本根收盘时刻，`open_at`为开盘时刻，`available_at`为完整资料实际可知时刻。价格未复权；停牌、涨跌停、公司行动及因子必须来自历史当时资料。`cash_dividend`为每股税后现金分红，`split_ratio`为本根生效的数量倍数；非整数份额行动缺现金替代信息时不能完成回测。不能用软件默认值替代来源证据。

「历史交易日与分钟完整性」可输入独立来源的预期交易日。未填时只尝试使用当前公开日历；跨年、北京市场或日历未覆盖资料仍可回放，但不会输出完整回测。分钟回测还必须声明预期的全部收盘时间，缺根即不计算绩效，不能从残缺行情反推完整时间表。

## 策略回测

选择已保存历史，配置收盘阈值或均线交叉、现金、数量、佣金、最低费用、卖出税费、滑点、价格步长、数量步长和成交量占比。收盘生成信号，最早下一根开盘撮合；遵守股票T+1、资金、涨跌停、停牌与数量约束。当前为单证券、只做多、空仓入场和持仓退出模型；不执行用户代码，不强制期末平仓。

结果包含净值、回撤、买卖标记、所有成交及未成交原因、含费用结果、风险和交易统计；小样本或零方差指标显示未知。可指定样本外起始日和最多20组参数试验，保留全部结果，不自动选优；样本外以独立初始现金起步，不继承训练持仓。支持交易CSV、完整结果JSON及当前账户研究资料导出。来源真实性、历史股票池、规则完整性和模型假设仍需单独评估。

## AI跨域与恢复

规则选股默认浏览器直连。模型服务未开放跨域时，推荐在模型配置中显式选择「同源服务端转发」，核对发送资料并勾选本次同意。密钥只在请求内存中使用，不进草稿、检查点或数据库。部署者必须允许该模型主机；不跟随重定向、不接受内网地址，不自动换源或重发。

解析／候选调用完成后保存回执。响应丢失时，读取原转发回执并恢复已有输出，不重复调用。只有调用未完成、无可用回执时才需核对供应商状态后明确新建尝试；无法确认是否计费时不会替本人重发。

## 部署与接口

沿用现有 PostgreSQL、HTTPX／httpcore、AKShare 锁定依赖，无新增外部任务队列。参见[部署手册](deployment/standalone-web.md)及[API合同](../知行成长/docs/investment-contracts.md)。

- `INVESTMENT_AI_RELAY_HOSTS`：精确模型主机名逗号列表；默认允许代码中列出的四家目的地，可设空值禁用转发。
- `INVESTMENT_MARKET_HOSTS`：本人数据接口主机白名单，默认空。仅HTTPS、443端口、无用户名密码／query／fragment，认证用当前请求的Bearer token。
- 接口用GET返回JSON对象；市场为 `market_date/coverage/expected_count/rows`，行包含 `code/name/values/known_at`；报价为 `quotes`；历史为 `code/name/interval/price_basis/sessions/expected_bar_times/bars`。账号、来源说明、确认用途由当前页面请求绑定，接口不能覆盖。
- 接口限制8MB、30秒；AKShare独立进程90秒、单并发。请求已开始但结果未知时，相同请求身份不会再访问来源；页面提供明确新建读取入口。失败不覆盖旧资料。
- 保持单实例／单worker部署。研究表及版本由私人schema备份一并保存；20MB以内可做账户研究JSON导出，更多资料使用管理员完整备份。凭证另行安全保管，JSON不是全站灾难恢复备份。
