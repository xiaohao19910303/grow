## 4.2：本人声明的分钟路径复盘

入口：「交易簿 → 导入分时路径」，再从完整交易链进入「路径复盘」。无需券商接口或模型，支持沪深股票/ETF普通竞价的一分钟未复权UTF-8 CSV。

CSV列固定为 `start,open,high,low,close,volume,amount`。`start`须带时区并对齐分钟；每行覆盖起点包含、下一分钟起点不包含的区间。上限2000条/250KB；不能有重复/交叠、未来、午休或盘后窗口。来源、原始文本（保留结尾换行）、原始单位、转换值和哈希保存；重试幂等，错误文件另导入新快照，不覆盖旧记录。

程序仅使用实际持有期间的有效分钟，按每个时点剩余数量与移动加权成本计算，公式为：

`成交累计已实现净结果 + 剩余数量 × 分钟低/高价 − 剩余成本`

本口径MAE为不大于零的最小标记净结果，MFE为不小于零的最大标记净结果，单位元；含已记成交费用，不含分红、利息、独立账户费用或未来假设退出费用。它不是逐份收益率、成交价格承诺或可清算收益。

| 情形 | 行为 |
| --- | --- |
| 入场前或平仓后极值 | 不纳入持有路径，不能用整日日线高低替代 |
| 分批进出 | 每个有效分钟用当时剩余数量/成本及已实现结果；不把后加数量套在先前价格上 |
| 分钟内成交或截止边界 | 该分钟数量/价格路径顺序不明，不计算该段完整极值 |
| 缺分钟、日历未覆盖、期初持仓入场时点不明 | 完整MAE/MFE为空；已观察边界和缺项分开显示 |
| 未知费用/账实差异 | 不给精确净路径结果，不补零 |
| 成交价超出对应分钟范围，或单笔数量超出所声明分钟成交量 | 显示冲突，不确认净路径极值；已知真实成交净结果仍保留 |
| 截止时点 | 后续分钟和成交不混入；开放仓位明确显示 |

回放可手动拖动已覆盖分钟，显示价格、数量、成本与净结果上下界。缺段不插值，高低先后未知不推导目标/止损成交顺序。单次最多62个自然日、500笔成交；大于范围需缩小截止时间。来源仍由本人声明，`complete_declared_path`只表示该声明范围内自洽完整，**不是独立行情验证**。

这属于使用当前账本版本的事后复盘：历史路径今天导入，也不会倒填为当年已知信息。路径与账本哈希可复算，账本更正使用当前版本；不能把它当作时间点回测输入或策略收益证明。实际记录允许保留规则偏离，回放不会因此把该操作判为可执行。

## 4.4：已交付的前向观察切片

入口：「复盘与策略 → 新建前向试验 → 前向试验列表 → 事前登记并冻结」。

- 登记前填写已确认策略版本、假设、反例、停止条件、文字参数、成本假设、观察期间和样本目标。参数只作为文本，不执行脚本。
- 草稿可修改，开始后不能补成事前登记。登记冻结策略快照/参数/期间/哈希，之后不覆盖；新参数应另建未来试验。
- 自动纳入窗口内入场、匹配冻结策略版本的全部交易链，包括盈利和亏损；不只取达到目标前的赢家。其他/混合/未冻结策略另列，开放仓位、未知结果与有效事前计划数分开。单次最多核对1000条交易链，排除项也计入限制。
- 页面展示已知净结果、胜率、净期望、小样本和本人选择的额外成本压力；接口另提供Profit Factor，亏损分母为零时返回未知。成本压力是另外的假设结果，不修改实际账本费用。
- 期间未结束只能记录停止；期间结束可保留/拒绝/无法判定。结项保存本人决定与评价快照，不能覆盖失败试验。账本变化导致当前评价不同只标记差异；保存时要求评价哈希一致，避免用过期结果结项。
- 不修改策略、不扩大风险、不记模拟成交或发出交易提醒。达到样本目标或30条也不证明方法有效。

此切片是**事前登记的观察记录**，不是受控实验或自动样本外回测；目前只做额外成本敏感性，未交付参数阈值重跑、样本外撮合、优化器及失败搜索全集。因此4.4整项仍未勾选，避免把观察表单当作完整研究引擎。

## API与私有边界

| 操作 | 接口 |
| --- | --- |
| 分钟路径保存/分页/保留原文 | `POST /api/investments/paths/import`；`GET /paths?account_id=...`；`GET /paths/{id}` |
| 截至时点回放 | `GET /accounts/{account_id}/campaigns/{campaign_id}/replay?path_id=...&cutoff=...` |
| 试验草稿创建/分页/版本修改/历史 | `POST /experiments`；`GET /experiments?account_id=...`；`GET/PUT /experiments/{id}`；`GET /experiments/{id}/history` |
| 事前登记/当前评价/结项 | `POST /experiments/{id}/register`；`GET /experiments/{id}/evaluation`；`POST /experiments/{id}/finish` |

表中简写接口沿用 `/api/investments` 前缀。所有接口沿用登录租户隔离、no-store、写入标识与幂等；修改/登记/结项同时核对版本。路径列表省略原始CSV和全部分钟，试验列表省略大快照；详情和私有导出保留。新记录、版本、原文和协议已纳入原完整备份包装器的空库恢复核对。

`readiness`及`capabilities`逐项标明离线回放/前向观察可用、回测/实时/盘中提醒不可用。不存在的回测入口返回404；提供Token或打开离线页面不会偷偷开启P2整体能力，不触发付费调用。
