# 课程分层浏览验收

2026-10-26，完成“我的课程 → 课程详情 → 具体课次”的课程信息层级调整。

## 已实现

- 我的课程默认学习中，提供待学习、已学完筛选及数量；外层只有课程卡片，不再逐课展开。
- 课程详情显示目标、真实进度、当前阶段、分阶段目录与待准备课次；仅当前阶段默认展开。
- 规划调整、备课生成、认知课程管理、归档和总结收拢到课程内部；外层保留新建课程以及折叠的草稿与课程设置。
- 私人账号数据库保存首次开始时间和最近成功打开课次，刷新后可续学；成功阅读和笔记暂存均不构成学完。
- 正式规划的未发布课次计入分母；持续课程学完现有内容显示“已学至最新”；暂停、归档单独展示。
- 支持详情深链接、刷新、前后导航和原路返回。保持原笔记、行动安排、本人确认学完、归档及总结流程。
- 修复课程关联行动回归发现的行动页面顶部按钮窄屏溢出，保留溢出元素诊断断言。

## 兼容与边界

历史完成事实直接参与分类；历史未完成且没有新续学记录的课程先列为待学习，首次成功打开后进入学习中。不虚构历史开始时间。原有三个持续课程未增加“整门结束”操作。

本次增加私人 `course_learning_activity` 表，账号首次访问活动接口时幂等创建；无历史回填、无完成事实迁移。规划列表新增只读 `curriculum` 和完成日期字段。旧 `#plans/*` 路由继续可用。

详细设计与验收场景见 [OpenSpec 设计](../../../openspec/changes/course-library-hierarchy/design.md) 和 [需求](../../../openspec/changes/course-library-hierarchy/specs/course-library-hierarchy/spec.md)。
