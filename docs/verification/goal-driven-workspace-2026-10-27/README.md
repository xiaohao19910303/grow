## 运行方式

以下 DSN 仅为本次专用测试实例，实例完成后停止。复现时新建临时 PostgreSQL，使用自己的非业务端口：

```sh
TEST_POSTGRES_DSN='host=127.0.0.1 port=56487 dbname=postgres user=grow_test' RUN_GITHUB_BROWSER=1 知行成长/.venv/bin/python -B 知行成长/server/tests/run_isolated_checks.py --pattern 'test_goal_*.py'
TEST_POSTGRES_DSN='host=127.0.0.1 port=56487 dbname=postgres user=grow_test' TEST_ZOOK_WORKTREE='/Volumes/肖豪/project/Zook' RUN_GITHUB_BROWSER=1 知行成长/.venv/bin/python -B 知行成长/server/tests/run_isolated_checks.py --pattern 'test_action_*.py'
```

完整运行另需 `NODE_PATH` 指向已安装 Playwright 的临时依赖目录，并传 `--full`。本轮使用 `/tmp/grow-goals-node/node_modules`，未修改项目依赖。
