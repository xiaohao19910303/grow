## 2. 当前产品与数据口径

- 网页优先；五个主栏目为「今日、行动、学习、记录、成长」，设置提供独立配置入口。
- FastAPI + PostgreSQL + 原生HTML/JavaScript；支持邀请注册和账号隔离。本地启动也按当前PG部署路径，不将SQLite作为应用运行时。
- 正式新课程、规划与采用的阅读资料使用GitHub；个人记录、笔记、进度、草稿、任务使用PG；既有英文/表达教材保留打包只读路径。
- AI按需启用，当前浏览器按账号保存个人配置、随请求提供；无服务端密钥兜底。行动、记录、周卡等核心路径不需要调用模型。
- 不设平台每日必学、强制四问复盘、补打卡或连续天数要求；最小步骤、内容学完与实际投入分别保存。
- 服务器完整备份依赖PG一致性快照、内容版本Git bundles及原加密密钥；网页JSON与节奏导出只是局部副本。安装与恢复统一按[部署手册](../../deployment/standalone-web.md)。
