# 课程学完后的学习接续

2026-10-27，按确认的计划完成“学完 → 直接续学／建议／填写 → 规划 → 第一课草稿 → 保存学习”流程。

## 产品行为

- 课程详情的进度概览下方固定展示“下一步学什么”，本人确认学完后在阅读器展示同一面板；不弹窗、不自动调用模型。
- 认知、英文、表达、正式课程共用入口。已有未学课次优先继续；正式规划仍有课次时按规划生成；当前内容学完后可以直接生成下一课。
- 建议生成巩固、应用、进阶三个方向，每项说明目标、理由和课数，选择后可修改；也可以直接填写方向。方向是生成规划唯一必填的文字字段。
- 默认四课的自由节奏，阶段课数可选2–12，每课时长沿用来源课程；最后一课复盘。不自动创建学习日程或固定周投入。
- 接续输入暂存在本人账号，刷新可恢复；并发修改提供重新核对入口，保留当前输入并可查看云端版本。
- 新阶段采用为关联的新课程，父子详情互相跳转。可仅保存规划，也可采用后生成第一课草稿。正文仍由本人预览后保存，成功生成不算学完。
- 已采用后第一课失败，回到原课程重试第一课即可，不重复创建课程；还可以从原课程再规划另一个方向。
- 持续课程使用原生成器。已完成的正式规划可准备额外一课：预览不改进度，保存时把新增正文与目录扩展一起提交。预览明确提示课程将转为自由节奏并调整周投入统计。

## 隐私与恢复

默认只参考教学内容、正式目标、已学主题和上一课正文。私人记录需要本次明确勾选，只用于私人建议。正式规划与正文请求不携带原始笔记、答案或私人完成反馈；生成前、采用前分别说明使用与发布范围。

模型凭证仍由浏览器按请求提供，不写接续记录、任务、规划或 GitHub。模型输出作为数据验证，界面使用DOM文本节点。接续任务与记录位于当前账号 PostgreSQL schema；跨账号读取测试返回未找到。

建议任务接入生成任务中心，刷新恢复原任务，不重复调用模型；中断与取消不会自动重试。采用和发布沿用原幂等回执，响应丢失后重试返回原课程编号。课程或规划版本变化时要求重新核对。

优先沿用已确认资料与上一课正文；无资料时保留规划并提供补充入口。本次接续正文没有提供链接资料时，不能加入未经提供的引用链接。无真实联网检索或新外部依赖。

## 兼容与实现说明

新增 `/api/course-continuations`，支持上下文、暂存、建议任务、规划生成、采用、首课及规划下一课。新阶段默认自由节奏；旧规划缺少pacing时仍按周计划处理。接续记录和任务表按账号幂等加建，无历史回填或完成事实迁移。

现代云端已移除同日生成阻断，检查当前未学课次、任务和可复用草稿。旧离线归档的按日逻辑保留。认知课程的已生成草稿可明确放弃后重新生成。

后端与界面分开提交；工作区内独立进行的投资、行动工作台和其他修改不纳入本次提交。实现依据见 [OpenSpec设计](../../../openspec/changes/course-learning-continuation/design.md)。
