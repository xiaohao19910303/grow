## 四、风险与注意事项

### 4.1 精度风险

- 必须使用 Decimal（Python）和 NUMERIC（PostgreSQL）
- JavaScript 不能用二进制浮点累计资金
- ETF、场外基金精度处理复杂
- 前后复权与未复权口径需分别标注

### 4.2 AI 风险

- AI 可能事后归因，需要设计反证检查
- AI 生成的数字必须标为假设
- 建议不能直接改成交或转移资金
- 需要可追溯性（证据快照、版本）

### 4.3 数据权限风险

- Tushare 权限未核验，不能假设已有全部权限
- 历史分钟、ETF分钟、实时能力需分别核验
- 没有权限时相关入口关闭

### 4.4 合规风险

- 不提供投资建议，只做研究、计算、记录
- 模型没有下单或转账工具
- 私人数据不进入 GitHub 仓库
