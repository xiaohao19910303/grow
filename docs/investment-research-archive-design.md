# 本地研究资料库与对比分析设计

状态：2026-10-30已实现不可变目录归档及筛选／回测批次对比，PostgreSQL继续保存真值及版本。具体操作和验收见[归档交付记录](investment-research-archive-delivery-20261030.md)。本文后续的事前观察协议、模型报告语义对比及Parquet卸载仍为扩展设计。

## 推荐选择

第一阶段采用「PostgreSQL真值与索引 + 本地不可变快照归档」。数据库继续负责租户隔离、权限、批次身份、配置版本和恢复；专用目录保存可搬运、可核验的完整数据与分析产物。对比读取冻结版本，通过来源、条件及算法身份解释差异。

本机建议位置：`/Volumes/肖豪/project/grow-data/investment-research`。本轮已在本机创建并启用该私有目录（权限700），文件权限600。服务器通过独立配置`INVESTMENT_RESEARCH_ARCHIVE_ROOT`选择持久磁盘，避免把机器路径写死。目录独立于Git源码、可清理runtime和浏览器缓存；安装者配置，网页只接收记录ID，不接收任意服务器路径。

这里的「本地目录」指运行Grow服务的机器。若服务在当前Mac上，使用上述磁盘位置；若部署云端，归档位于服务器持久卷，用户电脑通过下载研究归档保存副本，网页不直接写任意客户端路径。

第一阶段使用JSON及gzip压缩JSON Lines，无新增分析引擎依赖。所有金额、数量和精确指标仍为十进制字符串，未知为null，保持既有口径。规模增长后可增加Parquet副本作列扫描加速；数据库和原始快照身份不变，不能仅凭文件格式升级改变数值精度。

## 目录与批次身份

```text
investment-research/
  <sha256(schema)前32位>/<sha256(account)前32位>/
    datasets|runs|comparisons/<sha256(object-id)>/v1/
      manifest.json
      record.json
      rows.jsonl.gz            # 数据集按类型存在
      bars.jsonl.gz            # 历史数据
      evaluations.jsonl.gz     # 完整筛选判断
      result_trades.jsonl.gz   # 回测成交
      result_equity.jsonl.gz   # 回测净值
      result_changes.jsonl.gz  # 对比差异
```

产物按任务类型存在，例如筛选没有交易文件；空文件与未知状态不能伪称已完成。行情仅保存一份数据集，筛选、模型研究、回测批次引用其ID和哈希，避免每个结果重复抄整套行情。目录ID由服务端生成，不使用姓名、证券名称或自由输入作为路径。

每个`manifest.json`包括：格式版本、记录ID、租户及投资账户身份、源数据集ID及哈希、来源说明与原始来源字段、数据日及实际抓取时间、可知时间口径、覆盖范围、实际行数／未知数、单位、币种、时区、复权口径、条件／策略／费用配置、程序算法版本、模型与提示词版本（若有）、父批次、完成状态，以及每个文件的字节数与SHA-256。账号身份保持内部opaque值，不能把登录信息、密钥、完整授权请求头或认证URL写入文件。

原始供应商返回与规范化资料分别标识，保存哪些字段必须可说明；不把规范化后的资料称为原始报文。用户自由输入和模型内容仍为不可信文本，不能成为可执行脚本、HTML或文件名。

## 写入和恢复

已有数据集／筛选／回测先完成数据库事务，归档引用已固定的ID及哈希。配置归档后，页面分别展示业务完成和归档状态：待归档、已归档、归档失败。磁盘满或权限失败不改变已完成的账本／研究结果，也不能显示归档成功。主动重试只读原记录并写相同归档，不重新访问供应商或模型。

归档使用同一文件系统内的新临时目录，逐文件写完并核验，写清单、fsync后以新目录身份发布。禁止覆盖已有归档；同一ID已有相同哈希时复用，不同哈希报冲突。读取仅接受ready清单，逐文件检查范围、尺寸和哈希；拒绝符号链接逃逸、绝对路径和`..`引用。目录权限700、文件600。发现人工编辑时标记损坏，保留现场；重新导入创建新版本。

数据库记录与文件系统没有跨系统原子事务，必须显式记录归档状态。崩溃后根据记录ID及哈希补齐状态，临时目录和无引用目录不会自动成为有效结果。清理只作用于明确的临时对象，长期研究快照默认保留，人工删除前列出引用与影响。

备份升级为一个清单对应的数据库快照和归档目录快照，含文件摘要及代码版本。恢复先校验，再进入新的空库／新目录，检查全部引用；恢复成功不自动调用模型、重取行情或开启监控。单独拷贝目录是研究数据交换，不能代替账号权限、账本和数据库完整恢复。

## 对比方式

| 对比类型 | 固定条件 | 主要输出 |
| --- | --- | --- |
| 不同日期、相同筛选方案 | 方案版本、指标口径及来源身份 | 持续入选、新增、退出、未知、覆盖变化及逐条件差异 |
| 同一数据、不同筛选参数 | 数据集哈希、程序版本 | 阈值／逻辑变化及候选变化，减少数据源变化干扰 |
| 同一历史、不同策略或成本 | 数据集、价格／时间表口径 | 交易、拒绝原因、净值、回撤、成本及全部参数试验 |
| 筛选后的后续观察 | 事前冻结候选及评估协议 | D+1／D+5等固定交易日表现、完整失败与缺数据样本 |
| 同一证据、不同模型研究 | 证据哈希及问题／发送范围 | 引用、结论、反证、资料缺口和本人批注变化 |

比较前检查schema、单位、复权、交易日、来源覆盖与可知时间。股票不在另一快照中时区分「不再满足」「来源缺失／未知」「股票池变化」，不能直接视为失败或退市。后续观察用实际交易日和当时可用数据，未到观察期或缺行情显示未知，不删除失败样本，不以未来字段回填原筛选输入。

AI用于解释确定性差异；集合、指标、收益和费用差异由程序计算并可导出。后续表现属于研究观察，不自动称为可成交收益；回测保留成交假设和资料限制。
