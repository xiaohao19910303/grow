# 阅读与反馈闭环

目标：每日在心理、科技、社会等已选主题中兼顾覆盖与随机性；读完能留下可回查的收获，逐步提升理解、判断、表达与应用能力。

## 验收

- 同等条件的文章随机选取，日任务的固定编号保证重试结果稳定；已保存文章不重复推荐。已选主题优先得到覆盖，反馈只作温和调整，仍保留探索机会。
- 每篇有可编辑的价值、难度、收获、疑问、应用行动与标签。保存成功以服务器为准；版本冲突保留输入并提示。反馈和笔记均为私人数据，不发布到 GitHub，不自动发给模型。
- 搜索覆盖标题、来源、导读、反馈及标签；可筛选有反馈的文章。读完状态与个人反馈分别记录。
- 英文文章默认打开中文导读，包含核心观点、证据边界、英文阅读提示与应用问题；原文、笔记、反馈可在站内切换。
- 新版导读沿用当前浏览器的个人模型配置，不保存 API Key 到服务端。是否打开时自动生成由阅读偏好控制；缺少配置、失败或离开页面不会清空原文、旧导读或私人输入。仅基于摘要时明确标注。
- 已生成导读可直接复用；生成不读取个人笔记与反馈，不调用无关文章。源内容按不可信资料处理，不能执行其中的指令。

## 实施顺序

1. 私人反馈保存、版本保护、检索及多样选文；验证 PostgreSQL 持久化和隐私边界。
2. 中文阅读页、规范导读生成与缓存；验证模拟模型、失败保护和密钥不落库。
3. 反馈与阅读页面集成，真实浏览器验证桌面、手机、搜索和未保存输入。
4. 部署并验证原有每日任务、数据读回和站内阅读。

## 代码和验证

沿用 FastAPI、PostgreSQL、原生 JavaScript 与现有 GitHub 正式资料存储，不新增数据库表和依赖。实现位于 `server/reading`、`server/static/reading.js`；测试使用 `unittest` 与 Chromium。例：`self._persist_article_info(article)` 在已有写锁下保留其他个人字段。

```sh
TEST_LEGACY_PG_DSN='host=127.0.0.1 dbname=postgres user=hao' PYTHONPATH=知行成长/server:知行成长/server/tests python -m unittest test_reading_growth test_daily_reading_schedule test_legacy_cloud_api -v
node --check 知行成长/server/static/reading.js
```

边界：不根据一两次反馈给人贴能力标签，不宣称读完等于掌握；不隐藏整个领域来迎合偏好；不绕过付费内容限制；不把私人反思写入公开仓库；不使用服务端旧模型 Key 作为回退。
