## 使用流程

入口：「投资工作台 → 复盘与策略 → 撮合情景验证」。不需要行情Token、AI密钥或券商凭证。

1. 在交易簿导入来源合法、单位明确的一分钟未复权路径，在今日与计划保存同一证券的日历/规则核对资料。
2. 选择路径及核对资料，填写假设决策时间、声明证据可知时间、假设现金和期望数量、固定失效价/目标价。
3. 明确填写双边佣金万分率、每笔最低佣金、卖出税万分率、单边滑点万分率、分钟成交量占比上限；费用没有默认填零，也不提供适合本人的风险比例。
4. 填写每日状态CSV及来源说明。页面自动生成日期和unknown模板，不代填历史正常状态、价格上下限或公司行动。
5. 确认这是声明假设，保存后查看撮合、费用、约束事件及剩余仓位。刷新后从「查看已存撮合情景」找回，失败和无法判定也保留。

当前路径列表取前50份、核对资料前100份，历史情景每页50条；详情显示全部假设成交和前100条约束事件，完整结果保存在私有API中。更改表单不修改已保存记录，结果中显示原始标题、阈值、现金、费用/滑点与来源哈希。

## 数据合同与时间边界

每日CSV六列为：

```csv
date,status,limit_down,limit_up,available_at,corporate_action
2026-10-27,unknown,,,,unknown
```

- `status`：normal / halted / delisted / unknown；`corporate_action`：none_declared / unknown / adjustment_required。未知价格和时点留空，不把资料缺失当正常或0。
- `available_at`需含时区，表示本人声明这些约束当时可获知的时间；晚于尝试撮合的分钟则未知。缺分钟用停牌解释时，同样核对停牌声明的可知时间，不能用后来资料跳过路径缺口。
- 参数证据可知时间晚于假设决策，保存future_information结果，不生成盈利评价。本人填写时间并不是独立验证；原路径导入时间和哈希仍保留。
- 只处理当前公开参考覆盖内、最长62天的单证券路径，状态CSV最多63日/30KB；原路径最多2000分钟。假设决策不晚于当前、不在路径结束后或开始前7天之外。
- 不把今日证券身份、幸存样本、复权因子或人工填写的早期时间冒充历史当时可知。实际交易全样本、退市覆盖和历史公司行动/复权尚未交付。

## 确定性执行约定

模型版本：`next_open_stop_first_v1`，同时进入去重指纹与保存结果。以后更改执行模型须改版本，新模型不覆盖旧结果。

| 情况 | 模型行为 |
| --- | --- |
| 入场 | 只尝试决策之后下一普通竞价分钟开盘，一次开仓，不重开；缺首个应入场分钟返回未判定，不跳到后续赢家 |
| 时间相同 | 决策时间恰好等于分钟起点，不在该分钟倒填入场；用下一普通竞价分钟 |
| 数量 | 取期望数量、现金可承受量、声明分钟容量及公开参考单笔数量上限中较小值，再按声明步长向下取整；低于最低买入数量不成交，不扩大输入数量 |
| 现金与费用 | 每笔佣金=max(最低佣金,名义金额×佣金万分率/10000)，佣金和卖出税分别四舍五入至分；佣金预算覆盖取整差异，不透支假设买入现金 |
| 滑点 | 买入按开盘×(1+滑点/10000)向上取整至价格单位，卖出按基准价×(1−滑点/10000)向下取整；价格超出该分钟高低范围不虚填成交 |
| 目标与失效 | 目标须严格穿越才尝试；失效触达可触发，但不能保证成交。同分钟双触发先按失效处理，不选有利顺序 |
| 跨日跳空 | 初次失效尝试以开盘和失效价中较低者作为滑点前基准，不按失效价保证退出 |
| T+1/声明回转间隔 | 按连续覆盖的开市日计数，不能按自然日或把ETF通称推定T+0。ETF需本人明确核对资料，纯模型对未知回转机制返回未判定 |
| 失效但被制度/流动性阻挡 | 保留退出意图，在后续允许分钟按开盘再次尝试；不因后来目标触达就改判赢家 |
| 分钟容量 | `volume_shares × participation_rate`按步长向下取整，同分钟买卖共享，不重复使用完整容量；退出容量不足可分批，最低佣金按各笔扣除 |
| 限价 | 涨停买入或跌停卖出不能证明队列成交，不撮合；不靠“价格触达”保证成交 |
| 停牌/退市/公司行动 | 声明停牌不成交；退市、公司行动未知或须调整时不捏造退出价/零价或沿用旧成本 |
| 缺持有分钟 | 不能证明及时停牌时，整体净结果为空；不插值或只保留赢家路径 |
| 未平仓 | 保留剩余数量/成本和已撮合部分净已实现，完整净结果为空；不在最后一条收盘强制结算 |
| 规则参考冲突、过期或未覆盖 | 整体结果未判定，不发布假设净收益；旧公开规则版本不会自动转为新依据 |

容量使用整分钟成交量只是事后假设的上限，不是当时可知的精确下单数量或可成交证明。此模型没有盘口队列、竞价细则、退出申报数量的全量特殊规定、市价/盘后/大宗交易等能力，不能作为真实订单模拟器。场外基金仍用独立申请/确认流程。

## 手算与失败反例

合成股票：前一交易日14:59假设买100股×10，最低佣金1元；下一交易日09:30目标11被严格穿越，假设卖100股×11、佣金1元，输入现金10000。成本1001、净卖出所得1099、完整假设净已实现98、最终假设现金10098。实际账本仍为10000且没有新增成交。

同例单边滑点为1个万分点、价格单位0.01、卖出税率10个万分点：买价10.01、卖价10.99、买卖佣金各1、卖出税1.10，净结果94.90。此处费率仅是合成测试输入，不是券商费率或个人交易建议。

同根高12/低8.5且目标11/失效9，声明可当日回转时先按失效处理；若当日不可卖，则保留退出意图。次日低开8.5且满足其他约束的反例净结果为−152，不被原失效价9限制。跌停队列、缺失分钟或资料未知时仍可能完全无法退出。

## 私有接口与恢复

- `POST /api/investments/execution-studies`：有界参数、原始每日状态CSV、本人声明；同源写标记、幂等编号、租户授权。相同输入与模型版本重复请求只保存一次。
- `GET /api/investments/execution-studies?account_id=...&page=...`：每页50条，只返回标题、状态、ID、时间，不在列表传输原始假设或撮合明细。
- `GET /api/investments/execution-studies/{id}`：取原始input/check/reference快照、路径哈希、每日状态、结果、模型版本与哈希；无覆盖修改接口。
- 所有响应no-store，新对象`execution-studies`复用通用私有对象/版本/幂等表，并已纳入私有导出与整站原生备份恢复。
- 新能力`execution_study.enabled=true`；`backtest`、`realtime`、`intraday_alerts`与P2整体继续关闭。
- 不执行AI/行情请求，不修改实际现金、持仓、成交、计划、策略、风险或行动。
