# 投资模块：离线条件演练验收

本轮继续 `investment-decision-system`，交付4.5中的独立离线演练切片及4.6对应的能力降级检查。唯一任务状态源仍为[实施清单](../openspec/changes/investment-decision-system/tasks.md)：25/32项已勾选、7项未完成。没有把演练冒充盘中服务，也没有把尚未开发的回测/样本外评估归因为只缺密钥。

## 可以使用的流程

进入「投资工作台 → 今日与计划 → 离线条件演练」。先在交易簿导入合法来源的一分钟未复权CSV，并为同一证券保存「核对日历与交易规则」资料。

选择路径和核对资料，填写分钟收盘价的大于等于/小于等于阈值、有效期间、模拟到达延迟、最长价格有效秒数，以及可选的额外检查时点。退出条件可以填写一个假设买入日，按本人声明的回转间隔和连续交易日历演练；这不是账本真实可卖数量核对。默认只记录结果，本人可选择在本页显示模拟提示数量。

保存后返回状态汇总、前100条演练时序及来源/结果哈希。完整结果保存于账号数据库，可刷新后从「查看已存演练」找回；相同输入用相同或不同请求编号重试均不重复建立记录。页面展示的是已保存输入的标题、阈值、期间和结果，不随表单修改回写历史。

## 核对顺序与边界

| 情况 | 处理 |
| --- | --- |
| 资料尚未到达 | 额外检查时点只看已到达分钟，未来收盘不可见 |
| 同分钟高点触达而收盘未达 | 不满足；本工具只判断明确声明的分钟收盘条件 |
| 延迟超过有效秒数、跨交易日、无资料 | 过期/缺失，不产生模拟提示，不补零、不插值 |
| 午休/盘前/收盘后、休市、日历缺失 | 明确标记普通竞价时段外/休市/未知 |
| 公开参考冲突、未覆盖或复核期限到期 | 冲突/未知/过期，不产生候选；不能把核对资料日期延长当作参考规则续期 |
| 状态未知/停牌声明、分钟无成交 | 不产生候选；本人声明正常也不是供应商实时状态证明 |
| 假设当日买入的T+1退出 | 未满足可卖间隔；按开市日而非自然日计数 |
| ETF回转机制 | 不从名称或代码推定；本人明确声明的假设也不成为真实可卖证明 |
| 重复触发或跌回阈值后再次触发 | 同次演练每交易日最多一次匹配；其余显示抑制。不同演练独立 |
| 到期 | 自动加入到期事件；有效期为左闭右开，不在到期时产生候选 |
| 选择本页提示 | 仅结果中展示模拟候选，系统/站外通知发送数始终为0 |
| 关闭网页 | 没有后台轮询、自动调度或通知；不承诺实时定时过期降级 |

核对资料和公开参考在当前导入时冻结，仅供声明条件的事后演练；不是历史当时可知证明。有效期内到达的完整分钟才参与，部分分钟不推导价格；额外检查时点用于演练断流，缺少主动检查时不虚构实时监控事件。资料状态、身份、限价、权限、预算、委托队列和真实可卖数量仍需独立核验。

不会解析自由文本策略/计划，不生成买卖数量、委托、成交、AI请求或行动任务，不改变策略、风险、资金与实际账本。

## API与恢复

- `POST /api/investments/condition-drills`：有界声明输入，最多62天、10个额外时点；复用已有最多2000条的分钟路径，最多2011个事件。
- `GET /api/investments/condition-drills?account_id=...&page=...`：每页50条，列表不包含逐行时序或核对资料正文。
- `GET /api/investments/condition-drills/{id}`：读取原始规则、核对资料/参考快照、路径哈希和完整结果；无覆盖修改接口。
- 写入要求登录/同源标记/幂等编号；结果与列表均 `Cache-Control: no-store`；所有对象及写入引用受租户隔离。
- 对象种类为 `condition-drills`，沿用私有通用对象、不可变版本和幂等表。完整备份恢复核对整个演练对象一致，未新增凭证存储。
- `/readiness`、`/capabilities`新增 `condition_drill.enabled=true`；`intraday_alerts`、`realtime`、`backtest`及P2整体放行继续关闭。
