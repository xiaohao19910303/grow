# 学后用：一次实践与应用反馈

更新：2026-10-30。网页负责完整规划，App负责学习、记录及一次实践；整体职责以plan主PRD为准。

已有课程阅读与行动连接均生效时，在英文或正式计划课程正文下展开「学后用 · 实践与反馈」，填写一件准备做的事情，日期可留空。确认后网页与App读取同一条Zook check行动。阅读连接本身不迁移旧行动；连接不具备条件时页面明确说明，原课程仍可学习。

实践行动完成、课程学完、实际应用结果分别保存。「记录应用结果」可写已应用／未应用／暂不确定，以及结果、依据和下一步。保存反馈不增加完成事实、时长，不自动创建下一步任务，不调用模型。结果允许失败或未知。

输入按当前账号保存在原有行动草稿机制中；不确定请求锁定表单，重试原key。成功后清理匹配草稿。POST成功但刷新失败显示已保存，不能再把旧表单当作新请求提交。并发版本冲突先核对最新行动，输入保留。

课程来源或记录引用只保存kind／ID／版本／绑定，不复制来源正文、标题或URL。查看来源会重新核验当前授权，来源变化不删除本人实践与反馈。用户明确输入的行动标题和反馈属于私人行动历史，沿用账号导出／删除范围。

当前范围依赖既有可用行动绑定。Grow新版目标工作区的扩展、周规划草案、日常节奏接管及统一登录仍按原专项处理，本轮不绕过其接管屏障，不宣称所有网页对象均已映射至原生端。


选中一条已保存的反馈后，可点「审阅下一次安排」：本人确认下一次做什么、可选日期和已有上级。表单重新核对来源、原实践版本及上级版本；只创建新的check实践，原反馈／完成不变，上级日期及目标值不重置。目标分钟不是可用容量，不将其冒充共享预算。整体阶段／预算与自动跨期Coach仍由原专项承担。

App以当前Grow地址打开`#mobile/practice/{actionId}/{feedbackId}`，网页登录后返回此上下文。已关联账号的统一会话按[会话说明](grow-unified-web-session.md)验证；不存在跨设备自动免登或规划草稿云同步的承诺。旧服务未声明能力时不显示入口。

实践提交采用持久请求专用路径，pending实际写入失败时不发送；待确认时先恢复原请求，来源后来撤回仍可重放已保存回执。明确业务冲突解除待确认但保留草稿，认证或限流不丢弃原key。页面或账号变更后的迟到列表、正文和草稿不进入当前界面。
