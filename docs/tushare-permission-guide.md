# Tushare 权限核验指南

**日期：** 2026-10-27

---

## 一、核验步骤

### 1. 登录 Tushare 账号

1. 访问 https://tushare.pro
2. 使用你的账号登录
3. 如果没有账号，需要先注册

### 2. 查看权限等级

登录后，在个人中心可以查看：
- 积分等级
- 可用接口
- 每分钟/每天调用限额

### 3. 确认需要的接口

投资工作台需要以下接口：

**基础数据：**
- `stock_basic`：股票列表
- `trade_cal`：交易日历
- `stock_company`：上市公司信息

**行情数据：**
- `daily`：日线行情（需要 120 积分）
- `adj_factor`：复权因子（需要 120 积分）
- `daily_basic`：每日指标（需要 120 积分）

**财务数据：**
- `income`：利润表（需要 120 积分）
- `balancesheet`：资产负债表（需要 120 积分）
- `cashflow`：现金流量表（需要 120 积分）
- `fina_indicator`：财务指标（需要 120 积分）

**公告数据：**
- `anns`：公告数据（需要 2000 积分）
- `major_events`：重大事件（需要 2000 积分）

**指数/板块：**
- `index_basic`：指数列表
- `index_daily`：指数日线
- `concept`：概念板块
- `concept_detail`：概念成分股

### 4. 确认限额和费用

**免费用户（120 积分）：**
- 每分钟最多 80 次请求
- 每天最多 500 次请求
- 可以使用日线、财务等基础接口

**付费用户（2000+ 积分）：**
- 更高的调用限额
- 可以使用公告、分钟线等高级接口
- 需要付费获取积分

### 5. 确认许可和合规

Tushare 数据使用需要注意：
- 仅供个人学习和研究使用
- 不得用于商业用途
- 不得大规模分发数据
- 需要遵守 Tushare 的使用条款

## 三、备选方案

如果 Tushare 权限不足或费用过高，可以考虑以下备选方案：

### 1. AKShare

**优点：**
- 完全免费
- 开源项目
- 数据源丰富

**缺点：**
- 稳定性不如 Tushare
- 数据质量参差不齐
- 可能需要维护多个数据源

**使用方式：**
```python
import akshare as ak

# 获取股票列表
stock_list = ak.stock_info_a_code_name()

# 获取日线数据
df = ak.stock_zh_a_daily(symbol="600519")
```

### 2. Baostock

**优点：**
- 免费
- 数据质量较好
- 接口稳定

**缺点：**
- 数据范围不如 Tushare
- 更新速度较慢

**使用方式：**
```python
import baostock as bs

# 登录
bs.login()

# 获取日线数据
rs = bs.query_history_k_data_plus("sh.600519",
    "date,code,open,high,low,close,volume",
    start_date='2026-01-01', end_date='2026-10-27',
    frequency="d", adjustflag="3")
```

### 3. 东方财富/新浪财经爬虫

**优点：**
- 数据实时
- 免费

**缺点：**
- 需要自己维护爬虫
- 可能违反网站使用条款
- 稳定性差

## 四、推荐方案

**推荐方案：** 优先使用 Tushare（如果有权限），备选 AKShare

**理由：**
- Tushare 数据质量高，接口稳定
- AKShare 作为免费备选方案
- 可以设计统一的数据接口，方便切换数据源
