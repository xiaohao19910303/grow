# 学习笔记：保存后找回并继续

网页进入「学习 → 学习笔记」，可直接浏览当前账号在课程中独立暂存的笔记与练习答案，不要求先学完课程，也不需要记住搜索词。

- 支持英文阅读、结构化表达、认知课程、课程规划四类笔记。
- 按最近保存时间排列，可按模块筛选，搜索笔记、答案或课程标识，每页20篇。
- 点击课程按钮回到对应阅读页，沿用现有笔记恢复、版本比较、暂存和本人确认学完流程。
- 从课程点击「返回学习笔记」后保留当前搜索、筛选和页码，并重新读取已保存版本。
- 读取失败可以重试；列表为空不表示已删除内容。空白笔记和空白答案不会生成列表卡片。

暂存笔记不代表课程完成，不增加学习分钟或行动完成事实。列表只读现有笔记表，不写GitHub，也不调用模型。

仅存在于本机且尚未同步的输入，需要回到原课程恢复；其他设备无法读取该输入。旧版课程总结和阅读文章笔记仍可使用原学习回顾、全局搜索及阅读模块，不因新增入口而迁移或删除。课程改版、撤回或来源暂时不可用时，原有笔记保持保存，打开课程仍遵守现有读取与版本核对规则。

## 接口与维护

`GET /api/study-notes?q=&kind=&page=1&page_size=20` 通过现有账号鉴权与数据库隔离。kind可省略，或为yingyu、biaoda、renzhi、plan；page至少1，page_size为1至100，q最多500字符。返回items、total、page、page_size。

列表仅返回课程引用、模块、更新时间、修订、作答数量与最多240字符的摘要；完整笔记和答案通过原单课接口读取。响应使用Cache-Control: no-store。搜索参数绑定，百分号和下划线按字面内容匹配。相同更新时间按模块和课程标识稳定排序。
