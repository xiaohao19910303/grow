# 智能学习系统首版任务清单

> v1.1 · 2026-10-24。以下均为未来实现任务，全部保持未完成；本次仅编写方案和验收场景，不创建业务代码、迁移或测试文件，不运行应用。

## 1. 接线确认与私人存储

- [ ] 1.1 核实三路课程身份、完成证据、内容版本和路由的真实读取接口，记录对应文件及不完整来源的降级行为。（SRC-01～04）
- [ ] 1.2 新增复习模块的可信身份检查和当前 schema 连接，拒绝无身份及跨账号对象；注册独立路由与同源写保护。（ISO-01）
- [ ] 1.3 实现五张业务表与迁移版本表、字段约束、索引和账号范围迁移锁；不改原学习表。（ISO-02）
- [ ] 1.4 实现操作键、规范请求哈希、原子回执与按账号查询结果的公共写入流程。（REV-03）

## 2. 已确认课程来源

- [ ] 2.1 实现认知第一轮来源适配，过滤未完成/归档记录，验证课程可读取与正文版本。（SRC-01、04）
- [ ] 2.2 实现英语/表达来源适配，使用 module_id + filename，保留真实完成时间。（SRC-01、02）
- [ ] 2.3 实现新计划来源适配，联查已发布课程与 completed 反馈，区分不同计划同课号。（SRC-01、02）
- [ ] 2.4 实现分来源分页候选、账号绑定游标和来源可用性；不遍历正文、不将缺失来源显示为全量空数据。（SRC-03、04）

## 3. 课程级复习

- [ ] 3.1 实现本人加入、唯一课程身份、首次到期和历史候选行为；同课重复加入不重置调度。（REV-01）
- [ ] 3.2 实现 sm2-course-v1 的严格整数评分、EF 舍入、独立成功次数与总次数、业务日期计算。（REV-02）
- [ ] 3.3 实现到期评分事务、事件追加、revision 冲突和稳定请求键重试，保障只推进一次。（REV-03）
- [ ] 3.4 实现 active/paused、暂停恢复、到期分页与历史读取；评分后仍可再次到期。（REV-04）
- [ ] 3.5 实现来源撤销/归档/缺失/故障的动态资格判断和正文变更后的本人重新绑定，保留旧代事件。（SRC-04、REV-04）

## 4. 前台站内提醒

- [ ] 4.1 实现默认关闭的提醒偏好、revision/key、当天免打扰至次日业务 00:00。（REM-03）
- [ ] 4.2 实现 review 分类与 review_due 规则、当天唯一键、首次领取横幅资格及持久化通知列表。（REM-01、02）
- [ ] 4.3 实现已读/关闭幂等状态、当前到期数归零隐藏、历史数量快照与来源故障时禁止新提醒。（REM-01、02）
- [ ] 4.4 实现页面可见时检查、60 秒间隔、隐藏停止与恢复检查；不引入后端定时任务，不改现有行动提醒。（REM-01、03）

## 5. 网页复习入口

- [ ] 5.1 增加复习区的候选选择、课程跳转、到期列表、评分解释、下次日期与历史；不接入强制弹窗。（REV-01、02、REM-01）
- [ ] 5.2 为评分/重新绑定/暂停保留账号范围草稿和请求键，处理冲突、未知结果及回执恢复。（REV-03、ISO-03）
- [ ] 5.3 实现登录过期与切换账号时清理旧页面状态，来源异常明确展示、旧课程入口继续可用。（SRC-04、ISO-01、03）

## 6. 隔离验收与交付证据

- [ ] 6.1 在后续获准实现及验证后，按 acceptance.md A01～A06 核验三路来源、负向证据、身份与来源故障；记录真实结果。（SRC-01～04）
- [ ] 6.2 按 A07～A14 核验首次加入、SM-2 派生数值、评分事务、并发、跨日、暂停与新版正文；记录前后状态。（REV-01～04）
- [ ] 6.3 按 A15～A19 核验前台限制、通知去重、关闭/免打扰、跨账号页面与旧行动提醒隔离。（REM-01～03）
- [ ] 6.4 按 A20～A23 核验迁移、重启回执、备份恢复、旧快照边界及无 AI 依赖；保留可复核证据。（ISO-01～04）
- [ ] 6.5 记录实际备份工具对新增表的覆盖与隔离恢复结果；核对回退后原课程/笔记/行动不变。（ISO-03）
- [ ] 6.6 人工检查页面的评分草稿、错误提示、键盘操作、关闭横幅和账号切换；与文档校验结果分别记录。
- [ ] 6.7 运行 OpenSpec 严格校验，更新发布验收记录；未执行的验证明确保留待验收，不以文档通过标记功能完成。

自动入队、学习连续性、计划完成率、AI、后台调度与外部推送均不在上述任务中。若要增加，另行更新范围并获得实现授权。
