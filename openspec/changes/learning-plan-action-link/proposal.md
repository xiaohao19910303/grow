## Why

课程完成已有回执与行动衔接，但采用整份学习规划后仍需手动建立行动，行动页也看不到规划整体／阶段进度。本轮在新目录环境收尾后补齐 C1/C3，保留已有 C2 完成合同。

## What Changes

- 采用规划时可同时关联行动，旧规划可在详情一键关联；只为已发布且未学完的课程建立未安排内容行动。
- 复用既有内容安排的校验、去重和三态边界；复用已有匹配行动，不覆盖用户的日期、暂停、编辑或执行事实。
- 已关联规划发布后续课程／更新规划后自动补齐；失败不撤销已成功的 GitHub 保存，显示可重试的部分成功状态。
- 行动页显示当前正式规划的整体与阶段进度，区分学完、已发布与行动完成；支持停止／恢复自动补入。
- 修复新目录跨仓链接，建立新根虚拟环境并核对锁定依赖；不改真实账号密钥，不绕过启动预检。

## Capabilities

### New Capabilities
- `learning-plan-action-link`: 学习规划到现有行动的幂等关联、后续补齐和阶段进度。

### Modified Capabilities
无公共合同变更；Grow私有接口增量扩展，LightTick/Zook写入保持原门禁。

## Impact

学习规划表新增账号内关联账本，规划私有API、行动安排内部复用函数、规划与行动静态界面、隔离验收和用户说明。无新增依赖、模型调用、定时任务或公共原生合同。
