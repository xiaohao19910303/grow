# 日常复盘实施清单

本清单全部待实施。设计文档和规格完整不代表功能上线；P1可独立交付，P2完成后才可宣称AI复盘流程完整。真实服务启动、模型调用及新增依赖按当时的用户授权执行，不从本次设计请求推断授权。

## 1. P1：数据基础与保存合同

- [ ] 1.1 重新核对未提交改动及复盘入口、全量同步、统计、导出、备份和外部同步调用链，确认最小文件范围，保留既有改动。
- [ ] 1.2 实现迁移前一致性备份及独立复盘表、稳定UUID和版本字段，不加入旧全量覆盖表清单。
- [ ] 1.3 实现日期、正文、可选回答的校验，以及白名单目录、固定Markdown路径、文件内容与来源标识。
- [ ] 1.4 实现创建、按版本编辑、读取历史、归档和恢复接口；验证重复保存、同日多条、日期修改及并发冲突。
- [ ] 1.5 实现数据库与Markdown发布日志、哈希检查及中断恢复，共享备份短锁；磁盘不可用或外部修改时停止覆盖。

## 2. P1：轻量记录与旧页面接入

- [ ] 2.1 实现单正文编辑界面、日期继承、可选方向提示、默认折叠的深入问题与四问；切换方向保留所有输入。
- [ ] 2.2 实现非空保存、保存中防重、服务端成功后提示、失败保留输入及离开前未保存保护；验证键盘焦点与窄屏布局。
- [ ] 2.3 将今日卡片和记录列表接入新旧记录组合，按日期显示正文摘要、实际状态与来源，空的可选字段不渲染为待补充。
- [ ] 2.4 保留历史四问阅读与编辑合同，仅调整其成功反馈以等待实际保存；不自动迁移旧文件或为旧记录开启AI。
- [ ] 2.5 更新首页、成长与周月报计数；明确旧JSON导出/清空范围，实现新复盘独立导出及归档列表。
- [ ] 2.6 验证原同步脚本不扫描新子目录；完整备份与离线恢复覆盖新表、版本和Markdown，检查发布/恢复阻断与密钥排除。

## 3. P1：验证及阶段交付

- [ ] 3.1 用临时目录和数据库覆盖一句话记录、空白拒绝、同日多条、版本冲突、重复点击、路径越界、写入中断和外部哈希改变。
- [ ] 3.2 回归旧state同步与清空不影响新记录、报告计数不包含AI尝试、旧文件不被迁移、归档可恢复、导出及整库恢复范围准确。
- [ ] 3.3 在授权下完成页面验证：默认只填一框、切换提示保留输入、失败不丢内容、刷新后读取、旧四问兼容、键盘及窄屏可操作。

## 4. P2：AI追问与整理服务

- [ ] 4.1 复用现有模型配置、传输及共享生成锁，定义独立复盘提示与结构化结果，验证0–2个追问、建议来源标签、长度和可采用状态。
- [ ] 4.2 实现发送预览快照合同；模型仅接收用户最终选定正文与回答，不扫描其他模块，不在日志输出私人内容或密钥。
- [ ] 4.3 实现持久化生成任务、幂等、取消、超时及重启中断状态；刷新只读取，失败不自动重试，无用量或价格显示未知。
- [ ] 4.4 实现回答的本地保存、整理草稿编辑/放弃/采用、输入版本与哈希检查，保留原话与历史，原文改变后标记整理依据过期。

## 5. P2：页面与边界验证

- [ ] 5.1 接入保存后的“帮我想深一点”“帮我整理”，显示模型目的地和可编辑发送预览；取消发送不调用模型，缺配置不影响本地记录。
- [ ] 5.2 实现问题跳过、回答保存、生成进度与取消、结果恢复、草稿编辑及确认采用；不自动循环追问、不强制填写三段整理。
- [ ] 5.3 用模拟模型验证删减后的上下文、输入中夹带指令、无依据归因、非法输出、无自动重试、取消/重启、旧草稿冲突及保留原始版本。
- [ ] 5.4 在明确授权下用隔离样本完成真实模型与页面联调：记录→发送预览→追问→可选回答→整理→编辑采用→重新读取；记录费用可知性与人工修正情况。
