# 知行成长：轻量日常复盘与按需 AI 辅助

## Why

当前“今日复盘”默认展开预期、结果、归因、改进四个文本框，适合分析明确事件，却让普通收获、疑问和零散想法也必须套入同一结构。需要把入口改为先记录真实经历，再由用户按需深入或请求 AI 帮助，降低开始记录的门槛并保留个人表达。

## What Changes

- 默认只有日期和一个自由记录框，写几句即可保存；“学习收获、遇到困难、决策回顾”是可选提示，不是必选分类或另一组必填表单。
- 以“想再想一步”展开可选深入问题；保留旧四问记录的原字段与阅读方式，避免强制迁移或改写。
- 支持显式选择“帮我想深一点”或“帮我整理”：发送前展示本次正文、选定回答、模型与服务地址；AI 最多提出两个具体问题，或提供可编辑整理草稿。原话保留，采用后才形成正式整理。
- 每条记录具有稳定编号、独立保存和本地 Markdown；不会因改日期、同日多条、旧平台全量保存或反复点击而覆盖其他记录。
- 同步更新今日卡片、记录列表、报告计数、导出和备份范围；保存成功必须以服务端完成为准。
- “已记录”“AI建议待确认”“已整理”表达内容状态，不代表学完、掌握或行动已经完成。

## Capabilities

### New Capabilities

- `daily-reflection-capture`：自由记录、可选提示、渐进深入、编辑保护及统一展示。
- `reflection-ai-assistance`：限定上下文的 AI 追问与整理、请求状态、明确采用及原文保留。
- `reflection-local-storage`：独立编号、版本保存、Markdown 镜像、旧数据兼容、汇总与备份边界。

### Modified Capabilities

无现有已发布主规格需要修改。已有 `learning-copilot` 与 `ai-learning-plans` 变更分别保持原范围；本变更复用已实现配置和传输能力，不借本次复盘设计补做其他阶段功能。

## Impact

预期影响 `知行成长/server/static/index.html` 的复盘入口、今日展示与记录列表，`server/app.py` 的初始化和统计/导出，以及新增 `server/reflections/`、`static/reflections.js` 与少量样式。增量表与旧 `/api/data` 全量覆盖表分离；沿用当前 FastAPI、SQLite、原生 JavaScript 和已安装 httpx，不计划增加依赖。

新正式记录拟存入 `执行复盘/日常记录/YYYY-MM/ref-<uuid>.md`，原 `执行复盘/YYYY-MM-DD.md` 和既有同步脚本的来源范围不变。目录规则在实施时再更新生效。

本次只交付设计、规格和实施清单；不修改运行功能、数据库、学习记录或自动任务，不调用真实模型。范围不包含自动心理评估、历史记录批量分析、自动创建待办、自动调整学习规划或后台主动追问。
