# 变更提案：预测校准可视化

## 日期
2026-10-15

## 提案人
CEO Review (选择性扩展)

## 问题陈述
系统已有"预测校准"功能（predictions 表），用户记录预测 + 自报概率 + 结果。但目前只展示原始数据列表，缺乏可视化分析。

用户无法直观看到：
- 我的预测准确吗？自报 80% 概率的事件，实际发生了多少？
- 我是过度自信还是过于保守？
- 哪些类型的预测我特别准/特别不准？
- 我的校准在改善吗？

没有可视化，预测校准的价值大打折扣。

## 建议方案
增加"预测校准可视化"模块，将现有 predictions 数据转化为直观的校准图表和分析。

### 核心功能
1. **校准曲线**：X 轴为自报概率（0-100%），Y 轴为实际发生率。理想校准是 45° 对角线。
2. **准确度统计**：Brier Score（均方误差）、对数损失、校准误差。
3. **置信度分布**：用户倾向于给出什么概率？（直方图）
4. **按类型分析**：不同 statement 关键词的准确率对比。
5. **时间趋势**：校准是否随时间改善？（滚动准确率）
6. **过度自信检测**：高概率（>80%）但实际未发生的事件列表。

### 数据模型
复用现有 `predictions` 表：
```sql
CREATE TABLE predictions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    date TEXT,
    statement TEXT,
    probability INTEGER,  -- 0-100
    result TEXT,          -- 'correct', 'incorrect', 'pending'
    deviation TEXT
);
```

### API 端点
- `GET /api/predictions/calibration` - 获取校准数据（分桶统计）
- `GET /api/predictions/stats` - 获取准确度统计（Brier Score 等）
- `GET /api/predictions/overconfident` - 获取过度自信事件列表
- `GET /api/predictions/trend` - 获取时间趋势（滚动准确率）

### 前端界面
1. **仪表盘"预测校准"区域**
   - 校准曲线（SVG）
   - Brier Score 大数字展示
   - 总预测数 / 准确率 / 待判定数

2. **独立"预测分析"页面**（在"预测校准"tab 内新增子视图）
   - 校准曲线（大图）
   - 置信度分布直方图
   - 过度自信事件列表
   - 时间趋势折线图
   - 按关键词分析

### 技术约束
- 单用户，纯本地 SQLite 存储
- 零外部依赖，纯前端 SVG 可视化
- 不修改现有表结构
- 复用现有 predictions 数据
- 校准曲线使用分桶统计（0-10%, 10-20%, ..., 90-100%）

## 预期收益
1. **校准直觉**：用户能看到自己的预测偏差，逐步校准直觉
2. **识别盲点**：发现哪些类型的预测特别不准
3. **追踪进步**：看到校准在改善，增强信心
4. **决策优化**：更好的概率直觉 → 更好的决策

## 不在范围内
- AI 自动判定结果（手动标记 correct/incorrect）
- 复杂的贝叶斯分析
- 多用户对比
- 预测模板/快速录入

## 验收标准
1. 仪表盘展示校准曲线和关键统计
2. 预测分析页面展示完整可视化
3. 过度自信事件可点击查看
4. 不破坏现有预测录入功能

## 依赖
- 现有 predictions 表和数据
- 需要新增 API 端点（不修改现有端点）
- 需要修改 index.html 添加可视化

## 风险评估
- **低风险**：只读分析，不修改数据
- **低风险**：纯前端可视化，不影响现有功能
- **中等风险**：校准曲线需要足够的预测数据才能有意义（<10 条时显示提示）
