# Capability Spec: behavior-tracking

## 概述

行为应用追踪系统，记录用户在真实场景中应用学习概念/工具的频率和效果，为"知行合一"提供量化度量。

## 目标

1. 低摩擦记录：在复盘流程中自然嵌入，不增加额外操作步骤
2. 可视化度量：仪表盘展示应用频率、趋势、常用概念
3. 数据完整：支持 CRUD、过滤、统计，不丢失记录
4. 零依赖：SVG inline 可视化，不引入前端 chart library

## 核心概念

### 应用记录（Application Record）

一条应用记录表示"用户在某天、在某个真实场景中、使用了某个学到的概念/工具"。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| date | TEXT | 是 | 应用日期 YYYY-MM-DD |
| module_id | TEXT | 是 | 所属模块（renzhi/xiezuo/biaoda/yingwu/siwei/fupan/zhenghe/gaorenzhi） |
| concept | TEXT | 是 | 概念/工具名称（≤100字） |
| scenario | TEXT | 否 | 应用场景简述（≤500字） |
| effectiveness | INTEGER | 否 | 效果自评 0-5（0=未评估） |

### 统计聚合（Stats）

| 指标 | 计算方式 |
|---|---|
| total | period 内记录总数 |
| by_module | 按 module_id 分组计数 |
| top_concepts | 按 concept 分组计数，Top 5 降序 |
| trend | 按 date 分组计数，每日一条（缺日补0） |

## 行为规格

### 创建记录

**触发条件：**
- 用户在复盘页点击"保存"
- 或用户在应用记录页点击"新增"

**前置条件：**
- module_id 必须在已知模块列表中
- concept 必须非空且 ≤100 字
- date 必须为有效 YYYY-MM-DD 格式

**后置条件：**
- 新记录写入 behavior_applications 表
- 返回 201 + 完整记录（含 id）
- 仪表盘统计自动更新（下次加载时）

**错误处理：**
- module_id 无效 → 400
- concept 为空 → 400
- date 格式错误 → 400

### 查询记录

**过滤参数：**
- date_from：起始日期（含）
- date_to：结束日期（含）
- module_id：模块筛选

**排序：** 按 date DESC, id DESC

**返回：** 记录数组，每条含完整字段

### 更新记录

**前置条件：**
- 记录必须存在

**行为：**
- 部分更新（只更新提供的字段）
- 返回 200 + 更新后完整记录

**错误处理：**
- 记录不存在 → 404

### 删除记录

**前置条件：**
- 记录必须存在

**行为：**
- 物理删除（不软删除）
- 返回 204

**错误处理：**
- 记录不存在 → 404

### 统计查询

**参数：**
- period：天数（默认30）

**行为：**
- 计算从今天往前 period 天的统计数据
- trend 包含每日数据，缺日补0
- top_concepts 取 Top 5

## 前端规格

### 复盘页入口

- 位置：复盘四问下方，折叠区域
- 默认折叠，点击"今天用了什么？"展开
- 表单字段：模块（下拉）、概念（文本+自动补全）、场景（文本区域）、效果（1-5星）
- 自动补全来源：已有应用记录的 distinct concept 值
- 保存后表单清空，新记录追加到下方列表

### 仪表盘区域

- 位置：成长总览 tab 下方
- 组件：
  - 本月应用次数（大数字）
  - 近30天趋势（SVG 折线图）
  - Top 5 概念（SVG 水平柱状图）
  - 按模块分布（颜色方块）
- 空状态：显示引导文案"尚无应用记录"

### 应用记录页

- 入口：主导航 → 记录 → 应用记录
- 列表：按日期倒序，每条显示日期+模块+概念+场景摘要+效果星级
- 操作：编辑（展开表单）、删除（确认弹窗）
- 筛选：模块下拉

## 测试规格

| 场景 | 验证内容 |
|---|---|
| 正常创建 | 字段完整，返回201+id |
| 无效 module_id | 返回400 |
| concept 为空 | 返回400 |
| 更新不存在记录 | 返回404 |
| 删除不存在记录 | 返回404 |
| 统计空数据 | total=0, trend 全0 |
| 统计多模块 | by_module 正确分组 |
| 统计 Top 5 | 超过5个概念时只取前5 |
| 趋势缺日补0 | 某天无记录时 count=0 |
| 无 API Key | 功能正常（纯本地） |
| 不破坏现有功能 | 打卡/复盘/扫描/周报正常 |

## 约束

- 不修改现有表
- 不引入新依赖
- 不改变现有 API 行为
- 不进入 /api/data 全量同步
- 输入长度限制：concept ≤100字, scenario ≤500字
