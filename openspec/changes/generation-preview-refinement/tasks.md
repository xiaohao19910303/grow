# 生成预览与调整实施清单

已实施并完成核心联调。设计阶段没有授权真实模型调用或发布；后续用户已明确授权两次真实模型联调及Git提交推送。实施时保留已有修改，不回退资料入口和传输配置。M1/M2可以阶段交付，M3完成后才具备完整的按范围AI调整能力。

## 1. 基线与数据合同

- [x] 1.1 核对当前生成、资料、导航、编辑、发布与备份调用链及未提交改动，确认与旧课程管理、日常复盘方案的范围边界。
- [x] 1.2 定义progress投影、服务端时间、phase、revision、首字/末次增量及deadline字段，保留原attempt状态与读取接口兼容。
- [x] 1.3 设计并增量迁移draft_family及草稿父子元数据，完成迁移前备份、旧稿兼容和正式发布目标约束。

## 2. M1：生成中的可读反馈

- [x] 2.1 实现无副作用的进度读取接口；支持按revision轻量查询，不返回不必要上下文或密钥，读取不触发模型调用。
- [x] 2.2 实现规划完整条目提取与结构校验，覆盖嵌套、转义、跨分片、字段乱序和无效结果，不补全残缺JSON。
- [x] 2.3 实现课程正文与资料的渐进安全呈现及调整目标片段投影，不把半成品开放为可发布草稿。
- [x] 2.4 实现中文状态、真实计时、无新内容提示、可取消及折叠生成详情；核对任务总时限与现有用户配置，不显示伪进度。
- [x] 2.5 实现稳定更新、上滑停止跟随与回到最新内容，保留焦点/折叠状态，避免每次重建整页。

## 3. M2：完成后默认预览

- [x] 3.1 实现独立规划阅读预览和课程阅读预览，显示投入、目录、冻结课次、正文及真实资料边界，不要求先编辑或重复保存。
- [x] 3.2 将任务观察器与页面分离，接入全站栏目离开、页面可见性和当前任务身份；只有前台原生成页自动进入预览一次。
- [x] 3.3 实现站内完成提示、任务入口、刷新/深链恢复及只读查询退避，后台结果不抢页面，不重复调用模型。
- [x] 3.4 接入直接编辑、放弃、未保存离开保护与校验失败保留；手动保存创建关联子稿，无变化不重复建立版本。
- [x] 3.5 补齐规划阶段增删、未发布课次排序及先修重校验，显示映射并保护已发布课次。
- [x] 3.6 绑定明确草稿及哈希进行采用/保存，保留预算、同日、来源、外部文件冲突检查；跨日课程通过显式确认建立新日期子稿。

## 4. M3：按范围AI调整与版本选择

- [x] 4.1 实现调整意见、基线、课次/字段/章节范围选择及发送概要；快捷意见不自动调用，未保存输入先明确处理。
- [x] 4.2 实现refine接口的父稿哈希、类型、目标和范围校验；复用任务去重、模型配置、全局并发锁、取消与费用记录。
- [x] 4.3 实现规划局部更新白名单与合并、全局条件明确修改和冻结课次检查，拒绝模型越范围更新。
- [x] 4.4 实现课程稳定章节标识、受限替换及全文重校验；无法分段时仅支持整课，关联章节不得静默扩选。
- [x] 4.5 实现草稿族分页历史、父子分支及当前选择，旧稿保持可读；新生成或手改不覆盖另一分支或正在编辑的输入。
- [x] 4.6 实现规划字段/课次与课程章节的真实差异对照，以及返回原版/继续使用新版，区分选择草稿和正式发布。
- [x] 4.7 在发布事务中约束同family初次规划仅建立一个plan、同课只保存一稿；兄弟稿发布后失效，后续修订从正式新基线开始。

## 5. 验证、文档与交付

- [x] 5.1 用隔离测试覆盖进度解析分片、完成信号、终态、取消、超时、查询失败恢复及相同请求不重复调用。
- [x] 5.2 覆盖范围外更新拒绝、受保护字段、局部合并不变性、跨分支编辑、同family并发采用、正式基线变化、资料变化及跨日发布。
- [x] 5.3 回归新旧草稿读取、旧state同步、备份恢复包含family、已有规划/课程发布与预算检查，不以新UI绕过原校验。
- [x] 5.4 在授权下完成真实页面验证：等待→渐进内容→前台自动预览；离开/后台完成只提示；手改、未保存保护、失败修复、键盘与窄屏可用。
- [x] 5.5 在明确授权下用独立测试数据进行真实模型联调：首次生成→预览→局部调整→比较→选择旧版/新版→正式保存，记录实际费用可知性及人工修正。
- [x] 5.6 更新平台说明和验收记录，标明模型流式与页面轮询的区别、覆盖范围、草稿与正式文件归属；提供保留数据与服务端保护的回退步骤，不修改自动任务。
