## Context

已实现课程卡片和三类阅读器。英文/表达使用 MaterialGenerator，正式课程使用 PlanGenerator，认知课程使用 Copilot；发布与私人学习事实分离。

## Goals / Non-Goals

完成统一接续、三种私人建议、自由填写、自由节奏关联课程和第一课生成。复用原发布/幂等回执，不自动安排日期、写入完成事实或批量生成正文。不修改投资和行动工作台独立改动。

## Decisions

- 新增私人接续服务及任务表，按课程键提供当前状态、输入恢复、建议、规划生成、采用及第一课准备。资料和版本由服务端重新读取，用户只提交选择的私人记录引用。
- 建议独立持久化后台任务，注册到 GenerationTasks。正式规划与正文沿用 PlanGenerator。AI 凭证仅存当前任务内存，不写数据库或 GitHub。
- 建议默认三方向，每项含目标、理由、2–12课数；自由填写只要求方向。默认四课、15分钟或沿用来源时长，最后一课复盘。
- `self_paced` brief 使用 lesson_count，旧 brief 不新增字段以保持比较/快照兼容。周预算排除自由节奏但返回未安排数量。正式文档、编辑和提示词均理解两种节奏。
- 下一阶段是关联新计划，父子关系只保存在私人接续记录中。采用调用原 adopt，使用稳定请求键，响应丢失后恢复原结果。第一课失败保留已采用编号，独立重试。
- 原规划全部学完的“直接生成下一课”使用预览中的单课扩展：生成正文草稿时不改变正式规划，保存正文时把追加目录和正文通过原发布日志一次提交。预览明确总课数将增加，原完成课次不变。
- 正式内容上下文仅含确认的目标、公开教学内容和已准备资料；原始笔记、答案和反馈只进入本次明确选择的私人建议。先预览计划和正文再写入内容仓库。
- 现代云端改用未学课次/待处理草稿/运行任务判定，不以日期阻止下一课。旧离线代码保留按日兼容。
- 持久化内容快照；规划、课程版本变化返回409并提供重新核对。重启后建议任务标记中断，不自动付费重试；刷新恢复现有结果。

## Risks / Trade-offs

- 生成/采用跨GitHub与数据库 → 沿用原发布日志和稳定回执；关联操作可重复补齐，不重复建课。
- 正式课缺少资料 → 沿用上课正文和确认的材料，缺失则要求补充，保留表单。
- 多端编辑 → 接续输入使用 revision，生成请求使用key及内容摘要。
- 私人资料外泄 → 服务端引用检查、上下文隔离、发布文件断言测试，界面标明发布范围。

## Migration Plan

在当前账号schema幂等增加接续记录与任务表，保留所有旧计划与完成记录。回退前端入口及路由后新私人表可保留。无自动历史回填、无远端发布。
