## Context

当前根 Python 3.13.9，48 项运行锁匹配；配置缺 APP_PASSWORD、ACCOUNT_ENCRYPTION_KEY、LEARN_ROOT。现有 prepare_materials.py 可只读导出公共教学白名单，不覆盖既有目录。design-tokens.css 已有颜色、间距、字体、圆角等定义，index.html 又重复定义部分变量。

## Decisions

1. check --offline 仅跳过数据库连接，仍校验必填配置、导入依赖及目录读写；不启动服务。serve --offline 明确拒绝，不能成为绕过启动预检的入口。管理脚本增加 check 转发，保留原 start 行为。
2. 教材导出到新的 .grow-public-materials，保留清单及哈希，不含学习记录／个人规划。保持业务 .env 与原有加密密钥，缺项须从原安全来源恢复或由用户配置，不能生成新 key 冒充修复。
3. Token 文件是主页面变量唯一来源，保留旧变量别名；沿用已有品牌色。状态文字单设高对比前景色，不改变品牌绿／黄语义色本身。默认保留按钮按压效果，prefers-reduced-motion 下禁用过渡和按压缩放。
4. 给原有表单补充清晰的键盘焦点；布局、字号及模块结构保持已有范围。提取 index 内联样式的最小浏览器夹具必须同时读取 token 来源。
5. 本轮只改 Grow 网页；样式注释不再声称已与原生端自动同步。已有工作树保留。实际配置缺项与隔离启动成功分别汇报。
