## Context

平台为FastAPI、原生JS与SQLite，已有httpx及兼容模型流式接口。没有已配置的全网搜索服务。采用官方RSS/Atom来源内发现，不把限定来源检索宣传成全网搜索；后续收费检索可作为独立适配器。

## Goals / Non-Goals

**Goals:** 少量、中英文、可追溯的近期与经典文章，本地可读资料、个人记录、每日运行和主动搜集。

**Non-Goals:** 不虚构热度、不绕过付费墙、不默认复制全文、不默认调用付费模型、不把打开或生成视为读完。

## Decisions

1. 学习栏目增加认知阅读：每日精选、帮我找文章、阅读收藏、偏好。搜集结果先预览，手动勾选保存；每日运行按已保存偏好自动保存。默认3篇、混合、中文+英文、全部五类主题、北京时间10:00，可暂停及改时间。
2. 免费读取固定来源目录的RSS/Atom，显式显示来源列表与读取失败。题目/摘要按双语主题词匹配；用户关键词在来源内筛选，不让模型虚构文章。近期默认30天，有可靠日期才归近期。经典来自核验过的原始页面目录。数量不足如实交付，不以旧闻充数。规范化URL稳定编号，已保存文章不重复推荐；来源多样性优先。
3. 来源短摘要与自写阅读提示可离线阅读；仅核验订阅摘要时清晰标识。AI中文导读显式按钮触发，发送文章元信息与已有摘要，不发送笔记，不获取付费全文；结果标为AI待核对。摘要不足时拒绝生成，无完整结束信号不覆盖原导读。
4. 持久化任务有queued/running/ready/failed/cancelled，前端只读轮询、中文状态，失败可明确重新搜集。请求键去重，后台任务不会因离开页面停止。读取与刷新不发起模型调用。
5. 新reading_records表保存偏好、任务、文章与导读；独立于旧state同步。沿用平台写锁、原子文件替换和本模块导出意图恢复；文件外部修改冲突时不覆盖。个人笔记独立文件，保存要求当前哈希。导出意图完成后才标已保存。
6. 本地路径认知阅读/每日精选/YYYY/MM/YYYY-MM-DD-今日精选.md、文章资料/article-ID/{文章信息.json,中文导读.md}、阅读笔记/article-ID.md、搜集记录/YYYY-MM-DD-任务ID.md。非日常搜集使用独立目录文件，避免覆盖当日精选。
7. 本地应用生命周期启动一个每30秒检查的调度器；仅北京时间当日到点且没有日任务时运行。停机不会运行，重启只补当日。失败不无穷自动重试；用户可手动搜集。不创建新的Codex任务，不修改原课程自动任务。
8. 外部链接仅HTTPS与允许的来源域；网络请求仅固定订阅地址，不接受任意用户URL、不跟随任意重定向，限制响应大小和超时，XML拒绝DTD/实体。页面全部使用安全文本节点或已有Markdown渲染。

## Risks / Trade-offs

- 来源失效/网络限制 → 展示逐来源结果，不伪称全网完整覆盖，可保存已成功部分。
- RSS摘要信息有限 → 标明摘要来源，导读不能作全文结论；原文链接用于继续阅读。
- 经典种子库有限 → 用尽如实提示，可持续维护来源目录，不重复塞入已收藏内容。
- 本地服务停止 → 偏好页明确执行条件，日任务记录实际运行状态。
- 并发与外部编辑 → 短写锁、幂等键、文件哈希、恢复日志；备份包含新目录和数据库。

## Migration Plan

启动前数据库快照；增量创建reading_records。旧模块无迁移。回退UI入口可停止调度但保留模块数据；完整回退前备份，不能恢复旧数据库覆盖新笔记。首轮使用隔离目录和模拟传输验证，再测试真实订阅读取；真实AI调用沿用已获授权的计划联调，阅读导读先模拟验证，不扩大付费授权。
