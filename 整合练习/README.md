# 三合一整合练习：把四个模块串起来

## 为什么要有这个模块

你现在有四个学习模块：
- 英文阅读（输入）
- 每日认知通识（输入）
- 现代思维工具（加工）
- 结构化表达（输出）

它们现在是**平行推进**的——各学各的。
但真正的能力提升，不是"每个模块单独学"，而是**把它们组合起来用**。

就像学武术：你练了拳、练了腿、练了身法，但实战的时候要把它们合在一起用才行。

三合一整合练习就是：**一次练习，同时调用三个模块的能力**。

## 怎么练？

**频率：** 每周 1 次，周末做
**时间：** 30 分钟

**流程：**

```
第一步：输入（10分钟）
  → 选一篇你这周英文阅读里的文章
  → 或者选一个认知通识课的主题

第二步：加工（10分钟）
  → 选一个思维工具来分析它
  → 比如：用 5 Whys 分析文章里的问题
  → 比如：用逻辑树拆解文章的论证结构
  → 比如：用冰山模型分析一个社会现象
  → 比如：用 SWOT 分析文章里提到的决策

第三步：输出（10分钟）
  → 用结构化表达把你的分析写出来
  → 用 PREP 写一段 200 字的总结
  → 或者用 SCQA 写一个"问题—解决方案"的结构
  → 或者用金字塔原理组织你的分析结果
```

## 为什么这样练有效？

1. **你会真正理解每个工具的边界**——什么时候好用，什么时候不好用
2. **你会建立"工具库"的直觉**——遇到什么问题，自动想到用什么工具
3. **三个模块的知识会"长在一起"**——不再是零散的知识点，而是一个整体
4. **你会发现自己的薄弱环节**——哪个环节卡壳了，就重点补哪个

## 关键提醒

- **不要追求完美，追求"做完一次"。**
- 第一次练会很别扭，很正常——就像第一次用左手写字
- 做满 10 次之后，你会明显感觉到"打通了"
- 如果某个环节特别卡，说明那个模块你还没掌握，回去补
