# 每日认知与通识学习

所属平台：**知行成长 · 个人学习与成长平台**。本模块沿用现有目录，生成内容遵守 [平台内容存储规则](../知行成长/内容存储规则.md)。

每天北京时间上午 **10:00** 生成课程，每次学习约 **15–20 分钟**。

## 文件组织

- `每日课程/`：保存完整课程，按“日期-第NNN课-主题.md”命名。
- `参考资料/`：保存对应课程的资料摘要、来源链接、阅读提示与适用边界。
- `学习记录.md`：记录课程生成日期、课程链接、学习状态和个人反馈。
- `学习规划.md`：保存学习路线和每日学习方法。

资料采用本地 Markdown 摘要和来源链接；来源原文不默认全文复制或下载。没有网络时仍可阅读已保存的课程和摘要，打开外部原文需要联网。

自动生成课程不等于已经学习。学习状态由本人反馈或手动更新，程序不得自行标记为已掌握，也不得覆盖个人笔记。

每日任务先检查本地课程，沿最后一个完整课次继续；同一天不重复生成。漏学时不要求集中补课，课程进度与个人掌握程度分开记录。
