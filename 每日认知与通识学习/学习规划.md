# 24周每日成长学习规划

## 目标与节奏

逐步形成看清事实、理解自己和他人、理解社会运行、判断收益与风险，并用历史拓宽视角的能力。

第一轮24周、168课。每天北京时间10:00生成一课，每次学习15–20分钟；每7课为一周，前6课学习新知识，第7课复盘。按实际已生成课次推进，不因日期间隔跳课。

| 阶段 | 学习重点 | 目标能力 |
|---|---|---|
| 第1–4周：认知基础 | 事实与观点、证据、逻辑、数据、概率、因果 | 判断一个说法是否可信 |
| 第5–8周：心理 | 注意与记忆、情绪、认知偏差、习惯、沟通 | 理解自己的判断过程与他人的行为 |
| 第9–12周：社会 | 激励、信息不对称、合作与博弈、组织与制度 | 分析行为与环境的关系 |
| 第13–16周：经济与金融 | 机会成本、供需、货币、利率、通胀、银行与信用 | 看懂经济现象及其影响路径 |
| 第17–20周：投资 | 资产类别、复利、风险、分散、估值、费用 | 理解收益来源与可能承担的损失 |
| 第21–24周：历史与综合 | 史料、工业化、制度变迁、金融危机、跨领域分析 | 多因素解释事件，识别历史类比的边界 |

历史案例贯穿前20周，最后4周集中整合。第二轮根据学习反馈深化，继续每日频率，直到本人调整或停止。当前网页仅支持第一轮001–168；进入第二轮前，按[平台存储规则](../知行成长/内容存储规则.md)规划独立目录与接入，避免覆盖第一轮内容。

## 每日方法

1. 回忆2分钟：不看答案，回想一个已学概念。第1课不要求回忆前课。
2. 学习8分钟：理解一个概念和一个完整案例。
3. 练习5分钟：尝试把概念用在自己的生活或工作中。
4. 记录2分钟：写下“我原来怎么想，现在准备怎么判断”。

每课约600–1000字，包含日期与课次、引导问题、通俗解释、完整示范、常见误区与适用边界、3–5分钟练习、独立分隔的参考分析、自查标准和一句记忆提示。根据内容需要可适当调整篇幅。

在后续课程中适时回顾约1、7、30课前的内容；每周复盘，每4周进行跨领域案例练习。复习间隔是便于执行的安排，并非对所有人都最优的固定规律。

## 第一周

| 课次 | 主题 |
|---|---|
| 001 | 区分事实、解释与判断 |
| 002 | 什么样的证据更可信 |
| 003 | 确认偏误：为什么容易只看见支持自己的信息 |
| 004 | 相关不等于因果 |
| 005 | 基准率：判断之前先看看通常情况 |
| 006 | 机会成本：选择一件事时放弃了什么 |
| 007 | 用生活案例复盘本周知识 |

首周涉及后续主题时仅作直观引入，正式阶段继续深化。

## 自查与调整

- 能否用自己的话解释？
- 能否举出一个新例子？
- 能否说明什么时候不适用？

漏学后从当前课继续，不集中补课。根据实际完成时间、练习表现和本人反馈调整难度，不把生成或阅读等同于掌握。

## 资料原则

课程优先使用可信原始或权威来源，附实际使用的链接；区分事实、推测和有争议的解释。金融部分以概念与风险教育为主；历史案例注明背景及类比边界；心理内容不对个人进行诊断。

示范、练习、主动回忆和间隔复习的教学安排参考：[IES学习实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)。该指南支持这些一般方法，不验证本课程24周安排或个人学习效果。
