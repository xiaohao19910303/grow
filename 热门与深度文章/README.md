# 热门与深度文章：按需搜集

所属平台：**知行成长**。内容生成与归档遵守 [平台存储规则](../知行成长/内容存储规则.md)，已有文件与个人记录保留。

用于需要时寻找值得读的深度文章或近期热门文章。由对话中的助手按以下规则实时检索并保存；本目录本身不是搜索程序。

## 如何提出需求

- “帮我搜集最近一周值得读的热门文章。”
- “找5篇能提升认知的深度文章，重点是决策和社会观察。”
- “搜集最近关于AI与职业发展的热门文章，帮我筛出最值得读的3篇。”
- “今天只有20分钟，帮我选一篇文章并做阅读导引。”

可指定主题、时间范围、篇数、语言或平台。没有指定时，采用最近7天、5篇、中文优先，主题覆盖认知与决策、科技与社会、个人成长。候选不足时明确说明，可补充近30天文章并标出日期；经典深度文章单列，不冒充近期热点。

## 筛选规则

1. **分别评价深度和热度。** 深度看论证、证据、解释力、适用边界及是否带来可迁移的思考；热门看可核验的榜单、阅读或互动数据、讨论记录。不把热度当作正确性的证明。
2. **实际打开来源。** 核对标题、作者或机构、发布日期、原文链接和可访问范围。只能看到摘要时标注“仅核验摘要”，不写成全文精读结论。
3. **记录热度依据。** 写明平台、观察时间、指标或榜单位置及证据链接。不同平台数字不直接排名；无法查证时写“热度未核实”，不能因搜索排名靠前就称为爆款。
4. **优先原始出处。** 去除同文转载和重复收录；重要事实尽量追溯原始报告、研究或官方资料。争议观点说明主要分歧和证据局限。
5. **保留可读的本地摘要。** 用自己的话整理核心观点、论据、局限和思考题，链接回原文，不默认复制或翻译受版权保护的全文。登录或付费限制如实注明。
6. **保存不等于读完。** 新条目默认“待阅读”，仅根据本人反馈更新阅读状态，保留个人笔记。

## 每次交付

在 `搜集记录/` 下新建 `YYYY-MM-DD-主题.md`；同日同主题再次搜集使用序号区分，避免覆盖。先查看本目录已有记录，去重后再保存。每批包含：

- 搜集时间、检索范围、主题和筛选说明。
- 推荐清单：标题、类别（深度／热门／兼具）、发布日期、推荐理由、原文链接。
- 每篇阅读卡：作者与来源、核验范围、热度依据及观察时间、核心观点、关键论据、局限或反方观点、一个思考题、预计阅读时间（估算）、阅读状态与个人笔记。
- 优先读哪一篇及理由；若数量不足或热度不可核实，明确说明。

完成后将实际生成的文件链接追加到下面的索引，并检查原文链接与本地文件路径。没有实际检索和保存时，不新增文章条目。
