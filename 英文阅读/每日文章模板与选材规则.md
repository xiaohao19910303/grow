# 每日文章模板与选材规则

本文件供后续每日材料制作使用；学习者直接打开当天文章即可。

## 选材与维护要求

1. 先读取学习规划、学习记录和 README 索引，确定当前程度和已经使用的来源。
2. 每天在线寻找并实际打开一篇真实英文文章，优先来源明确、适合学习、无需登录的教育或科普材料。不要将搜索摘要当作全文。
3. 同一来源文章不重复当作新课。允许相同主题连续学习，以复现词汇。新闻并非必选，不要求文章当日发布。
4. 注明来源标题、机构、原始链接、发布日期或更新时间（能确认才填）、检索日期。
5. 优先选可合法转载的公有领域或明确开放许可文本。受版权保护的文章提供链接、合规短摘录及有限概述，不全文复制或逐段翻译整篇，不用近似全文改写规避限制。必要时换用可复用来源。
6. 若使用 AI 教学改写，要明确标记，并将中文翻译对应到教学正文，不把改写标为来源原文。例句和练习可自行编写，事实依据须可靠。
7. 默认每日 35 分钟，周末周期中的复盘日和轻阅读日缩短篇幅。无学习反馈则保持起始难度，不因日历推进自动大幅升级。
8. 文件名采用 `YYYY-MM-DD-DayNNN-中文主题.md`。日期按 Asia/Shanghai；序号按已有课次递增。当天文件已经存在时检查完整性，保留用户笔记，不重复创建或覆盖。
9. 追加 README 索引和学习记录空白行，不虚构学习用时、成绩或完成状态。
10. 网络或来源获取失败时说明情况，不编造出处。改用另一个可访问来源；都失败则保留现有材料，通知本次未完成。
11. 每次成功生成后，简短通知当天主题、语法重点和本地文件链接。不发送无变化的重复通知。失败或需要用户处理时明确说明。
12. 仅修改本学习目录；不创建代码提交，不安装工具。每次检查文件内容、来源标记、题目答案和内部链接。

## 每篇文章结构

```markdown
# Day NNN｜英文标题｜中文标题

- 学习日期：
- 难度：教学估计，非正式测评
- 篇幅与预计用时：
- 来源标题、机构、链接：
- 来源日期 / 检索日期：
- 内容性质：原文摘录 / AI 教学改写；翻译对应哪一部分
- 今日目标：2～3 项

## 1. 阅读前：带着问题读
2 个引导问题，不提前揭示全部答案。

## 2. 英文学习正文
分段编号；先英文，后面才出现翻译。

## 3. 先做阅读理解
3 题：主旨、细节、关系或推断；答案在文末。

## 4. 逐段中文翻译
与英文段落一一对应，必要时补充词义辨析。

## 5. 词汇与词组
8～12 项：词性、语境中文义、搭配、英文例句及中文。
标出 3～5 项重点记忆，其余只需认识。后期可按篇幅调整。

## 6. 语法与长句
约 3 项：正文原句、主干、句子成分、译法、易错点、迁移例句。
一个重点完整讲清，其余用于认识或复习，不堆砌术语。

## 7. 巩固练习
3 题：填空 / 改写 / 翻译，可用正文解决。

## 8. 今日复习
重点词、明日回顾项；结合过去课程安排间隔复习。

## 9. 参考答案与解释
说明正确原因，并指出所在段落；开放题允许同义表达。

## 10. 我的学习笔记
首次用时、主旨、答题结果、困难句、反馈；保持空白待用户填写。
```
