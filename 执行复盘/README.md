# 执行复盘：把"想清楚"变成"做得到"

## 为什么要有这个模块

前面的四个模块（英文阅读、认知通识、思维工具、结构化表达）解决的是"输入→加工→输出"的问题。
但从"知道"到"做到"之间，缺了一个关键环节：**执行与反馈**。

执行复盘就是补上这一环——通过每天的刻意反思，把你的决策、行动、结果连接起来，形成一个持续迭代的闭环。

## 核心逻辑

```
决策 → 行动 → 结果 → 复盘 → 改进 → 下一次更好的决策
```

不复盘的人，同样的错会犯第二次；复盘的人，每次犯错都是一次升级。

## 每天怎么练

**时间：** 睡前 5 分钟，不超过 10 分钟
**原则：** 写下来，不要只在脑子里想。写下来的过程本身就是思考。

每天回答三个问题：
1. 今天我做了哪个重要决策？依据是什么？
2. 结果怎么样？和预期有什么差异？
3. 如果重来，我会怎么调整？

再加一个：今天做得不错的一件小事是什么？（正面反馈，保持动力）

## 文件说明

| 文件 | 用途 |
|---|---|
| `每日复盘模板.md` | 每天复制一份，按模板填写 |
| `复盘记录.md` | 按日期汇总，方便周复盘和月复盘 |

## 节奏

- **每天：** 5 分钟写当日复盘
- **每周日：** 翻一遍本周的 7 条记录，找规律
- **每月底：** 看这个月重复出现的问题是什么，制定下月改进重点

## 关键提醒

- 不要追求完美，写得粗糙也比不写强
- 不要只写"哪里做得不好"，也要写"哪里做得好"
- 漏了一天就漏了，第二天接着写，不要补写
- 复盘的目的不是自我批评，而是**让下一次更好**
